## 摘要
大语言模型（LLM）的日益部署放大了自回归解码的计算和内存瓶颈，其中低计算强度和带宽受限的内核主导了推理成本。权重剪枝提供了一种有前景的解决方案，但现有方法仍局限于要么是静态剪枝（SP），即永久移除冗余权重但缺乏适应性，要么是动态剪枝（DP），即适应输入稀疏性但引入运行时不规则性。本文提出SPDP，一个统一的稀疏推理框架，将非结构化SP与输入自适应DP相结合，以在GPU上实现高效的LLM推理。SPDP协同设计了一种新的平铺列式位图压缩（Tiled-CBC）格式和两个互补的GPU内核：（1）一个CUDA核心的稀疏矩阵-稀疏向量乘法（spMspV）内核，具有混合激活感知动态共享内存位图解压（HAD-SMBD），用于细粒度的运行时激活跳过；（2）一个针对预填充计算优化的张量核心稀疏矩阵乘法（SpMM）内核。这种联合格式-内核设计协调了静态和动态稀疏性，在LLM推理的两个阶段都保持了带宽高效的内存访问和高计算强度。在推理优化GPU上的全面评估表明，SPDP相对于最先进的稀疏框架（如SpInfer）实现了1.24倍至1.37倍的平均加速（最高达2.51倍），同时以高达25%更高的稀疏度匹配了困惑度。SPDP推进了推理效率-质量的帕累托前沿，表明统一静态-动态剪枝可以在大规模LLM服务中实现显著的吞吐量和每瓦性能提升。

## Abstract
The increasing deployment of large language models (LLMs) has magnified the computational and memory bottlenecks of autoregressive decoding, where low compute intensity and bandwidth-bound kernels dominate inference cost. Weight pruning offers a promising remedy,   but existing methods remain confined to either static pruning (SP), which permanently removes redundant weights but lacks adaptivity, or dynamic pruning (DP), which adapts to input sparsity but introduces runtime irregularity. This paper presents SPDP, a unified   sparse-inference framework that integrates unstructured SP with input-adaptive DP for efficient LLM inference on GPUs. SPDP co-designs a new Tiled-Column-wise Bitmap Compressed (Tiled-CBC) format and two complementary GPU kernels: (1) a CUDA-core spMspV kernel   featuring Hybrid Activation-aware Dynamic Shared-Memory Bitmap Decoding (HAD-SMBD) for fine-grained, runtime activation skipping, and (2) a Tensor-Core SpMM kernel optimized for prefill computation. This joint format-kernel design harmonizes static and dynamic   sparsity, maintaining bandwidth-efficient memory access and high compute intensity under both phases of LLM inference. Comprehensive evaluations on inference-optimized GPUs demonstrate that SPDP achieves 1.24x-1.37x average speedup (up to 2.51x) over state-of-the-   art sparse frameworks such as SpInfer, while matching. perplexity with up to 25% higher sparsity. SPDP advances the inference efficiency-quality Pareto frontier, showing that unified static-dynamic pruning can deliver substantial throughput and performance-per-watt   improvements in large-scale LLM serving

## 2. 论文提出的方法论：核心思想、关键技术细节、公式与算法流程

### 核心思想
- **互补性**：静态剪枝（SP）减少权重的存储和带宽；动态剪枝（DP）根据输入实时跳过非重要激活列。两者同时作用可倍增有效稀疏度，从而提升计算强度（CI）。
- **联合格式-内核设计**：针对SP+DP同时存在的场景，设计既能保持静态压缩又支持运行时列访问的稀疏格式，以及分别适用于解码（spMspV）和预填充（SpMM）的GPU内核。

### 关键技术细节
1. **Tiled-CBC（平铺列式位图压缩格式）**
   - 按列微块（Tile）组织：每个Tile大小 `TILE_M × TILE_K`（如256×16），列微块大小为 `TILE_M × 1`。
   - 存储结构：`TileOffset`（索引GTile）、`Values`（按列存储非零值）、`Bitmap`（每列4个64位位图）、`ColInfo`（打包每列的起始偏移和NNZ计数）。
   - 优势：列对齐，便于运行时按激活稀疏性跳过整列；同时保证全局内存的合并访问。

2. **解码阶段（spMspV）内核**
   - 采用CUDA core执行GEMV，避免Tensor Core在GEMV场景下的低效。
   - **HAD-SMBD（混合激活感知动态共享内存位图解压）**：两阶段解压，首先根据动态阈值判断列是否活跃；对活跃列，使用MaskedPopcount计算每个线程的偏移，加载对应元素到寄存器。非活跃列完全跳过。
   - **异步流水线**：采用三组独立异步拷贝组（ColInfo加载、XTile加载、GTile加载），并通过元数据预取实现内存与计算的重叠，最小化同步开销。
   - 优化细节：使用`cp.async`指令，列值填充到16字节对齐，设置`TILE_K=16`，采用Split-K并行化均匀分配负载。

3. **预填充阶段（SpMM）内核**
   - 利用Tensor Core执行矩阵-矩阵乘法（GEMM）。
   - **布局对齐**：将Tiled-CBC的列主序布局在共享内存中转换为Tensor Core要求的行主序，通过填充（`TILE_K_PAD`）避免bank冲突。
   - 异步流水线：与spMspV类似，但去掉DP相关的列选择，增加布局对齐阶段，利用XTile加载的长延迟掩盖开销。

### 相关公式
- 计算强度（CI）：
  $$CI = \frac{M \cdot N}{\frac{M}{CR} + N}$$ 
  联合稀疏下：
  $$CI_{SPDP} = \frac{M \cdot N}{\frac{M}{CR} \cdot (1-s) + N}$$
  其中CR为压缩比，s为动态稀疏率。

### 算法流程（以spMspV为例）
① 加载ColInfo到共享内存 → ② 加载XTile（输入向量） → ③ 加载GTile（权重微块，仅加载DP活跃列） → ④ HAD-SMBD解压 → ⑤ CUDA core执行GEMV累加。采用双缓冲和异步拷贝流水线重叠各阶段。
