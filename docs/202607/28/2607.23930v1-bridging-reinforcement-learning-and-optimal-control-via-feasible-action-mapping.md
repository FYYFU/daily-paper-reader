## 摘要
运行受约束的动态系统要求控制器在强制执行递归可行性和安全约束的同时高效解决复杂任务。为应对这些相互矛盾的需求，我们提出了可行动作最优控制（FAOC），这是一种集成强化学习（RL）与最优控制（OC）的新型控制框架。关键贡献在于一种计算高效的、基于优化的映射算法，该算法将RL agent的动作从静态抽象集转换为最优控制问题（OCP）的状态依赖可行参数集，从而严格保证动态系统约束的满足。因此，FAOC有效结合了OC的可预测安全性与RL的灵活性。与先前工作不同，RL agent的抽象动作空间无需专家或启发式设计，且OCP的公式化不会因RL无法保证可行性而受损。我们将该方法应用于乒乓球机器人的实时运动规划，该场景囊括了上述挑战。通过仿真实验，我们展示了FAOC在样本效率与闭环性能上均优于最先进的基准方法。

## Abstract
Operating constrained dynamical systems requires controllers to efficiently solve complex tasks while enforcing recursive feasibility and safety constraints. To address these competing requirements, we present Feasible Action for Optimal Control (FAOC), a novel control framework integrating Reinforcement Learning (RL) and Optimal Control (OC). The key contribution is a computationally efficient, optimization-based mapping algorithm that transforms the RL agent's action from a static abstract set into a state-dependent feasible parameter set of the Optimal Control Problem (OCP), guaranteeing strict satisfaction of the dynamical system's constraints. Thus, FAOC effectively combines the predictable safety of OC with the flexibility of RL. In contrast to prior work, the abstract action space of the RL agent does not require expert or heuristic design, and the OCP formulation is not compromised by the inability of RL to guarantee feasibility. We apply our approach to real-time motion planning for robot table tennis, which encapsulates these challenges. Via simulated experiments, we show that FAOC outperforms state-of-the-art baselines in both sample efficiency and closed-loop performance.

- **动机**：现有RL+OC混合方法的一个关键瓶颈在于两者接口——RL往往输出动作作为OCP的参数，若参数超出可行集，OCP会不可行。已有方法要么使用软约束牺牲安全性，要么需要启发式设计动作范围，要么只能处理一维映射，限制了表达力和性能。
- **整体含义**：本文提出FAOC框架，通过一个可逆的优化映射，将RL的抽象动作（静态凸集）转化为状态依赖的OCP可行参数集，从而严格保证约束、同时保留RL的探索灵活性。

## 2. 方法论

### 2.1 核心思想
- **分层结构**：高层RL策略输出抽象动作 \(\bar{a} \in \bar{\mathcal{A}}\)（静态凸集，如超立方体）；低层参数化OCP（如线性MPC）以参数 \(p\) 编码RL意图（如终端状态目标）；中间层为映射算法 \(\mathcal{M}\)，将 \(\bar{a}\) 一对一映射到当前状态下的可行参数集 \(\mathcal{P}(x)\)，确保OCP始终可行。
- **关键要求**：映射需是双射（避免动作别名）、连续、计算高效，且能处理状态依赖的、可能只有隐式定义的参数集。

### 2.2 关键技术细节

#### (a) 参数集拓扑性质
- Lemma 1：在OCP满足一定条件（如约束函数凸、可行集紧致、存在严格可行点等）下，\(\mathcal{P}(x)\) 是紧致、凸、实心的。Corollary 1给出线性MPC的实例（终端约束矩阵满秩保证凸性）。

#### (b) 通用径向映射算法（Algorithm 1）
1. 给定基集 \(\mathcal{X}\)（抽象集）和目标集 \(\mathcal{Y}\)（参数集），分别计算内点 \(x_c, y_c\)。
2. 对任意点 \(x \in \mathcal{X}\)，计算从 \(x_c\) 出发方向 \(d = x - x_c\)，并求射线与边界相交的缩放因子 \(\alpha\)。
3. 应用方向变换 \(\phi(d)\) 得到 \(d'\)，再求射线 \(y_c + \beta d'\) 与 \(\mathcal{Y}\) 边界的缩放因子 \(\beta\)。
4. 映射结果 \(y = y_c + (\beta / \alpha) d'\)。
- 方向变换 \(\phi\) 需连续、可逆、正齐次。Proposition 1 证明此映射是双射。

#### (c) 方向变换设计（缓解点累积）
- **Identity变换**：简单但会导致在狭长目标集中点严重聚集，降低学习效率。
- **2D面积匹配变换**（Proposition 2-3）：利用归一化面积函数 \(a_{\mathcal{X}}(\xi)\) 和 \(a_{\mathcal{Y}}(\xi)\) 将角度 \(\xi\) 映射到 \(\upsilon = a_{\mathcal{Y}}^{-1}(a_{\mathcal{X}}(\xi))\)，使得均匀采样在 \(\mathcal{X}\) 中的点的角度分布在 \(\mathcal{Y}\) 中与面积比例一致，完全消除点聚集。
- **高维线性变换**（Proposition 4）：用最大体积内接椭球（MVIE）拟合 \(\mathcal{X}\) 和 \(\mathcal{Y}\) 的代理集，计算矩阵 \(\Phi = Q_{\mathcal{Y}} Q_{\mathcal{X}}^{-1}\)，将 \(\phi(d)\) 设为 \(\Phi d\)。此近似有效减轻点累积，且可扩展到任意维度。

#### (d) 隐式参数集的处理
- 当 \(\mathcal{Y} = E\mathcal{W} + e\)（\(\mathcal{W}\) 为高维OCP决策变量集）时，无需显式表示 \(\mathcal{Y}\)，而是直接在 \(\mathcal{W}\) 空间操作。
- **计算内点**：通过Proposition 5（投影相对内点）或优化内接多面体球（Proposition 6-7）。
- **计算形状矩阵**：离线建立状态无关的代理集（Example 3），在线只做线性变换。
- **计算边界因子**：通过求解一个凸优化问题（8）直接得到 \(\beta\)。
- 整个映射过程避免了对 \(\mathcal{P}(x)\) 的显式多面体表示，适合实时计算。

## 3. 实验设计

- **场景**：8-DoF移动机械臂的乒乓球任务，每个控制循环RL输出16维目标位姿/速度（每关节2维），OCP规划4段8ms的恒定 jerk 轨迹，最终下发1ms控制参考。
- **Baseline方法**：
  - 1Dpos/1Dvel/1Dacc：基于Kiemel & Kröger [30]的一维映射，只能指定位置/速度/加速度之一。
  - 2Dsoft：相同2D动作空间但无可行性保证，使用软终端代价（权重 \(w_s, W_t\)）替代硬约束。
- **算法框架**：使用SAC + BRO网络架构（基线实验）和SimBaV2（分布层批评者+更大网络）验证算法迁移性。
- **评估指标**：返回球比例、生成上旋/下旋角速度、球速、目标距离。每点来自1000个评估episode，5个随机种子。

## 6. 主要结论

- FAOC在所有实验中的样本效率和最终性能均显著优于所有baseline（尤其1D变体和2Dsoft）。
- 在低RL频率（7.8125 Hz）下，FAOC几乎保持性能，而其他方法退化严重，验证了FAOC更好的轨迹段可控性。
- FAOC无需专家设计动作范围，自动保证OCP可行性，且映射计算高效（仅需少量比值运算或简单优化）。
- 真实世界验证：该框架已用于赢得与专业运动员的正式比赛（Nature 2026），证明实际有效性。
