## 摘要
基于可验证奖励的强化学习（RLVR）在训练大型语言模型智能体方面是有效的。然而，终端奖励仅提供粗略的轨迹级监督，使成功行为、重复错误和偶然选择混杂在同一个结果信号中。现有的智能体自蒸馏方法通过自然语言技能丰富稀疏监督，但从外部检索或由更强模型从单条轨迹提取的技能可能与当前经验不匹配、超出策略能力或仍局限于特定路径。我们提出群体反思式自蒸馏（GRSD），它从策略自身的已验证轨迹中导出能力对齐且结果判别性的指导。对于每个提示，策略对同策略组中的每条已验证轨迹进行反思，一个停止梯度的快照对比成功与失败轨迹产生的反思结果，以构建组级别的特权指导。在该指导的条件下，一个自教师通过调节基于结果的优势，同时保持验证器确定的学习方向，来细化回合级别的信用分配。在多个智能体环境和模型规模上的实验表明，GRSD持续优于竞争基线，并在未见任务上实现更有效的泛化。

## Abstract
Reinforcement learning with verifiable rewards (RLVR) is effective for training large language model agents. However, terminal rewards provide only coarse trajectory-level supervision, leaving successful behaviors, recurring mistakes, and incidental choices entangled in the same outcome signal. Existing agentic self-distillation methods enrich sparse supervision with natural-language skills, but skills retrieved externally or extracted from a single trajectory by stronger models may mismatch current experience, exceed the policy's capability, or remain path-specific. We propose Group-Reflective Self-Distillation (GRSD), which derives capability-aligned and outcome-discriminative guidance from the policy's own verified rollouts. For each prompt, the policy reflects on each verified trajectory in an on-policy group, and a stop-gradient snapshot contrasts the resulting reflections from successful and failed rollouts to construct group-level privileged guidance. Conditioned on this guidance, a self-teacher refines turn-level credit assignment by modulating outcome-based advantages while preserving the verifier-determined learning direction. Experiments across multiple agentic environments and model scales demonstrate that GRSD consistently outperforms competitive baselines and generalizes more effectively to unseen tasks.

## 1. 核心问题与整体含义

- **研究动机**：LLM 智能体在多轮交互中需要与环境、工具协作，基于可验证奖励的强化学习（RLVR，如 GRPO）已成为主流训练范式。但**终端奖励只提供轨迹级粗粒度监督**，使成功行为、重复错误和偶然选择在同一个结果信号中纠缠，难以判断哪些中间决策真正决定了成败。
- **现有方法不足**：已有智能体自蒸馏方法通过自然语言技能来丰富稀疏监督，但技能来源存在明显缺陷：
  - 外部技能库检索（如 Skill-SD、SDAR）可能**与当前提示/轨迹/状态不匹配**；
  - 从单条轨迹由更强外部模型提取的后见技能（如 OPID）可能**超出当前策略能力边界**，且缺乏成功–失败对照，容易学到路径特定的噪声细节。
- **核心目标**：使策略能够**从自身已验证的同策略轨迹中提取能力对齐、结果判别性的指导**，并利用它进行回合级（turn-level）信用分配，从而提升智能体 RL 的训练效率与泛化能力。

## 2. 方法论：GRSD（Group-Reflective Self-Distillation）

### 核心思想
- 对每个提示采样一组（G 条）策略自身生成的轨迹，验证结果后，策略对每条轨迹进行“自我反思”；用**停止梯度快照**对比成功与失败轨迹的反思，合成**组级特权指导（DO/AVOID）**；再以该指导为教师上下文，将轨迹级优势转化为回合级优势，同时保持验证器决定的更新方向不变。
- 训练过程中，指导仅用于构建训练信号；**推理时完全不需要特权指导**，无任何额外推理开销。

### 关键技术细节
- **阶段 A：策略原生自我反思**  
  - 同策略策略按指令 `p_ref` 对每条已验证轨迹生成结构化的反思技能 `s_i`（识别关键回合、解释成败原因、总结可复用行为）。
  - 外部固定评判器 `J` 为每条反思打标量分（0–3），并通过组内归一化得到反思优势 `A_ref_i`，用于训练反思能力。
  - 反思由策略自身生成，保证“策略原生”的能力对齐。
- **阶段 B：组级指导构建**  
  - 按结果标签划分成功反思集合 `S+` 与失败反思集合 `S-`；停止梯度快照 `π_θ̄` 对比两者，生成简洁的“DO/AVOID”指导 `z_x`。
  - 只对同时包含成功和失败轨迹的提示组（`m_x=1`）启用信用调节；否则回退到原始 GRPO。
- **回合级自蒸馏**  
  - 构造普通学生上下文 `c_stu` 与指导增强的教师上下文 `c_tea`，由同一快照策略分别评估同一动作 token 的对数似然，差分得到 `Δ_i,t`。
  - 用 `q_i,t = sign(A_i)Δ_i,t` 对齐验证器方向，再经指数变换、归一化、裁剪得到有界调制分数 `bq_i,t`。
  - 回合级优势：`bA_i,t = A_i (1 + λ bq_i,t m_x)`，并约束 `λ bG ≤ 1`，保证**不会反转验证器决定的符号**。
- **总体目标**：`L = L_task + α L_ref`，两者监督不同 token 集合（任务 token vs 反思 token），任务损失采用替换为 `bA` 的 GRPO 目标，反思损失用 GRPO 风格优化反思序列。

## 6. 主要结论与发现

- **性能领先**：GRSD 在三个骨干上均取得最强聚合表现；平均优于 GRPO 5.5%（ALFWorld）、2.7%（SearchQA），WebShop 得分与成功率高 4.8% / 7.2%；相对最强的技能型自蒸馏方法（Skill-SD / SDAR），ALFWorld 平均提升 4.2%、WebShop 成功率提升 5.5%。
- **泛化更强**：在 ALFWorld Unseen split 上平均成功率 83.6%，高于 GRPO（75.4%）和 SDAR（77.6%），Pick2 与 Cool 提升最显著（相对 GRPO +23.5% / +14.3%）。
- **训练动态更优**：GRSD 在后续训练阶段持续提升，而非基线方法那样的早期饱和；教师–学生差距更小，说明指导与策略能力更兼容。
- **消融验证设计**：组级指导、组聚合、失败反思均不可或缺；回合级调制优于 token 级（噪声大）和轨迹级（过于粗糙）；策略原生反思优于外部模型反思，且更易被策略内化。
- **理论支撑**：附录证明组内成功/失败对比能降低轨迹特定方差；优势调制是有界正缩放，不反转验证器方向。

## 7. 优点

- **方法创新性强**：
  - “策略原生 + 组级对比”的指导构建避免了外部技能库检索不匹配和单轨迹路径特定性问题。
  - 利用停止梯度快照避免自利博弈（self-serving bias），使指导既能反映策略当前能力又保持结果判别性。
  - 保留验证器决定的优势符号，仅做幅度调制，保持了 RL 目标的可信方向。
- **理论与实践结合**：附录提供了关于方差缩减、有界正调制、正重加权等价性的形式化分析，增强了方法的可解释性。
- **工程优雅**：
  - 无需外部内容生成模型（外部 judge 只提供标量评分，不生成内容）。
  - 推理无额外开销；训练开销仅增加约 17%，相对性能增益而言性价比高。
  - 在标准 GRPO 框架上改动自然，兼容现有 RLVR 训练栈（veRL + vLLM + FSDP）。
- **实验设计全面**：多环境、多骨干、多基线、多消融、超参敏感性和训练动态分析齐备，并给出实际训练成本对比。

## 8. 不足与局限

- **对混合结果组的依赖**：只有当同一提示下同时存在成功与失败 rollout 时，GRSD 才启用信用调制（`m_x=1`）。训练初期或策略较强时，混合组比例可能很低，此时方法退化为普通 GRPO，获益有限。
- **外部评判器的引入**：虽然 judge 只打分不生成内容，但其评分质量会影响反思训练（`A_ref`）。文中仅使用单一固定 judge（DeepSeek-V4-Flash）在温度 0 下的判断，未研究 judge 偏差、噪声或替换 judge 的鲁棒性。
- **符号对齐假设局限**：`q_i,t = sign(A_i)Δ_i,t` 在二元奖励（0/1）下与结果标签一致，但在连续奖励场景下优势符号可能与成功/失败标签不同，方法未在此类环境中验证。
- **理论分析的范围限制**：附录明确承认分析仅针对优化机制（有界正重加权），不保证生成指导的语义正确性、期望收益单调改善或联合优化的收敛性。
- **实验覆盖仍有限**：三个环境（具身、搜索问答、网页导航）虽具代表性，但未覆盖代码智能体、多智能体交互等更复杂场景；模型最大到 7B，未验证更大模型下的可扩展性。
- **统计可靠性**：未报告多次独立运行的方差、置信区间或显著性检验，某些子集上的性能波动可能影响结论的稳健性。
- **训练成本略高**：相比 GRPO 增加约 17% 训练时间，主要来自在线反思生成和组级合成；虽然相对增益可观，但在资源受限时需权衡。
