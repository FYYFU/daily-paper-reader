## 摘要
大型语言模型（LLM）智能体自主地将语义推理与复杂的系统操作交错进行。在这些动态环境中，静态的工具级权限从根本上是不够的；安全授权高度依赖上下文，并且严重依赖于不断变化的运行时状态和数据流。我们提出FAVA（Formal Authorization for Verified Agents），一个用于智能体执行的携带权限的授权框架。FAVA利用LLM引导的权限中间表示（IR）将模糊的自然语言任务转化为结构化约束。然后，一个确定性的降级过程将此IR转换为一个基于证据的权限图，该图显式地跟踪数据流、依赖关系和上下文标签。为了提供严格的安全保证，一个可满足性模理论（SMT）授权器在任何有效操作执行之前，根据安全策略对当前图进行数学验证。然后，运行时网关强制执行求解器的结果，要么授权执行，要么用精确的反例拦截执行。我们在OpenAgentSafety、OctoBench和ActPlane场景中评估FAVA。我们的评估表明，FAVA在聚合数据集上实现了90.5%的决策合规率（DCR），成功拦截了所评估的轨迹条件场景中的动态违规轨迹。

## Abstract
Large language model (LLM) agents autonomously interleave semantic reasoning with complex system operations. In these dynamic environments, static tool-level permissions are fundamentally insufficient; safe authorization is highly context-dependent and heavily reliant on evolving runtime states and data flows. We present FAVA (Formal Authorization for Verified Agents), a permission-carrying authorization framework for agent execution. FAVA utilizes an LLM-guided Permission Intermediate Representation (IR) to translate ambiguous natural-language tasks into structured constraints. A deterministic lowering pass then converts this IR into an evidence-backed permission graph that explicitly tracks data flows, dependencies, and contextual labels. To provide strict security guarantees, a Satisfiability Modulo Theories (SMT) authorizer mathematically verifies the current graph against security policies before any effectful action executes. A runtime gateway then enforces the solver's result, either authorizing the execution or intercepting it with a precise counterexample. We evaluate FAVA across OpenAgentSafety, OctoBench, and ActPlane scenarios. Our evaluation demonstrates that FAVA achieves a 90.5% Decision Compliance Rate (DCR) over the aggregate dataset, successfully intercepting dynamic violating traces in the evaluated trace-conditioned scenarios.

## 2. 方法论：FAVA框架

### 2.1 核心设计哲学

> **将“语义权限提取”与“最终安全授权”严格分离。**

- LLM只用于它擅长的地方：将模糊的自然语言任务解析为结构化的**权限中间表示（Permission IR）**；
- 由**确定性降级过程**将IR转换为**证据支持的权限图**（Evidence-backed Permission Graph）；
- 最终安全决策由**SMT求解器**在图与系统策略上数学地计算得出，而非依赖不可信的模型判断。

### 2.2 四阶段流水线

**（1）证据获取与Permission IR生成**
- IR共定义五个核心字段：`intent`（意图）、`assets`（受保护资产）、`actions`（工具级动作）、`obligations`（义务）、`sinks`（数据汇点），外加`evidence spans`（证据跨度）。
- 运行时轨迹也映射为相同IR格式，保证静态任务与动态执行在表示上统一。
- 明文规定：不能将“摘要”等模糊LLM声明当作“脱敏器”，必须有可信的转换器规范（如`redact(secret) -> safe_text`）。

**（2）图降级（Graph Lowering）**
- 确定性降级将IR映射为权限图 G = (V, E)：
  - **节点**：上下文本、源节点、工具节点、汇点（sink）节点，承载安全标签（secret/destructive），记录操作、参数、时间戳等；
  - **边**：三类依赖关系——`data`（值流）、`control`（时间/顺序守卫）、`parent`（运行时祖先）；
  - **信任来源**：observed（观察）、policy（策略）、inferred（推断——仅用于审计，不得作为授权依据）。
- 恶意提示幻觉：经过严格的结构与证据验证，拒绝畸形结构后才会进入SMT求解器。

**（3）SMT授权（SMT Authorization）**
- 将授权问题形式化为**可满足性模理论（SMT）问题**（使用Z3求解器）。
- 核心编码（Algorithm 1）：
  - **标签传播**：设 `H[v, ℓ]` 表示标签ℓ在节点v上的存在性，则：
    - 有可信脱敏器时，按规范转换标签；
    - 否则 `H[v, ℓ] = Explicit(v, ℓ) ∨ Source(v, ℓ, P) ∨ (∃u∈Pred(v) H[u, ℓ])`
  - **能力分配**：`A[v, c]` 表示能力c授予节点v；必需能力为硬约束，可选能力用Z3软优化最小化。
  - **策略执行**：对每条禁止规则 f = (Lf, Sf)，断言：
    `¬( (∨ℓ∈Lf H[v,ℓ]) ∧ (∨c∈Match(v,Sf) A[v,c]) )`
  - **义务编码**（如“通过测试后才允许提交”）：`A[v, commit] ⇒ Seen(tests_passed, v)`
- **有限图完备性**：对合法化的有限权限图，若能力分配可满足则严格满足所有策略规则；否则返回精确违反路径（含违反节点、标签、汇点、污染路径）。
- **污点单调安全性**：G ⪯ₜ G′（仅污点追加扩展）时，在G上被拒绝的动作在G′上必然被拒绝；可靠信息加入只会保留或引入冲突，不会消解既有冲突。

**（4）运行时网关与单调修复（Monotonic Runtime Repair）**
- 运行时事件**严格追加**新节点、边、标签和证据；既有安全约束永不静默丢弃。
- 在任何有效操作执行前，**JIT（刚好及时）运行SMT授权器**；若有反例→`block`并展示违反路径；若无违规且IR标记为良性→`allow`；若风险姿势为`sensitive/dangerous/ambiguous`→**默认失败关闭（fail-closed）**。

### 2.3 安全假设
- 所有安全相关的运行时效应必须在执行前由网关中介；
- 后端执行必须“能力一致”（可能比求解器更严格，但绝不超出授予集合）；
- 策略翻译与脱敏器规范属于可信计算基（TCB）。

## 6. 主要结论与发现

1. **整体效果**：FAVA在801例全量矩阵上达到 **90.5% DCR**；在ActPlane Public与ActPlane Traces上均达 **100% DCR**（0 FP / 0 FN）；OctoBench为90.8%，OpenAgentSafety为84.4%。
2. **解决二极困境**：
   - Regex Guard和ActPlane严重**过度拦截**（Regex在OpenAgentSafety上TN=0，把合法动作全拦了）；
   - GuardAgent和AgentSpec严重**欠拦截**（OctoBench上FN高达191和189，因不追踪污染数据流而“语境失忆”）。
3. **组件归因（消融）**：
   - **去掉证据标签**杀伤力最大——OctoBench从90.8%降至7.4%（图退化为无约束结构）；
   - **去掉数据流边 ≡ 去掉SMT授权**——均降为25.8%（OctoBench）/61.6%（OAS），证明局部启发式无法替代全局约束推理；
   - **去掉运行时网关**：轨迹条件集100%→40%，隔离了在线JIT拦截的不可替代性。
4. **效率结论**：形式化验证不构成执行瓶颈，运行时每步授权亚毫秒级。
5. **失败归因**：76个不匹配中——过度标记（39.4%）、安全关键词误触发（27.7%）、受保护标签缺失（26.6%）、维护误判为破坏（3.2%）、不可信过度传播（3.2%）。数学授权边界本身稳健，未来应优化**溯源感知的语义提取**与**精准sink范围界定**，而非修改SMT决策规则。

## 7. 优点与亮点

- **架构理念清晰**：将“LLM擅长但不可信”的语义理解与“可信但需结构化输入”的形式验证解耦，避开了两个天然的不可靠环节；这一“语义提取/数学强制”二分法是该领域的一个优秀设计模式。
- **形式保证有明确定界**：明确限定保证始于权限图构建之后（不声称覆盖上游语义提取），不夸大适用范围（承认不论及隐式数据流），表述诚实。
- **单调安全性质**：首次明确利用“污点单调性”保证失败关闭策略的数学合理性——污染信息只会加深拒绝，不会翻转既有决策。
- **反例可解释性**：SMT失败的二次求解可映射回违反“节点-标签-汇点-污染路径”，直接对接证据，便于审计。
- **效率设计精巧**：以**有限前缀图 + 局部标签传播**编码代替物化传递闭包，使运行时求解亚毫秒级；
- **实验设计全面**：从四个不同侧面的数据集、7+个基线、到含组件归因/后端泛化/效率/失败模式的五组RQ，覆盖较完整。

- **尽力重实现的基线可信度有限**：AuthGraph与SafeAgent没有公开实现，由作者自行复现；这类重实现容易因接口推测偏差而低估原系统的实际效果，从而放大FAVA的相对优势。
- **数据集规模与真实性局限**：801个任务中相当部分来自合成或标注场景，真实生产环境的恶意输入分布、复杂多步攻击语料等并未覆盖；轨迹条件集被作者自述为“labeled diagnostic”，其泛化结论需要更真实条件下的验证。
- **缺乏失败成本的差异化考量**：所有误判（FP/FN）被同等计权，但现实中“放行一次危险删除”与“拦截一次合法查询”的代价差异巨大；论文没有引入不同违规类型的分层风险评估或成本敏感评价。

## 9. 未来工作方向

- **语义提取的鲁棒化与可证明化**：将证据跨度抽取、意图分类与sink识别纳入可验证管道（如通过可解释分类器、规则校验器或更严格的IR模式约束），缩小“LLM不可信区间”；或引入主动澄清机制，在IR置信度不足时向用户/管理员请求确认，而不是静默接受。
- **扩展隐式流与上下文感知建模**：探索利用程序分析（如taint analysis）与系统调用级追踪来捕获间接数据流，将权限图从“工具调用轨迹”扩展到“真实数据血缘”，以削弱被构造的旁路绕过风险。
- **策略语言的工程化**：设计面向策略管理员的高层DSL，并配套编译器将DSL自动降级为SMT约束；减少手工翻译错误，使FAVA的可证明性向上游策略定义层延伸。
- **多步规划的预防性授权**：当前机制是每步JIT授权，对未来规划路径中的潜在危险缺乏全局预判；未来可结合规划中的IR序列进行前向模拟，实现“计划级预授权”与“执行级复核”的双层闸门。
- **失败分类与自适应缓解**：对过度标记、关键词误触发等失败模式，学习调整标签传播的保守度或sink定义范围（如允许用户自定义“可信sink”名单），在维持安全底线的前提下降低误拦率。
- **更广泛的生产部署验证**：在真实企业agent工作流、多租户环境与对抗性攻击压力下进行长期评估，测试策略更新热加载、审计日志追溯与FAVA与现有IAM系统的集成方式。

## 10. 总体评价

FAVA的核心贡献不是“又一个更聪明的guard”，而是提出了一个清晰、可辩护的系统架构原则：**语义层负责理解，数学层负责裁决**。它将授权问题拆解为“如何描述上下文”与“如何检验上下文约束”两个相对独立的子问题，前者交给LLM（承认其不确定性），后者交给SMT（保证其决定性），并以权限图作为两者之间简洁而完备的契约。这种分工在理论上消解了“既要求LLM灵活性、又要求安全可证性”的深层矛盾。

从工程视角看，FAVA的落地友好度也值得肯定：亚毫秒级运行时授权、单调修复保证不翻转既有决策、失败时给出可审计的违反路径——这些设计直接回应了生产环境中“安全系统不能成为性能瓶颈、不能制造新的不确定性”的现实诉求。

但其最本质的局限在于：**整条链路的可信度仍然始于一次不可信的LLM幻觉**。权限图之后的一切都牢不可破，而权限图本身的质量却悬于提示词工程与模型即时状态之上。从这个意义上说，FAVA不是一个完整的安全解决方案，而是一个优秀的安全“验证内核”——它以严谨的数学将不确定性的影响范围压缩到最小、并使其显式可见，但并未也不可能消除那一层根本的不确定性。这一诚实的边界，恰恰是它作为学术贡献最值得尊重的地方。

**一句话概括**：> FAVA用“证据支持权限图+SMT求解”为LLM智能体的运行时授权构建了一个可解释、可证明、高效率的数学内核，但安全性的天花板仍取决于上游语义提取的可靠性——它优雅地驯服了不确定性，却无法彻底消灭它。
