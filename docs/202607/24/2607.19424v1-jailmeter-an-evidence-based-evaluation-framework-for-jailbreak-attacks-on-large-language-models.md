## 摘要
目前，针对大型语言模型的越狱攻击评估存在标准和方法不一致的问题，导致攻击成功率的估计不可靠。我们提出JailMeter，一种基于证据的评估框架，旨在更忠实地衡量越狱效果。受信息瓶颈理论启发，JailMeter应用双反馈优化，从模型响应中过滤越狱噪声，同时保留与原始恶意问题相关的内容。这一过程产生简洁的证据，用于严格评估：只有当响应捕捉到恶意意图并给出完整答案时，攻击才被认定为有效，从而表明模型安全对齐被实质性绕过。我们在JailMeter-Eva上评估JailMeter，这是一个包含330个人工标注、未被拒绝越狱实例的具有挑战性的基准测试。JailMeter达到了97.27%的准确率，显著优于现有评估方法。为了支持大规模评估，我们进一步将JailMeter蒸馏成一个小型语言模型JailMeter\textsubscript{SLM}，它在显著降低计算成本的同时保持了可比的可靠性。代码和数据集可在https://github.com/Magi2B0y/JailMeter获取。

## Abstract
The assessment of jailbreak attacks against large language models currently suffers from inconsistent evaluation criteria and methods, leading to unreliable estimates of attack success rates. We propose JailMeter, an evidence-based evaluation framework designed to more faithfully measure jailbreak effectiveness. Inspired by the Information Bottleneck theory, JailMeter applies dual-feedback optimization to filter jailbreak noise from model responses while preserving content relevant to the original malicious question. This process produces concise evidence for a rigorous assessment under which an attack is validated only when the response captures the malicious intent and delivers a complete answer, thereby signaling a substantive bypass of model safety alignment. We evaluate JailMeter on JailMeter-Eva, a challenging benchmark containing 330 human-labeled, non-rejected jailbreak instances. JailMeter achieves an accuracy of 97.27%, substantially outperforming existing evaluation methods. To support large-scale evaluation, we further distill JailMeter into a small language model, JailMeter\textsubscript{SLM}, which maintains comparable reliability with significantly reduced computational costs. Code and dataset are available at https://github.com/Magi2B0y/JailMeter.

## 1. 核心问题与整体含义（研究动机和背景）

当前，针对大型语言模型（LLM）的越狱攻击评估存在严重不一致性：不同研究使用截然不同的评估标准（如毒性分数、危害性分数、是否违反安全策略等）和评估方法（关键词匹配、RoBERTa分类器、Llama Guard、LLM Judge等）。这种碎片化导致同一越狱方法在不同论文中汇报的攻击成功率（ASR）相差甚远。更关键的是，许多评估方法容易被越狱方法引入的“越狱噪声”（extra content无关原始恶意问题）干扰，难以准确判断攻击是否真正成功。论文指出，从安全对齐的角度看，一个成功的越狱攻击应该使模型像回答良性问题一样，完整且直接地满足恶意请求的意图。因此，需要一个统一、可靠且可解释的评估框架来更忠实地衡量越狱有效性。

## 2. 方法论：核心思想、关键技术细节

**核心思想**：受信息瓶颈（Information Bottleneck, IB）理论启发，将证据提取视为语义压缩任务：从模型响应中过滤越狱噪声，保留与原始恶意问题最相关的信息，形成简洁证据集，然后基于此判断攻击是否成功。成功标准：响应捕捉恶意意图并提供完整答案。

**关键技术细节**：
- **多智能体框架**：
  - **SentenceSegmentation Agent (A_seg)**：将模型响应分割为语义块。
  - **Extraction Agent (A_ext)**：根据IB原则提取与原始问题相关的子集E_t。
  - **Relevance Agent (A_rel)**：评估E_t是否充分满足原始问题，给出推理z_rel和分数s_rel（0~1）。
  - **Conciseness Agent (A_con)**：评估E_t相对于完整响应S的简洁性，给出分数s_con。
  - **Evaluation Agent (A_eva)**：基于最终最优证据E*进行最终判断，输出推理z和标签l（0/1）。
- **双反馈优化**：每轮迭代中，A_ext根据A_rel和A_con的反馈（F_t）优化证据集。计算复合质量评分 `Quality_score = s_rel - β(1 - s_con)`，当不再提升时终止。β为平衡参数（推荐0.5）。
- **蒸馏模型 JailMeter_SLM**：使用多智能体知识蒸馏，将JailMeter的完整轨迹（包括CoT推理）蒸馏到Qwen2.5-7B-Instruct中，通过LoRA微调。输入为(原始问题，模型响应)，输出结构化结果（思考过程、证据、推理、标签），一次前向推理完成，大幅降低延迟和成本。

**算法流程（文字说明）**：
1. 将响应分割成语义块。
2. 初始提取证据E_0。
3. 循环迭代（最多t_max次）：
   - 计算当前质量评分。
   - 若评分不再提升或达到最大次数，终止。
   - 否则，A_rel和A_con生成反馈，A_refine根据反馈更新证据。
4. 最终证据E*交由A_eva评估，输出标签和推理。

## 3. 实验设计

**数据集**：
- **JailMeter-Eva**：作者构建的挑战性基准，包含330个人工标注的、未被明确拒绝的越狱实例（排除包含“I'm sorry”等拒绝短语的样本），覆盖6类恶意问题（骚扰、仇恨、非法、自残、性、暴力），来自11种越狱方法攻击60个原始问题（共660个攻击载荷，过滤后保留330个）。标注标准：模型正确理解意图并给出完整、清晰、切题的回答为成功（1），否则为失败（0）。人工标注一致性达0.86（Fleiss Kappa）。
- **BenignInstructions**：100个良性指令及其GPT-4响应，全部标注为成功（1），用于验证方法对良性指令的正确判定。

**评估方法（Baselines）**：共8种，分为两类：
- 来自越狱攻击论文的评估方法：DAN（LLM二分类）、I-FSJ（Llama Guard）、ADC（微调Llama-2-13B分类器）、CodeAttack（LLM评分）、PastTense（LLM评分）。
- 来自越狱基准测试的评估方法：HarmBench（LLM Judge）、StrongREJECT（三维度评分）、JailbreakRadar（激进预判）。

除ADC和I-FSJ使用专用模型外，其余统一采用GPT-4o-mini作为评估模型（温度=0）。JailMeter也使用GPT-4o-mini作为所有智能体的骨干模型。JailMeter_SLM使用微调的Qwen2.5-7B-Instruct。

**对比指标**：准确率、精确率、召回率、F1分数。

**消融实验**：
- JailMeter变体：仅采用A_eva、无A_rel和A_con、无A_con、无A_rel、完整JailMeter。
- JailMeter_SLM变体：无微调、无CoT的SFT、包含CoT的SFT。

**额外分析**：在不同骨干模型（GPT-3.5-Turbo、GPT-4o-mini、GPT-4o、GPT-5.1）上测试其他评估方法的表现；对11种越狱方法在12个目标模型（4个Llama系列、8个GPT系列）上重新评估ASR；效率与成本对比。

## 6. 主要结论与发现

- **JailMeter显著优于现有方法**：在JailMeter-Eva上准确率97.27%，F1 93.88%，远高于第二名ADC（80.30%准确率、65.61% F1）。
- **蒸馏模型JailMeter_SLM接近原框架性能**：准确率95.15%，F1 89.19%，同时大幅降低计算成本（约12倍Token减少，延迟从54s降至19s）。
- **现有评估方法存在严重不一致与偏差**：不同方法在同一数据集上的准确率从29.09%到80.89%不等，且受骨干模型能力影响大（StrongREJECT在GPT-5.1上甚至精度/召回率为0），凸显统一评估标准的重要性。
- **越狱攻击的实际成功率低于过往报告**：通过重新评估发现，许多方法因“语义漂移”（优化后提示偏离原始恶意意图）而导致模型看似响应但实际未完成要求，JailMeter能正确将其识别为失败。
- **双反馈优化和迭代证据提取是关键**：消融实验表明，迭代优化（特别是同时考虑相关性和简洁性）比单轮或缺少某代理显著提升性能；CoT蒸馏进一步提升SLM效果。

## 7. 优点

- **基于信息瓶颈理论**：将评估问题形式化为语义压缩与保留，理论基础扎实。
- **可解释性强**：输出最终证据集和推理过程，支持人工审计，透明度高。
- **多智能体协同**：分解任务（分割、提取、相关评估、简洁评估、最终判断），降低对单个LLM能力的依赖，鲁棒性好。
- **统一评估标准**：从安全对齐本质出发，明确成功定义为“完整满足恶意意图”，消除了标准模糊性。
- **大规模效率解决方案**：蒸馏为SLM后，保留大部分性能，显著降低成本和延迟，便于实际部署。
- **实验设计较为全面**：涵盖消融、参数分析、骨干模型敏感性、大规模重评估，验证了框架的稳健性和实用性。
- **公开数据和代码**：便于复现和后续研究。

## 8. 不足与局限

- **缺乏多模态支持**：当前仅支持纯文本越狱场景，无法处理图像、音频等模态的输入或输出。
- **易受针对评估器的攻击**：依赖模型评估器，可能被专门误导评估过程的对抗行为（如操控中间证据、利用输出格式）所欺骗。
- **数据集规模有限且单一**：JailMeter-Eva仅包含330个样本，且来源限于GPT-4o-mini的响应，可能无法完全代表所有越狱攻击和模型的复杂情况。外部泛化性需更多验证。
- **骨干模型依赖性**：实验表明不同骨干（GPT-4o-mini vs. GPT-4o vs. Gemini）存在评估偏差（如Gemini偏保守、GPT-4o偏激进），JailMeter选择GPT-4o-mini虽平衡但非最佳情况。
- **未探索其他蒸馏或优化策略**：仅使用了LoRA微调Qwen2.5-7B，可能不是最优的SLM选择；未来或可尝试更小模型或不同训练策略。
- **伦理风险**：尽管作者声明为安全研究，但公开的评估框架理论上可被用于优化越狱攻击，存在双重用途风险。
- **成本考虑**：JailMeter每次评估需多次调用API（平均10.1次），即使使用较便宜的模型，大规模场景下成本仍可累积；蒸馏版本有效缓解，但需额外训练成本。
