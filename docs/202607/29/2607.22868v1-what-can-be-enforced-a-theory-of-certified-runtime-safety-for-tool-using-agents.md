## 摘要
运行时护栏在不可逆工具调用之前发挥作用，但其保证取决于可表征的策略状态、法官的观测内容以及干预是否会改变未来行为。我们区分三个问题。首先，相对于固定的预言谓词，确定性门限强制执行恰好是那些其寄存器模型能识别良好前缀的非空安全策略；策略非平凡性在具有两个可递减计数器时不可判定，但对于可分离单调片段则属于PSPACE。其次，在固定外生规律下，奈曼-皮尔逊方法给出了精确的误阻/漏报边界，而共形校准给出了有限样本边际证书（可能通过全阻策略实现）。第三，一旦阻截改变了未来提议，静态分数和无门控轨迹不一定能识别闭环边界；相反，一个特定的有限受控模型会产生一个占用程序。有界表示攻击增加了鲁棒性余量，因此仅凭良性校准无法转移。实验通过静态诊断、受控模型枚举、表示重写和配对的闭环重演来针对这些区分。

## Abstract
Runtime guardrails act before irreversible tool calls, but their guarantees depend on what policy state is representable, what a judge observes, and whether intervention changes future behavior. We separate three questions. First, relative to fixed oracle predicates, a deterministic gate enforces exactly the nonempty safety policies whose good prefixes its register model recognizes; policy nontriviality is undecidable with two decrementable counters but in PSPACE for a separable monotone fragment. Second, under a fixed exogenous law, Neyman-Pearson gives the exact false-block/miss frontier and conformal calibration gives a finite-sample marginal certificate, possibly via block-all. Third, once blocking changes future proposals, static scores and ungated trajectories need not identify the closed-loop frontier; a specified finite controlled model instead yields an occupancy program. Bounded representation attacks add a robustness margin, so benign calibration alone does not transfer. Experiments target these distinctions through static diagnostics, controlled-model enumeration, representation rewrites, and paired closed-loop reruns.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **背景**：随着大语言模型（LLM）智能体越来越多地通过工具调用（发送邮件、转账、编辑文件等）在真实世界中行动，运行时护栏（runtime guardrails）被广泛部署——它们在不可逆操作执行前检查并拦截/改写/升级提议。然而，这些护栏的保证依赖于三个未完全澄清的前提：策略状态是否可被准确表示、法官（judge）能观察到什么、以及干预是否会改变未来的行为提议。
- **核心问题**：哪些安全策略可以被运行时护栏强制执行？在什么条件下？其代价（效用损失）有多大？当决策改变后续提议时，静态的接收者操作特征曲线（ROC）分析是否仍然有效？
- **整体含义**：本文系统性地分离并回答了三个独立的问题：（T1）**表示与可能性边界**——在固定预言谓词接口下，确定性门控能强制执行哪类策略；（T2）**统计与序贯边界**——在外生静态决策下，最佳的安全-效用权衡由Neyman-Pearson理论确定，而在决策影响未来提议的闭环中，静态ROC失效，需用受控过程模型；（T3）**可判定性边界**——策略规范的非平凡性（是否存在违规行为）在通用计数器模型下不可判定，但在可分离单调片段（如限额、撤销）中可在多项式空间内判定。论文旨在为现有机制（如AgentSpec、Shield、CaMeL等）提供理论基础，指出其适用边界和局限性。

### 2. 论文提出的方法论：核心思想、关键技术细节

- **方法论整体框架**：将运行时安全认证分解为三个独立的理论问题，分别对应不同的数学工具：
  - **T1（Oracle表征定理）**：对于非空策略 \(P\)，存在一个确定性 \((T;\Pi)\)-门控（寄存器自动机 + 预言谓词接口）能有效强制执行 \(P\) 当且仅当 \(P\) 是安全属性且其良好前缀语言 \(Good(P)\) 属于该类自动机可识别的语言类。证明通过构造：模拟自动机，拒绝会导致进入吸收坏状态的动作。这严格弱于编辑自动机（edit automata）能强制执行的非安全类。
  - **T2（统计与序贯边界）**：
    - **外生决策**：固定一步实验，假设法官评分 \(s\) 和标签分布已知，则所有可测量的决策规则中，最优的安全-效用边界由Neyman-Pearson引理确定：最小误阻概率 \(B^\star_I(\beta) = \text{roc}_I(\beta)\)（ROC边界），且该值是下界。
    - **共形校准**：在标签条件可交换性假设下，使用共形风险控制（conformal risk control）校准阈值，可提供有限样本的边际风险保证：\(\mathbb{E}[\text{unsafe episode}] \le \delta\)。若每步独立，则联合界需要除以 H（步数）；若使用整集校准则无需此因子。
    - **闭环（受控过程）**：当阻截改变后续提议时，静态ROC不能识别闭环边界。引入有限受控模型（有限抽象状态、完美回顾历史、转移核依赖门控决策），通过信念状态占用度量的线性规划精确描述可达性能凸多边形，其下确界由至多两个确定性信念-马尔可夫策略混合实现。
  - **T3（可判定性边界）**：提出一个可判定且表达能力强的守卫理论片断 \(T_0\)，包含有限确定性E组件（等式寄存器）、K组件（每个密钥独立单调计数器）和V组件（固定有限向量单调计数器）。通过精确上限饱和（cap saturation）和单见证投影（one-witness projection），坏前缀可达性在PSPACE内，在线执行时间为多项式。而若引入两个可递减计数器（双计数器Minsky机模拟），则非平凡性不可判定。
- **关键技术细节**：
  - **门控定义**：可计算映射 \(g: (A\backslash\{\bot\})^* \times A \times [0,1]^m \to \{\text{allow}, \text{block}, \text{sub}\}\)，用于不可逆动作提交前。
  - **法官模型**：地面真值谓词 \(\pi_i\)，近似法官 \(\hat{\pi}_{\theta_i}\) 通过阈值 \(\theta_i\) 将风险分数 \(s_i\) 二值化，其错误率 \(\alpha_i(\theta_i), \beta_i(\theta_i)\)。
  - **对抗性鲁棒性**：定义 \(p\)-预算对手可修改法官可见表示 \(z\) 至多 \(p\) 步（如插入 token），但保持可执行动作和真实标签不变。良性和部署之间的条件漏报增加 \(\eta(p;\theta)\)，校准后的风险上界变为 \(\delta + H\bar{\eta}(p)\)。稳健校准需将目标收紧 \(\delta/H - \bar{\eta}(p)\)。

### 6. 论文的主要结论与发现

- **T1**：确定性门控恰好强制执行那些良好前缀语言可用寄存器自动机识别的非空安全属性。该类比编辑自动机严格弱——例如“每次付款后必须有确认”是不可逆门控无法执行的。
- **T2**：对于固定外生决策，ROC边界是精确的，且通过可能性比检验可达。然而，一旦门控改变未来提议，静态ROC不能识别闭环边界；必须使用受控有限模型才能获得真实前端。共形校准可提供有限样本边际证书（可能通过全阻），但对抗性表示攻击会引入鲁棒性余量 \(H\bar{\eta}(p)\)，良性校准无效。
- **T3**：具有两个可递减计数器的策略非平凡性不可判定（等价于Minsky机停机问题）；但可分离单调片段（限额、撤销等）的非平凡性可在PSPACE内判定，且在线执行时复杂度多项式。
- **实验结论**：
  - 23法官的AUC范围 0.660–0.858，无模型在家族族误差控制下优于Gemma-2-9B（仅Llama-3.1-8B被判定显著更差）。
  - 表示攻击（16 token 后缀）使8/11法官在固定阈值0.5下的漏报增加0.2–0.6，同时置信区间排除零。
  - 闭环：3B门控将攻击成功率从4.7%降至0.4%（McNemar p=2.4e-6），但通过阻截78%的调用实现；7B门控仅阻截12%，效果不显著（p=0.09）。且门控创造了新的攻击（5个门控-only discordant pair）。
  - 有限模型枚举显示：完美回顾策略在 δ=0.05 时成本0.551，显著优于当前分数+时间策略（0.863）和固定阈值（1.137）。

### 7. 优点

- **理论贡献明确**：分离了三个原本纠缠的问题（表示、统计、动态），每个问题给出精确边界，避免了跨场景的泛化谬误（如将静态ROC结论错误地用于闭环环境）。

### 8. 不足与局限

- **实验覆盖不足**：
  - 静态诊断仅使用指令文本，缺乏完整历史上下文，可能低估真实场景下法官的辨别能力（或相反）。
  - 闭环只在单一本地智能体（7B）、三种策略下测试，无法推广到不同规模/类别的智能体或更丰富的策略类。
  - 表示攻击仅评估一种有限模板（16-token 后缀），无法为一般鲁棒性上界提供证据。
- **假设强度限制**：
  - 共形证书依赖于标签条件可交换性（对抗部署时无效）；稳健校准需要已验证的均匀余量 \(\bar{\eta}(p)\)，但论文并未提供验证方法。
  - 有限受控模型需要已知抽象（状态、转移）——实际中不可得时，定理无法直接应用。
- **小样本问题**：多个基准中合规/违规样本极少，导致共形校准退化为全阻或置信区间极宽，无法断定实际效果。
- **仅推理无训练**：所有法官是黑箱评分，未探索微调以改善ROC，也未分析不同提示策略的影响。
- **未解决开放问题**：精确的多元谓词区域（m≥3）、信息增益的定量规律、数据驱动的鲁棒证书等均未涉及。
- **风险偏见**：虽然作者声明为防御性工作，但展示了“白色脱敏”攻击，可能被滥用。
