## 摘要
机器学习工程（MLE）任务需要在迭代的解决方案调试与改进过程中进行长视野决策，且环境交互昂贵且反馈驱动。为这类任务开发和训练单一智能体从根本上具有挑战性，因为它必须同时管理极长且嘈杂的上下文、探索庞大的解决方案空间，并在有限的模型容量和计算预算下保持有效性。为应对这些挑战，我们提出了Matryoshka智能体，一个用于复杂长视野任务的统一分层智能体框架。Matryoshka智能体将智能体问题求解分解为决策与执行的协调层级：高层编排器维护紧凑的长视野探索状态并发布战略指令，而低层子智能体通过直接环境交互执行具体解决方案尝试，并由标准化工具接口中介。这种设计将战略探索与昂贵执行解耦，大幅减轻长上下文推理负担，并实现高效的迭代精炼。我们进一步开发了适用于Matryoshka智能体的高效训练范式。在多种模型类型和规模的大量MLE任务上的实验结果表明，Matryoshka智能体是长视野MLE任务和复杂智能体问题求解的有效且可扩展的范式。值得注意的是，Matryoshka智能体使Qwen3-4B-Instruct达到了与o4-mini相当的编排器性能。将Matryoshka智能体应用于Qwen3-30B-Coder可实现最多36.7%的相对性能提升。

## Abstract
Machine learning engineering (MLE) tasks require long-horizon decision making over iterative solution debugging and refinement, under expensive and feedback-driven environment interactions. Developing and training a monolithic agent for such tasks is fundamentally challenging, as it must simultaneously manage extremely long and noisy contexts, explore vast solution spaces, and remain effective under limited model capacity and computational budgets. To address these challenges, we propose Matryoshka Agent, a unified hierarchical agent framework for complex long-horizon tasks. Matryoshka Agent decomposes agentic problem solving into a coordinated hierarchy of decision making and execution: a high-level Orchestrator maintains compact, long-horizon exploration states and issues strategic instructions, while lower-level Sub-Agents execute concrete solution attempts through direct environment interaction, mediated by standardized Tool interface. This design decouples strategic exploration from costly execution, substantially reducing the burden of long-context reasoning and enabling efficient iterative refinement. We further develop an efficient training paradigm for Matryoshka Agent. Experimental results on a broad range of MLE tasks with diverse model types and scales demonstrate that Matryoshka Agent is an effective and scalable paradigm for long-horizon MLE tasks and complex agentic problem solving. Notably, Matryoshka Agent enables Qwen3-4B-Instruct to reach Orchestrator performance comparable to o4-mini. Applying Matryoshka Agent to Qwen3-30B-Coder results in at most 36.7% relative performance gain.

- **单体智能体的困境**：传统单体（monolithic）智能体需要同时处理不断累积的超长上下文、探索巨大的方案空间，并受限于模型容量和计算预算，因此很难在长视野MLE任务中取得稳定性能。
- **核心动机**：作者提出，将"战略决策"与"具体执行"解耦，是应对长视野复杂智能体任务的关键方向。
- **整体含义**：本文提出的 **Matryoshka Agent** 是一种统一的分层智能体框架，通过"编排器（Orchestrator）+ 子智能体（Sub-Agent）+ 工具接口（Tool）"的三层结构，将长视野问题求解拆分为决策与执行两个层级，为复杂MLE任务提供了一种高效、可扩展的范式。

## 2. 方法论

- **框架结构**：
  - **Orchestrator（高层决策层）**：维护紧凑的跨轮状态（历史指令、结果摘要、得分），决定下一轮要探索或精炼的解决方案方向；不直接接触原始代码、执行日志或调试痕迹。
  - **Sub-Agents（低层执行层）**：由编排器的指令实例化，拥有独立的全新上下文，通过直接与环境交互实现代码生成、执行、调试和提交评估，并在有限调试预算内完成一次具体方案尝试。
  - **Tool（中介层）**：标准化编排器与子智能体之间的通信——将编排器指令转换为子智能体上下文、注入选定的参考方案、启动子智能体、返回结构化摘要和分数。
- **推理时逻辑**：编排器每次发出一个工具调用，指定"要精炼的父尝试、新的实现指令、可选的参考尝试"；工具层据此构造子智能体环境并运行；执行结束后返回紧凑结果，追加到编排器历史中，用于后续决策。
- **训练范式——Solution Refinement Tree**：
  - 构建树状采样：从根状态出发，当前编排器策略在非叶节点采样两个不同精炼指令，分别由子智能体执行，形成两个孩子节点，依此类推。
  - 使用**分支级下游回报**构造偏好：对内部节点，比较两个子分支子树内的最大分数，更高者作为偏好继续方向。
  - 在线强化学习目标：使用基于排序的NCE损失，优化编排器策略。在能量函数形式下，将轨迹分数参数化为新策略与参考策略的对数比值：  
    \( r_\theta(s_u, \Delta\tau) = \beta \log \frac{\pi_\theta(\Delta\tau|s_u)}{\pi^{(m)}(\Delta\tau|s_u)} \)  
    损失函数为对每个分支状态最大化偏好连续的对数概率。该设计使更新始终锚定于先前策略，避免训练震荡。
- **子智能体自我强化**：从最高得分的精炼路径中提取子智能体的成功轨迹，进行监督微调（SFT），提升其指令遵循能力和调试鲁棒性。

## 3. 实验设计

- **数据集 / 基准**：
  - 使用 **MLE-Dojo** 基准，包含 200 个端到端 Kaggle 风格MLE任务，采用官方划分：150 个训练任务、50 个评估任务。
  - 评估任务分为四类：**MLE-Lite（21个）、Tabular（10个）、CV（9个）、NLP（10个）**，覆盖表格、视觉、文本等多种模态与目标。
- **评估指标**：
  - **HumanRank**：表示智能体在排行榜上超越的人类参赛者比例，范围 [0,1]，取公共与私有榜单得分的平均值。
- **对比方法 / 模型**：
  - 基线：**Dojo Agent**（MLE-Dojo提供的单体智能体）。
  - 模型组合：Qwen3-4B-Instruct-2507、Qwen3-Coder-30B-A3B-Instruct、o4-mini、GPT-5-nano，以及这些模型的SFT/RL变体。
  - 对比格式：Model A + Model B，A为编排器，B为子智能体；"+ self"表示相同模型同时担任两者。
- **训练设置**：
  - 用 gemini-2.5-flash 收集 100 个完整Matryoshka Agent轨迹作为SFT数据；对Qwen3-4B仅训练编排器，对Qwen3-Coder-30B同时训练编排器和子智能体。
  - 在线RL在SFT基础上进行，Qwen3-4B-RL 与 o4-mini 配对，Qwen3-Coder-30B-RL 同时作为编排器和子智能体。
- **推理设置**：每个任务、每个配置最多 12 小时执行时间，每轮子智能体最多 10 次调试迭代；每个配置运行 3 次平行试验，取最佳成绩作为最终结果。

## 6. 主要结论与发现

- **分层框架有效**：Matryoshka Agent 在无需额外训练的情况下就能提升模型表现（如 Qwen3-30B-Coder 从 0.3302 提升至 0.3652）。
- **训练协同收益**：SFT 和在线 RL 均能增强编排器决策能力；Qwen3-30B-Coder-RL + self 达到 0.4515，相对 Dojo Agent 基线提升最高 **36.7%**。
- **小模型可作为强编排器**：Qwen3-4B-RL 作为编排器搭配 o4-mini 子智能体达到 0.5360，与 o4-mini 作为编排器的 0.5465 几乎持平，说明小模型在决策层具有巨大潜力。
- **子智能体规模敏感性**：小模型作为子智能体时指令遵循能力明显不足，导致执行失败率升高，体现编排器与执行器在能力要求上的不对称性。
- **Plug-and-Play 泛化**：RL 训练后的编排器即使搭配训练时未见的子智能体（GPT-5-nano），也能带来稳定性能提升。
- **上下文优势**：编排器上下文增长斜率（约 1201.9 tokens/轮）低于单体 Dojo Agent（约 1870.3 tokens/轮），子智能体上下文保持恒定，使得在相同上下文预算下可支持约 213 轮 vs 137 轮，显著提升长视野可扩展性。

## 7. 优点
