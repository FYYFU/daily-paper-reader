## 摘要
记忆系统在提升智能体性能方面展现出潜力，但其在小语言模型中的潜力仍未得到充分挖掘，因为小模型难以自行生成足够的成功轨迹。我们提出了Agent记忆蒸馏（AMD），一种无需训练框架，通过层级记忆将大型教师智能体的结构化知识迁移至小型学生智能体。AMD从成功的教师轨迹中构建三种互补的记忆类型：工作流记忆编码任务级策略，子任务记忆提供中间粒度的具体行为示例，函数记忆捕获每个函数的调用约定与常见陷阱。工作流记忆和子任务记忆在每项任务开始时主动注入，而函数记忆则在工具调用出错时被动检索。我们使用四个学生模型（4B-8B参数）在三个工具使用基准上评估AMD，以GPT-5-mini作为教师，在AppWorld、BFCL V3和ToolSandbox上分别实现了27.2个百分点、11.2个百分点和3.4个百分点的平均准确率提升，并持续优于现有的基于记忆的基线方法。进一步分析表明，子任务记忆贡献了最大的增益，教师效果取决于教师能力与学生兼容性，且4B规模的学生从AMD中获益最多。

## Abstract
Memory systems have shown promise for improving agent performance, but their potential remains largely unexplored for small language models, which struggle to generate sufficient successful trajectories on their own. We propose Agent Memory Distillation (AMD), a training-free framework that transfers structured knowledge from a large teacher agent to a small student agent through hierarchical memory. AMD constructs three complementary memory types from successful teacher trajectories: Workflow memory encodes task-level strategies, Subtask memory provides concrete behavioral examples at an intermediate granularity, and Function memory captures per-function calling conventions and common pitfalls. Workflow and Subtask memories are injected proactively at the start of each task, while Function memory is retrieved reactively upon tool-calling errors. We evaluate AMD on three tool-use benchmarks using four student models (4B-8B parameters) with GPT-5-mini as the teacher, achieving average accuracy gains of 27.2%p, 11.2%p, and 3.4%p on AppWorld, BFCL V3, and ToolSandbox, while consistently outperforming existing memory-based baselines. Further analysis shows that Subtask memory contributes the largest gains, teacher effectiveness depends on both teacher capability and student compatibility, and 4B-sized students benefit most from AMD.

- 为此，本文提出**Agent Memory Distillation（AMD）**，通过层级化、多粒度的记忆组织方式，让教师知识对小模型变得可理解、可执行。

## 2. 方法论

**核心思想：** 从教师智能体的成功轨迹中构建三种互补的层级记忆类型，分别覆盖任务级规划、子任务级执行示例和函数级调用知识，通过主动注入与被动检索相结合的方式指导学生推理。

**三种记忆类型：**

- **Workflow Memory（工作流记忆）**：编码任务级整体完成策略，以自然语言概括教师的高层思路，包含涉及的apps和工具、关键前置条件、决策规则、验证线索和常见失败模式；具体运行时值用类型化占位符（如`<ID>`、`<EMAIL>`）替换以保证泛化性。
- **Subtask Memory（子任务记忆）**：将教师轨迹分割成语义连贯的子任务片段，每个片段包含具体可执行的工具调用/代码及对应观测，并配有简短标签和描述；粒度介于高层规划与底层调用之间，为学生提供可直接参照的中间层行为示例。
- **Function Memory（函数记忆）**：按函数名索引的细粒度工具调用知识，包含函数名、教师的具体调用示例、上下文及可选的API文档参数/响应模式。

**检索与注入策略：**

- **主动注入（Proactive Injection）**：任务开始时，用任务指令检索top-1 Workflow记忆注入系统提示；学生先将任务分解为最多6个子任务标签，用每个标签独立检索top-1 Subtask记忆并去重后注入系统提示。
- **被动注入（Reactive Injection）**：仅在工具调用返回错误时，按失败函数名检索top-1 Function记忆，附加到错误消息中提供针对性修正指导，不增加成功执行时的上下文负担。

**算法流程（文字描述）：**

1. 任务开始前，用任务指令检索Workflow记忆并注入系统提示。
2. 学生将任务分解为子任务标签序列。
3. 每个子任务标签作为查询检索Subtask记忆，去重后注入系统提示。
4. 进入执行循环：当上一步观测包含错误时，提取失败函数名，从Function记忆库中检索对应示例并注入上下文；学生生成工具调用；执行并获得观测；重复直到任务完成或达到最大步数（40步）。

## 6. 主要结论与发现

1. **AMD显著提升小模型智能体的性能**：三个基准上平均准确率增益分别为+27.2%p（AppWorld）、+11.2%p（BFCL V3）、+3.4%p（ToolSandbox），一致优于所有基线。三个基线效果不稳定，甚至多次低于zero-shot，说明朴素或结构不当的记忆迁移对小模型有害。
2. **小模型可以达到甚至超越教师水平**：Gemma4-E4B（54.17%）和Qwen3-8B（51.79%）在AppWorld上超越GPT-5-mini（50.00%），Qwen3-4B（49.40%）也接近教师；在BFCL V3上三个学生超过教师。
3. **子任务记忆贡献最大**：在WF基础上添加ST产生最大的增量提升（AppWorld上+25.0%p），说明中间粒度的具体行为示例对复杂长程任务最是关键。
4. **教师效果好坏的机制复杂**：对较强学生（8B），教师准确率是蒸馏质量的可靠预测器；对较弱学生（4B），表现最好的却是中等能力的GPT-5-mini，而非准确率最高的GPT-5.5，说明教师-学生兼容性同样关键。
5. **4B规模学生受益最大**：绝对准确率随模型规模增大而增高，但增益在4B处达到峰值（+34.52%p）并随规模增大而递减。
6. **k=1近乎最优**：增加检索记忆数量普遍不提升甚至降低性能（特别是Subtask记忆，从49.40%降至33.34%），精确高置信度注入优于覆盖面。
7. **最合适的表示随粒度而异**：高层规划知识以自然语言最优，低层执行知识以具体代码示例最优。
8. **AMD还提升了交互效率**：学生模型的交互轮数显著下降，更接近教师的轮数。

## 8. 不足与局限

- **场景覆盖有限**：仅在基于文本的工具使用基准（Python API、结构化函数调用）上验证，未涉及多模态环境（需视觉感知的智能体）和开放式编码任务（动作空间不是固定函数集而是开放式代码生成）。
- **记忆离线构建、静态固定**：记忆在推理时冻结，无法在线整合学生自身的成功/失败经验，也无法适应教师示范与学生实际面临任务之间的分布偏移。
- **教师质量依赖**：AMD的效果取决于教师轨迹的质量和教师的适用性，但选择"哪个教师最适合哪个学生"仍是一个未解决的开放问题。
- **对弱模型存在负面效应风险**：如LLaMA3.1-8B在AppWorld上添加Function记忆时，准确率从30.36%降至27.38%，说明额外上下文可能干扰能力有限的学生模型。
- **TaskSandbox上的增益相对较小**（平均+3.4%p），表明在对话式、状态依赖更强的场景中，记忆蒸馏的效果有一定折扣。
- **算力和成本信息不透明**：论文未报告教师轨迹生成和大量推理评估的总体计算成本，不利于评估实际部署的经济可行性。
