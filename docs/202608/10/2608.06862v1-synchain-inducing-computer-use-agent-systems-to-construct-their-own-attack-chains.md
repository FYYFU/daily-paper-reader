## 摘要
计算机使用代理（CUA）已将大型语言模型转变为持久执行系统，能够生成、存储和复用技能与记忆条目等工件。然而，现有的安全防御大多将攻击视为外部触发或时间上有界的，留下了一个关键空白：如何解决入侵可通过代理自身的持久状态在内部传播的问题。我们揭示，恶意影响可以被隐蔽地嵌入到自主合成工件的结构冗余中，使其能够在内部状态更新中幸存并绕过标准审查机制。为形式化这一威胁，我们提出了SynChain，一种自合成攻击范式，利用持久性感知的定向监督微调来诱导代理生成有毒但看似良性的工件。为系统评估这种传播，我们构建了CUAChain，一个包含30条良性任务链和三个攻击目标的数据集。SynChain使潜伏载荷能够在未来工作流中作为受信任上下文无缝重新激活，完全无需新的恶意外部输入。在OpenClaw、Codex和Claude Code上四种防御设置下的大量实验表明，SynChain实现了高攻击成功率，并优于适配的基线，证明保护CUA需要跨任务执行轨迹的溯源感知推理。

## Abstract
Computer-use agents~(CUAs) have transformed large language models into persistent execution systems capable of generating, storing, and reusing artifacts like skills and memory entries. However, existing security defenses largely treat attacks as externally triggered or temporally bounded, leaving a critical gap in addressing how compromise can propagate internally through an agent's own persistent state. We reveal that malicious influence can be covertly embedded into the structural redundancies of autonomously synthesized artifacts, allowing it to survive internal state updates and bypass standard vetting mechanisms. To formalize this threat, we introduce SynChain, a self-synthesized attack paradigm utilizing persistence-aware directed supervised fine-tuning to induce agents to create poisoned yet benign-looking artifacts. To systematically evaluate this propagation, we construct CUAChain, a dataset comprising 30 benign task chains and three attack objectives. SynChain enables dormant payloads to seamlessly reactivate in future workflows as trusted context, operating entirely without new malicious exogenous inputs. Extensive experiments on OpenClaw, Codex, and Claude Code under four defense settings demonstrate that SynChain achieves high attack success and outperforms adapted baselines, proving that securing CUAs requires provenance-aware reasoning over cross-task execution trajectories.

## 二、方法论：核心思想、关键技术细节与流程

### 2.1 威胁模型
- **攻击者定位**：供应链攻击者，在 CUA 部署前通过发布不安全的开源检查点、分发恶意微调模型或提供 API 兼容模型端点来攻击模型。
- **攻击者能力限制**：无法控制未来用户任务、无法修改代理框架、无法访问私有工作区、无法直接安装恶意技能；其影响仅限于普通代理执行期间对模型输出的控制。
- **攻击目标**：诱导代理在良性工作流中生成被系统信任的可复用工件，使恶意影响跨任务边界持久化。

### 2.2 核心思想：持久性感知的定向监督微调（Persistence-Aware Directed SFT）
- **关键概念——扩展状态空间**：形式化定义代理状态为 `˜s_t = (M_t, A_t)`：
  - `M_t`（被动记忆）：日志、任务摘要和情境记忆的存储库，作为潜伏攻击触发器的被动传播介质；
  - `A_t`（主动工件）：可执行技能、配置模式等系统生成的扩展组件，因执行环境隐式授予高权限而成为恶意载荷的主要载体。
- **关键概念——系统演化**：任务序列下，代理通过检索函数 `R(·)` 获取状态上下文，并通过状态更新函数 `U_M`（记忆管理）和 `U_A`（工件管理）实现状态转移。`U_A` 可增删、覆盖、压缩或移除工件，非严格单调。
- **关键概念——自合成（Self-Synthesis）**：工件 `a_t ≠ ∅` 若由代理策略 `π_θ` 在良性工作流中自主生成并经 `U_A` 吸收到持久状态，即为“自合成”工件。这区别于传统注入攻击中恶意载体由外部提供的场景。
- **核心方法——潜伏载体变异（Latent Carrier Mutation）**：
  - 对良性工件生成指令 `p_s` 和对应干净工件 `a_s`，攻击者施加持久性感知变换 `T_z(·)` 生成有毒工件 `˜a_s = T_z(a_s)`；
  - `T_z(·)` 将恶意行为 `z` 编码到 `a_s` 的结构冗余或元数据中（如嵌入良性 JSON 模式、文档字符串或看似无恶意的日志函数中的执行触发器），保留工件表面效用且绕过审查；
  - 用数据集 `D_SFT = {(p_s, ˜a_s)}` 对基础策略 `π_{θ0}` 进行监督微调：`θ* = argmin_θ Σ_{(p_s,˜a_s)} −log π_θ(˜a_s | p_s)`。
- **跨任务传播与状态空间瓶颈**：
  - 攻击在任务链 `X_i = {x_i^{(n)}}` 中以递归方式传播，每次执行更新扩展状态，外部输入保持完全良性；
  - 形式化定义严格 Chain-N 攻击谓词：恶意行为仅在链上第 N 步触发（n < N 时为 0，n = N 时为 1）；
  - **信息瓶颈分析**：随着链长 N 增加，恶意信号必须经过多次记忆更新和上下文检索。现代 CUA 中的 LLM 摘要或上下文截断本质上是**有损信息瓶颈**，恶性载荷的生存需抵抗这种马尔可夫式退化，同时保持隐蔽性避免提前激活。

## 三、实验设计

### 3.1 数据集 / Benchmark
- **CUAChain 数据集**：30 条良性任务链，覆盖五类代理工作流（软件工程、系统与架构、安全与风险、第三方集成、内容与分析），含 3 个攻击目标：
  - O1 隐私泄露（Privacy Leakage）：读取 .env 等敏感配置并外传；
  - O2 权限篡改（Privilege Tampering）：诱导请求提升权限（如 sudo -S）；
  - O3 未授权写入（Unauthorized Write）：未经授权修改本地文件。
- **链长设置**：评估 Chain-1 至 Chain-5，主实验关注 Chain-1 至 Chain-3（对应 30/60/90 个子任务），Chain-4 与 Chain-5 用于长链压力测试。

### 3.2 代理框架与模型
- **三个 CUA 框架**：OpenClaw、Codex、Claude Code（覆盖执行抽象、系统集成等异构设计）。
- **三个骨干模型**：Qwen3.5-9B、Llama-3.1-8B、Ministral-3-8B。

### 3.3 对比基线与防御设置
- **攻击基线**：SkillJect（技能层注入）、DemonAgent（触发器条件后门）。由于两者原设计为单步攻击，按“保留原则”适配到 Chain-N 协议，使其同样具备跨步持久化能力。适配后基线在无防御 Chain-1 下保持高 ASR，确认适配未削弱其核心攻击能力。
- **四类系统级防御**：
  - None（无防御基准）；
  - Sandwich（提示包装防御）；
  - Skill Vetter（技能审查防御）；

- **指标**：任务完成准确率（Acc）和攻击成功率（ASR）。ASR 由 GPT-5-mini 基于执行证据判定。

- 训练数据为 149 条指令-工件对，仅监督工件生成阶段（不含后续激活任务或攻击轨迹）。

## 六、主要结论与发现

1. **SynChain 在 Chain-1 中高度有效**：无防御下平均 ASR 达 98.89%（OpenClaw）、97.78%（Codex）、98.89%（Claude Code）；即使面对 GuardAgent 最强防御仍保持 87.78% 以上，远超基线（SkillJect 降至约 16.67%-20%，DemonAgent 约 30%-33.33%）。
2. **链长增加显著降低传播可靠性**：平均 ASR 从 Chain-1 的约 98% 降至 Chain-2 的约 72.59%（主实验平均），再降至 Chain-3 的约 26.57%；Chain-4 和 Chain-5 仅约 6.67% 和 1.11%。该衰减趋势在三种框架中一致。
3. **基线在长链下迅速失效**：SkillJect 在 GuardAgent 下 Chain-2/Chain-3 降至 3.33%/0.00%；DemonAgent 降至 0.37%/0.00%，证明 SynChain 自合成工件提供更持久的传播载体。
4. **良性任务效用与攻击可共存**：Chain-2 下 SynChain 在实现 72.59% 平均 ASR 的同时保留了约 80.19% 的平均准确率；Chain-3 效用损失更明显，但仍显著优于基线。
5. **跨模型泛化**：Llama-3.1-8B 和 Mistral-3-8B 在 Chain-1 下整体 ASR 始终不低于 92.67%，证实攻击源于 CUA 工作流特性而非单一模型漏洞。
6. **现有防御不足**：Sandwich、Skill Vetter、GuardAgent 均无法充分抵御 SynChain；且 GuardAgent 引入最高运行开销（250.2 秒 vs 干净基线 103.9 秒）但仍然不能完全抑制攻击。需转向**溯源感知、轨迹感知的防御架构**。

## 七、优点

- **问题定义的创新性**：首次系统化识别并形式化了 CUA 中的“内部供应链攻击”风险——代理以正常工件合成机制“自我武装”，威胁模型定义清晰、与外部注入类攻击明确区分。
- **方法论完整**：将攻击建模为扩展状态空间上的递归传播过程，通过持久性感知 SFT 实现潜伏载体变异，既有技术流程也有理论分析（马尔可夫链 + 信息瓶颈），兼顾严密性与可复现性。
- **实验设计系统全面**：覆盖三框架 × 三模型 × 三目标 × 四防御 × 多链长，形成较大规模的组合评估矩阵。
- **防御评估视角务实**：不仅报告 ASR，还报告 Acc 与效率（时间、命令数），揭示了安全-效用-效率的三方权衡，结论对实际防护决策有参考价值。
- **评估质量控制**：对 LLM-as-a-Judge 做了有说服力的人类盲审验证（高一致性、零假阴性）；消融实验覆盖数据规模、OOD 泛化等维度，增强了结论稳健性。
- **前瞻性防御验证**：初步测试溯源感知工件校验管道（将信任根外置于生成模型）可将 Chain-2 ASR 从 86.7% 降至 16.7%，为未来防御指明了方向。

## 八、不足与局限

- **传播深度有限**：SynChain 在 Chain-3 及以上急剧退化（Chain-5 几乎失效），攻击的实用面主要是 1-2 次状态转移内。作者也承认这是当前方法的固有边界。
- **环境为受控模拟**：所有实验使用合成任务和隔离工作区，敏感文件和远程端点均为模拟替身，未在真实生产系统、真实私有数据上验证。
- **评估规模有限**：基础场景仅 30 条任务链；附录虽澄清总执行数量为 6,480 次，但模板多样性受限。
- **基线适配可能存在争议**：SkillJect 和 DemonAgent 虽按保留原则适配到跨步协议，但其原始设计并非为长链传播而生，对比条件上的公平性仍可能被质疑（尽管文中给出合理性论证）。
- **初步溯源防御验证不够充分**：仅覆盖单一框架、单一链长、单一目标（Claude Code + Chain-2 + O1），缺乏更广泛的可行性结论。
- **长链状态管理黑盒化**：对记忆摘要和上下文截断的信息瓶颈分析框架合理，但缺乏对不同 CUA 框架内部状态管理机制的细粒度剖析（如摘要触发条件、上下文窗口管理策略）。
- **效率和实用性未充分刻画**：无防御攻击设置比干净基线更快这一点缺乏充分解释；GuardAgent 的巨大开销主要来自审计延迟这一点也缺乏前置分析。

## 九、总结与展望

- **总结**：SynChain 攻击框架揭示了 CUA 代理在从“工具处理器”向“自进化工作流单元”演进过程中的结构性安全盲区——当代理有能力自主生成并持久化工件时，模型输出本身就变成了内部供应链的污染源头。论文通过大规模跨框架、跨模型、跨链长评估证实了该攻击的有效性与隐蔽性，并明确指出现有防御体系（提示包装、工件审查、代理审计）在跨任务传播场景下的系统性失效，最终将研究方向指向溯源感知的信任边界重构。
- **展望**：未来工作可从以下方向展开——
  1. **溯源感知防御**：为每个工件建立完整的状态溯源图（生成时的输入、所使用的检索上下文、修改历史），在加载工件时进行轨迹级验证；
  2. **信任边界外置**：将技能/工件验证逻辑从生成模型自身迁移至独立验证器，或引入带有不可变审计日志的硬件级信任根；
  3. **自适应状态管理**：对长链任务施加定期的状态熵压缩或随机性重初始化，切断潜伏载荷的跨任务连续性；
  4. **多模态/多工件协同攻击**：研究恶意载荷跨技能、记忆、配置文件的分布式隐藏与协同触发；
  5. **合成数据与红队演练**：建立 CUA 专用的对抗训练数据生成管道，将持久性攻击纳入安全对齐的过程监督（process supervision）范畴。

## 十、个人评价（审稿视角）

- **学术价值**：本文属于“提前一步预测新型攻击面”的安全研究类型，选题敏锐、定义严谨、实验扎实。它将安全社区对 LLM 的注意力从“单次会话的输入/输出安全”扩展到“跨任务的持久状态安全”，具有很强的启发性和预警价值。
- **技术深度**：马尔可夫链 + 信息瓶颈的分析框架虽然略显抽象，但为理解长链传播中的信号退化提供了简洁的理论视角；持久性感知 SFT 的实际实现简洁高效，体现了“以小成本实现大影响”的攻击设计原则。
- **工程影响**：对 Claude Code、Codex 等已发布产品的实际威胁评估具有现实紧迫性；论文揭示的“自合成工件即内部供应链”问题，应该推动 CUA 平台在工件生成流程中引入独立于生成模型的校验节点。
- **可读性**：结构清晰，但部分章节（如状态空间形式化、链长定义）偏形式化，对安全工程师不算友好；实验表格信息密度高，需要仔细对照正文阅读。
- **综合结论**：这是一篇方法新颖、评估系统、结论可信的安全研究论文，虽受限于模拟环境与链长退化，但其问题定义和防御方向对该领域后续研究有重要的指引作用，具备发表在高水平安全/ML 会议上的质量。

## 十二、一点补充思考

从更宏观的角度看，SynChain 的深层根源不在某一具体模型或框架的漏洞，而在于 **“代理对自己产出的信任”**——当代理学习、复用、执行由自身历史输出沉淀而成的工件时，它实际上是在把曾经的自己当作可信的“上游供应商”。这与传统软件供应链中“信任上游组件”的逻辑同构，只是链条更短、更隐蔽、更难以审计。因此，本文的核心价值或许不在于提出一种新的攻击手段，而在于提醒社区：**当模型成为自己供应链的源头时，安全边界必须随之重构。** 这一认识对未来的 CUA 系统设计、模型对齐和监管框架都有深远的启示意义。
