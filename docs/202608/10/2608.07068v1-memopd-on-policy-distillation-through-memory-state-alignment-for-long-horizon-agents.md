## 摘要
长时程智能体在交互过程中会积累不断增长的情境，损害性能与稳定性。紧凑的记忆通过压缩和重写在模型调用之间保留的历史来缓解这一问题。学习保留什么通常依赖于带最终任务奖励的近端策略优化（PPO），但稀疏奖励对单次记忆更新提供的指导甚少。这一局限促使了在线策略蒸馏（OPD），它在学生轨迹上提供密集的教师监督。为使此类监督有效，教师必须在生成每个采样动作的相同状态下评估该动作。然而，记忆压缩过程中进行的上下文重写可能破坏这种对齐。当采样响应被保留并重新编码以供后续调用时，将交互展平为持久历史可能导致教师在学生rollout期间从未访问过的状态下对动作打分。因此，该动作从来源上讲仍是on-policy，但不一定在状态上符合。为此，我们提出记忆对齐在线策略蒸馏（MemOPD）。MemOPD记录每次模型调用的输入和采样输出，恢复其原始token位置和因果可见性，并打包重构的调用以实现高效的教师评分。教师在采样动作位置提供全词汇表监督，而PPO保留最终任务目标。实验验证了在多次上下文更新中的状态对齐，并表明在匹配对照中，相比持久历史教师评分，其F1提升了7.0%。总体而言，MemOPD-3B相比PPO将F1提升了高达416.2%，而打包在训练期间为actor计算带来了最高1.63倍的加速。本工作的代码公开于：https://github.com/TPssp/MemOPD。

## Abstract
Long-horizon agents accumulate growing contexts during interaction, impairing performance and stability. Compact memory mitigates this problem by compressing and rewriting the history retained between model invocations. Learning what to retain typically relies on proximal policy optimization (PPO) with final task rewards, but sparse rewards provide little guidance for individual memory updates. This limitation motivates on-policy distillation (OPD), which supplies dense teacher supervision on student rollouts. For such supervision to be valid, the teacher must evaluate each sampled action under the same state in which it was generated. However, the context rewriting performed during memory compression can break this alignment. When sampled responses are retained and re-encoded for later invocations, flattening the interaction into a persistent history may cause the teacher to score the action under a state that the student never visited during rollout. The action therefore remains on-policy by provenance, but not necessarily by state. We therefore propose Memory-Aligned On-Policy Distillation (MemOPD). MemOPD records the inputs and sampled outputs of each model invocation, restores its original token positions and causal visibility, and packs the reconstructed invocations for efficient teacher scoring. The teacher provides full-vocabulary supervision at the sampled action positions, while PPO preserves the final task objective. Experiments verify state alignment across several context updates and show that it improves F1 by 7.0% over persistent-history teacher scoring in a matched control. Overall, MemOPD-3B improves F1 over PPO by up to 416.2%, while packing yields up to a 1.63x speedup in actor computation during training. The code for this work is publicly available at: https://github.com/TPssp/MemOPD.

### 2. 方法论：核心思想、关键技术细节与算法流程

#### 2.1 核心思想
- **记忆状态对齐（Memory State Alignment）**：训练时必须重建产生每个采样动作的确切调用状态，使重建状态 $\tilde{\sigma}_{t,k}$ 与 rollout 状态 $\sigma_{t,k}$ 完全一致。
- **动作域分离（Sampled-Action Domain）**：状态重建与判定"哪个 token 是策略决策"是两个独立问题。保留的响应副本作为后续上下文出现时，不属于采样动作域（$m^{\text{act}}_j=0$）。

#### 2.2 紧凑记忆 rollout 形式化
- 形式化交互过程：$a_t \sim \pi_{\text{old}}(\cdot|q, x_t)$，环境返回 $(o_t, r_t, d_t)$，上下文更新规则为 $x_{t+1}=U(x_t, a_t, o_t)$。
- 记忆状态定义为 $\sigma_t=(z_t, \rho_t, V_t, \gamma_t)$，其中 $z_t$ 为 token 输入，$\rho_t$ 为位置，$V_t$ 为因果可见性，$\gamma_t$ 指示预测位置。**相同的解码文本可以代表不同的记忆状态**。

#### 2.3 重建与打包（Reconstruction and Packing）
- **精确记录**：rollout 期间记录每次调用的精确 token 输入和采样输出 ID（不重新解码/分词），保留采样动作与 token 边界。
- **物理序列**：将各次调用放入单一物理序列 $y=[q, x_0, a_0, x_1, a_1, \ldots]$，但将物理相邻性与因果可见性分离处理：
  - 稳定前缀 $q$ 只存一次，位置保持 $0,\dots,|q|-1$，对所有调用可见（因其在各独立执行中完全一致）。
  - 每个调用的 token 只看到本调用内的前缀；不同调用的私有块之间**互不可见**（no cross-attention）。
  - 位置 ID 从各自独立调用的索引重新开始，而非沿打包序列递增。
- **保留内容的双表示**：同一响应在序列中出现两次——一次是精确采样动作（policy trajectory），一次是后续调用的上下文（具有后续调用的位置与可见性）。
- **拒绝而非静默改动**：若序列长度限制会删去条件 token 或采样动作，编译器拒绝该样本。

#### 2.4 Rollout 上下文等价（RCE）
- **定义**：打包执行与独立逐调用执行在相同动作 token 上产生相同的全词表 logits：$\|\ell^{\text{pack}}_{g(t,k)} - \ell^{\text{ind}}_{t,k}\|_\infty \le \epsilon_{\text{num}}$。
- **作用**：RCE 是训练前的离线正确性审计标准，确保打包只是计算共享而非状态近似。

#### 2.5 优化目标
- **教师指导（OPD）**：在监督位置 $j$，计算学生分布 $p_{\theta,j}$ 与冻结教师分布 $p_{T,j}$ 的全词表反向 KL 散度：
$$\mathcal{L}_{\text{OPD}} = \frac{1}{\sum_j m^T_j}\sum_j m^T_j \sum_{v \in V} p_{\theta,j}(v)\log\frac{p_{\theta,j}(v)}{p_{T,j}(v)}$$
- **PPO 分支**：PPO 比值、熵、价值学习、GAE（广义优势估计）全部限定在采样动作域（$m^{\text{act}}=1$）内。GAE 按有序采样动作递推，跳过纯上下文位置。参考策略（reference policy）保持 SFT 初始化的冻结状态，提供 token 级 KL 正则：
$$\text{KL}^{\text{ref}}_j = [\ell_{\text{old},j} - \ell_{\text{ref},j}]_+,\quad \tilde{r}_j = r_j - \beta\,\text{KL}^{\text{ref}}_j$$
- **联合目标**：$\mathcal{L}_{\text{actor}} = \mathcal{L}_{\text{PPO}} - \alpha H + \lambda \mathcal{L}_{\text{OPD}}$，其中教师给出密集局部偏好，PPO 保留任务级最终奖励。

### 6. 主要结论与发现

1. **状态对齐是 OPD 在紧凑记忆智能体上的必要条件**：持久历史重建导致的 logit 差异（p99 = 1.774）足以改变教师预测和 PPO clipping 行为；重建打包在数值精度下限内完全匹配独立调用。
2. **MemOPD 显著提升长时程任务性能**：Q2/Q8/Q16 上 F1 相对 PPO 提升 14.3%/283.2%/416.2%（5 种子均值），且优势随时程增长而扩大——越长的任务越需要对齐的密集监督。
3. **教师指导与状态对齐贡献可分解**：匹配对照中，持久历史教师评分相对 PPO 提升 F1 5.6%；状态对齐额外提升 7.0% F1 和 10.0% EM——说明即便在错位状态下教师仍有价值，但对齐能进一步解锁其潜力。
4. **方法具有通用性**：重建接口不依赖 MEM1 的符号记忆语义，对 5 种不同类型的上下文更新均满足 RCE。
5. **训练效率更高**：打包策略在保持 RCE 的同时带来最高 1.63 倍 actor 计算加速（前向），前向+反向达 1.08–1.63 倍。
6. **Wiki-RAG 迁移受益**：MemOPD 相对 PPO 提升 EM 6.1%、F1 7.4%，同时将依赖量降低 31.6%、推理时间降低 28.5%。

### 7. 优点

- **问题定义精准且新颖**：明确区分"动作来源上的 on-policy"与"状态上的 on-policy"，将状态错位形式化为紧凑记忆 + 蒸馏的根本条件冲突，是此前工作未明确定义的训练条件。
- **概念清晰、验证严格**：用 RCE 作为可验证的正确性标准，直接对比打包与独立调用的 logit 是否一致，而非仅用最终指标间接推断——机制验证可信度高。
- **设计具有解耦性与可移植性**：将"状态重建"（conditioning preservation）与"动作域判定"（decision identification）分离，且编译器消费的是"实际 token 上下文"而非特定记忆拓扑，可支持多种上下文更新策略。
- **实验对照组设计严谨**：匹配控制实验隔离了教师价值与状态对齐的贡献，用审计数据展示持久历史的量化破坏程度（top-1 变化、false clipping），有说服力。
- **全词表反向 KL 与 PPO 的角色分工清晰**：教师提供局部密集偏好，PPO 保留任务级优化，两者互补而非冲突。

### 8. 不足与局限

- **模型规模覆盖有限**：学生模型仅验证了 3B，教师为 7B；未验证在更大学生（7B/14B）或跨模型族（非 Qwen 系列）下方法的有效性。
- **任务领域较窄**：实验集中在检索增强的 QA 任务（HotpotQA/NQ/Wiki-RAG），未覆盖更一般的智能体场景（如具身智能、网页导航、多智能体协作）。
- **训练数据依赖外部教师**：SFT 数据由 gpt-oss-120b 生成并筛选正确轨迹，可能引入教师偏差和分布局限，且未讨论该依赖对下游性能的影响。
- **算力信息不完整**：未报告训练时长、总 GPU 小时、SFT 数据生成成本等，难以评估方法的实际工程成本。
- **RCE 是离线审计而非在线约束**：论文通过离线验证说明打包不改变状态，但训练过程中的数值漂移或实现偏差（如 bf16 vs fp32）在极端情况下仍可能引入未被捕捉的错误。
- **未讨论鲁棒性边界**：如记忆更新规则出错、超长轨迹触达序列上限、上下文更新规则与训练分布不一致等情况下的退化表现未涉及。
