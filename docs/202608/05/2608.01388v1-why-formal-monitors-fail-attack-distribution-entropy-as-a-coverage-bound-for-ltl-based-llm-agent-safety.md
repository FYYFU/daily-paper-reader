## 摘要
基于线性时序逻辑（LTL）和有限自动机（FSA）的运行时安全监控器越来越多地被部署用于拦截LLM智能体中的不安全工具调用序列。然而，同一监控器在某些模型架构上能达到68-75%的攻击覆盖率，在另一些上却几乎为零，而能力分数、训练数据或提示设计均无法解释这一差异。我们提供了缺失的理论。我们证明，任何固定不变量的FSA监控器的召回率受攻击分布集中度的上界约束：即k个最频繁的触发-完成模式所覆盖的攻击比例。当攻击集中（低香农熵）时，一个小的固定不变量集即可实现高召回率；当攻击分散在多个结构不同的模式中（高熵）时，无论不变量如何推导，任何可处理大小的固定不变量集都无法实现高召回率。我们在八个前沿LLM架构上验证了这一熵-覆盖界。GPT类和DeepSeek后端产生高度集中的攻击（H约0.24比特；一个模式覆盖96%），解释了68-75%的召回率；Gemini变体产生高熵分布（H约2.81比特；7个簇各占不超过7%），解释了近乎为零的召回率（6-13%），且对架构匹配的再训练不变。熵解释了覆盖率的76%方差（皮尔逊r = -0.87，p = 0.005，95%置信区间[-0.98, -0.78]），在留一法下保持（r在[-0.91, -0.82]）。我们引入了一种部署前熵测试，可从少量攻击样本预测监控器覆盖率，从而在部署前实现架构感知的监控器选择。该界和测试与架构无关，适用于任何基于FSA的离散动作序列运行时监控器。

## Abstract
Runtime safety monitors based on Linear Temporal Logic (LTL) and finite automata (FSA) are increasingly deployed to intercept unsafe tool-call sequences in LLM agents. Yet the same monitor achieves 68-75% attack coverage on some model architectures and near-zero on others, with no explanation from capability scores, training data, or prompt design. We provide the missing theory. We prove that the recall of any fixed-invariant FSA monitor is bounded above by the concentration of the attack distribution: the fraction of attacks covered by the k most frequent trigger-completion patterns. When attacks concentrate (low Shannon entropy), a small fixed invariant set achieves high recall; when they disperse across many structurally distinct patterns (high entropy), no fixed invariant set of tractable size can, regardless of how the invariants were derived. We validate this entropy-coverage bound across eight frontier LLM architectures. GPT-class and DeepSeek backends yield highly concentrated attacks (H ~ 0.24 bits; one pattern covers 96%), explaining 68-75% recall; Gemini variants yield high-entropy distributions (H ~ 2.81 bits; 7 clusters each <= 7%), explaining near-zero recall (6-13%), invariant to architecture-matched retraining. Entropy accounts for 76% of variance in coverage (Pearson r = -0.87, p = 0.005, 95% CI [-0.98, -0.78]), holding under leave-one-out (r in [-0.91, -0.82]). We introduce a pre-deployment entropy test that predicts monitor coverage from a small attack sample, enabling architecture-aware monitor selection before deployment. The bound and test are architecture-agnostic and apply to any FSA-based runtime monitor over discrete action sequences.

## 2. 论文提出的方法论

### 思想
- 将攻击分布视为攻击模式（触发-完成对，trigger-completion pair）上的概率分布。
- 一个 FSA 监控器包含 n 条不变量，每条不变量只能覆盖一种特定模式，因此最多覆盖 n 个模式。
- 监控器召回率上界等于攻击分布中概率最大的 n 个模式的总概率（top-n 集中度），即 `C_n(D) = Σ p*_i`，与不变量推导方法无关。
- 高 Shannon 熵分布意味着概率分散，导致任何可处理的 n 对应的 C_n 都很小，因此 FSA 监控器结构性失效。

### 关键定义
- 攻击模式：`(T, t_c)`，其中 T 是触发工具集，t_c 是被禁止的完成工具。
- 监控器公式：`ϕ = G(T_trig → F[1,k](t_comp))`，即“当触发器出现时，禁止在 k 步内出现指定完成”。
- 监控器召回率：`R(M,D) = Σ p(T,t_c) · 1[M covers (T,t_c)]`

### 核心定理
- **定理 1（熵-覆盖界）**：对任意含 n 条不变量的固定 FSA 监控器和攻击分布 D，召回率 `R(M,D) ≤ C_n(D)`。证明基于模式互斥性与贪心选择最优 n 个模式。
- **推论 1**：最小残余攻击率 `ASR_min(n) ≥ 1 - C_n(D)`；当 `H(D) ≥ log₂(n+1)` 时，任何 n 条不变量的监控器都无法使 ASR 降为零。
- **命题 1（高熵结构不足）**：若 D 近似均匀分布在 m 个模式上（m >> n），则 `C_n ≈ n/m`，召回率随 n/m 线性下降。
- **定理 2（熵-覆盖对偶）**：`H(D) ≥ H_b(C_n(D))`（二元熵函数），因此当 `H(D) < 1` 比特时，任何 FSA 监控器都能达到优于随机的覆盖率（C_n > 0.5）。
- **定理 3（预部署测试样本复杂度）**：基于 Hoeffding 不等式，给出估计熵所需样本量：`N ≥ log₂²(m̂) · ln(2/δ) / (2ε²)`，如低熵架构（m̂≤3, ε=0.3, δ=0.05）需要 N≥51 条轨迹。

### 预部署熵测试流程
1. 从目标后端采集至少 50 条攻击轨迹。
2. 提取触发-完成模式，按 Jaccard 距离（阈值 θ=0.4）层次聚类。
3. 估计攻击分布熵 Ĥ。
4. 若 Ĥ < 0.5 bits → 预期召回率 > 50%，适合 FSA 监控器；若 Ĥ > 2.0 bits → 预期召回率 < 20%，应改用概率性/神经监控器；中间灰区需领域风险评估。

## 6. 论文的主要结论与发现

- **信息论解释覆盖差异**：攻击分布熵是 FSA 监控器召回率的决定性因素。低熵架构（H≈0.24 bits，如 GPT/DeepSeek）一个模式覆盖 96% 的攻击，因此固定不变量可实现高召回（68–75%）；高熵架构（H≈2.81 bits，如 Gemini）7 个最大簇各占≤7%，固定不变量几乎无效（6–13%）。
- **熵预测强度**：熵解释覆盖率方差的 76%（Pearson r = -0.87，p=0.005，bootstrap 95% CI [-0.98, -0.78]；LOO r∈[-0.91, -0.82]），而 Elo 能力分数无显著预测力（|ρ|<0.35，p>0.4）。
- **“剧院鸿沟”的本质**：Gemini 高熵攻击分布导致任何 8 条不变量的 FSA 监控器理论覆盖率上限仅为 27–31%，且架构匹配的再训练无法改变分布，故 Δrecall=0.0pp，鸿沟对再训练不变。
- **界限紧性**：观察到的召回率总是低于或等于理论界 C₈；界限与观察值的差距由 FPR 约束（约 20–28 pp）和跨架构分布不匹配（23–54 pp）构成，不影响定理有效性。
- **应用价值**：预部署熵测试（N≈50 条轨迹即可识别低熵架构）可预测 FSA 监控器是否有效，从而引导监控器选型。
