## 摘要
自我蒸馏（SD）已成为强化学习的一种计算高效替代方案，可验证奖励：自我教师以关于答案的特权信息（PI）（如参考解决方案）为条件，向从未见过该信息的学生提供密集的逐令牌监督。然而，报道的收益几乎完全来自狭窄、低难度的设置，留下了一个基本问题：作为唯一目标，在没有奖励项的情况下，SD 能教给学生什么？我们在 SDPO 的简单设置中重现了其报道的收益，然后将相同的设置应用于困难任务，发现它并不适用。在问答、数学、编码和多轮智能体工具使用中，跨推理模式、模型大小和 PI 形式，以及在 SDPO 和 OPSD 两种配方下，逐令牌损失稳步下降，而验证准确率没有提高，通常会下降。我们通过从损失到它产生的模型的单一因果链来解释这一失败。该链条从 PI 偏差开始：教师看到特定参考解决方案后，其逐令牌目标被拉向该轨迹，而不是向一般的正确性，我们用 PI 偏差分数量化了这一效应。为了在所有地方匹配这一目标，学生的目标变得几乎对轨迹是否正确毫无感知，它分配的损失主要落在低信息令牌上，如停用词、标点、不确定性标记，而不是决定答案的令牌；在正确的轨迹中，探索性令牌产生最高分歧，因此它惩罚了推理所需的犹豫。结果是一个更平坦、更不果断的学生，在推理上没有更好：作为唯一目标，SD 优化了一个与任务成功脱节的信号。

## Abstract
Self-distillation (SD) has emerged as a compute-efficient alternative to reinforcement learning with verifiable rewards: a self-teacher, conditioned on privileged information (PI) about the answer such as a reference solution, supplies dense per-token supervision to a student that never sees it. Reported gains, however, come almost exclusively from narrow, low-difficulty settings, leaving open a basic question: as a lone objective, with no reward term, does SD teach anything? We reproduce SDPO's reported gains in its easy setting, then apply the identical setup to difficult tasks and find that it does not. Across question answering, mathematics, coding, and multi-turn agentic tool use, across reasoning modes, model sizes, and forms of PI, and under both the SDPO and OPSD recipes, the per-token loss falls steadily while validation accuracy does not improve and typically degrades. We explain this failure through a single causal chain from the loss to the model it produces. The chain begins with PI bias: having seen one particular reference solution, the teacher's per-token target is pulled toward that trajectory rather than toward correctness in general, an effect we quantify with a PI Bias Score. Trained to match this target everywhere, the student's objective becomes nearly blind to whether a rollout is correct, and the loss it assigns falls mostly on low-information tokens like stopwords, punctuation, uncertainty markers, rather than those that determine the answer; within correct rollouts the exploratory tokens incur the highest divergence, so it penalizes the hesitation that reasoning requires. The result is a flatter, less decisive student that is no better at reasoning: as a lone objective, SD optimizes a signal decoupled from task success.

## 1. 核心问题与研究动机

- **研究背景**：强化学习（RLVR）为大语言模型后训练提供标准方案，但其监督信号粗糙、稀疏且昂贵（每个 rollout 仅一个标量奖励）。自我蒸馏（Self-Distillation, SD）被提出作为计算高效的替代方案：以特权信息（Privileged Information, PI，如参考解、提示或执行反馈）为条件的自我教师，为学生提供密集的逐 token 监督，无需外部教师或奖励项。
- **核心问题**：**SD 作为唯一目标（lone objective）时，是否真的能教会模型推理？** 已有方法（SDPO、OPSD）的收益几乎全部来自狭窄、低难度的简单设置；在困难任务上，SD 是否只是优化了一个与任务正确性脱节的代理信号？
- **论文立场**：作者在简单设置中成功复现 SDPO 的收益，但在问答、数学、编码、多轮智能体工具使用等困难任务上，发现逐 token 损失稳步下降而验证精度不升反降，并给出从损失到模型的完整因果机制解释。

## 2. 方法论

### 2.1 SD 目标函数
- 训练目标为式 (1)（无任何奖励项）：
  - 学生仅以提示 x 为条件：pS(·|x, y<t) = πθ(·|x, y<t)
  - 教师以 PI r 为额外条件：pT(·|x, y<t) = πθ′(·|x, r, y<t)
  - 损失：LSD(θ) = E[ (1/|ŷ|) Σt D( sg(pT(·|x,r,ŷ<t)) ‖ pS(·|x,ŷ<t) ) ]，沿学生自身 rollout ŷ 逐 token 匹配教师，梯度仅经学生传播。
- **两个关键属性**：
  - **密集逐 token 目标**（Property 1）：每个位置都有目标，使标点、停用词、风格性话语标记与内容 token 处于同等地位。
  - **PI 条件目标**（Property 2）：以完整参考解为条件时，目标反映的是某一条特定轨迹（措辞、顺序、答案），而非一般正确性。

### 2.2 训练配方
- 主配方采用 SDPO 实现：Jensen–Shannon 散度（α=0.5，即 KL( p‖m ) 与 KL( q‖m ) 的均值）、慢速 EMA 教师（α=0.001）、逐 token 损失裁剪（τ=0.001）、学习率 1e−5、batch size 32、3 epochs。
- 另复现 OPSD 配方（单 rollout、固定正确解、初始策略教师、forward KL）以排除配方特异性。

### 2.3 PI 偏差分数（PI Bias Score）
- 定义：PSt(w) = sT_t(w) − sS_t(w)，即教师与学生对目标序列 w 的平均对数概率之差，仅需前向传播即可计算。
- 对四个目标分别打分：上下文参考解 y⋆、同一问题的另一正确解 y′、无关问题的解 ỹ、错误解 y⁻，以区分"教师编码正确性"还是"教师编码单条轨迹"。

### 2.4 因果链（核心贡献）
1. **PI 偏差**：教师聚焦单条参考轨迹而非正确性（PI Bias Score 显示 PS⋆≫PS′≈PS∼）。
2. **损失对正确性无感知**：正确与错误 rollout 的逐 token 损失和 KL 几乎完全重叠，且在分离的方向上反而倒挂（正确 rollout 上教师–学生差距更大）。
3. **损失集中于低信息 token**：停用词、不确定性标记、标点、空白占 55.4% 的损失预算，而决定答案的内容词、数字、数学符号占比低。
4. **惩罚探索**：正确 rollout 中偏离参考路径的位置 KL 约为路径上的 4 倍（≈0.31 vs ≈0.08），使推理所需的探索被压制，响应变短。
5. **学生变平而非变尖**：教师–学生平均差距从 ≈3.1 收敛到 ≈0，但 ±1 标准差带不收缩、熵上升——是抵消而非收敛，最终产生更平缓、更早下结论的策略。

## 6. 主要结论与发现

1. **SD 作为唯一目标在困难任务上失败**：损失稳定下降但验证精度不升反降；think 模式智能体域平均降 3.51 分，单基准最高降 7.0 分（BFCL Miss Func）；通用问答两模式均降约 1.6 分。
2. **结果与配方无关**：SDPO 与 OPSD 两种配方呈现相同失败模式，说明问题在于两者共享的目标结构（PI 条件 + 逐 token 密度）。
3. **教师编码的是单条轨迹而非正确性**：PI Bias Score 显示上下文参考解被强烈偏好（≈0.52），而同一问题的其他正确解与无关解几乎无差别（≤0.02）。
4. **损失与正确性脱节**：正确与错误 rollout 的损失/KL 重叠；学习压力反而集中在学生已能正确求解的 rollouts 上。
5. **损失预算错配**：低信息 token（停用词、不确定性标记、标点、空白）吸收 55.4% 的损失；不确定性标记的平均逐 token 损失最高。
6. **探索被惩罚、响应缩短**：偏离参考路径的探索性 token 承担 4 倍以上的 KL 惩罚，模型因被迫更早下结论而输出变短。
7. **学生分布变平而非变尖**：教师–学生差距收敛至零但方差不收缩、学生熵上升，是抵消性匹配而非真正的融合。
8. **PI 特异性无安全中间档**：完整解过特异（绑定单轨迹），hint/skill 过弱（几乎不传递信号），两端都失败。

## 7. 优点

- **先复现后质疑的严谨性**：先验证 SDPO 在简单场景（SciKnowEval 生物/物理）的正向结果，再以完全相同的代码和设置转向困难任务，排除实现错误的嫌疑。
- **统一的因果解释框架**：将 PI 偏差、损失无感知性、token 预算错配、探索惩罚、学生熵上升串成一条逐环可测量的因果链，且整合了 RLSD 的信息论分析（条件互信息）与 Kim et al. 仅观察到的退化现象。
- **PI Bias Score 实用性强**：只需少量前向传播即可在训练前筛选 PI 候选，成本可忽略，具有实际工程价值。
- **实验设计全面**：覆盖 4 领域、2 种推理模式、2 种配方、3 种 PI 形式、3 种响应长度档、3 种难度档、2 种模型规模，且均含独立迁移基准，防止"只拟合训练集"的假阳性。

## 8. 不足与局限

- **未提出解决方案**：论文性质为观察性/诊断性研究，只刻画目标缺陷，不提供修复方案；组合 verifier 奖励与 SD 项（如 RLSD 式重加权）能否修复失败，作者明确声明未测试。
