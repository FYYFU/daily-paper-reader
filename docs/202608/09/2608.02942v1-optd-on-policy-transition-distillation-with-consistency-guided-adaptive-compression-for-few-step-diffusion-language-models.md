## 摘要
扩散语言模型（dLLMs）可以并行预测多个词元，但准确生成仍需多次迭代去噪步骤。少步蒸馏通过将多个教师步骤压缩为单个学生过渡来加速解码。然而，现有方法在离线策略轨迹上构建监督。在推理时，学生的早期并行承诺会改变后续预测的上下文，因此其实际访问的状态会偏离受监督的状态——而正是在步长压缩最激进时出现这种偏差。在线策略蒸馏是对这种不匹配的自然补救措施，但它未能解决每个过渡应推进多远的问题：仅匹配教师的下一步动作会限制压缩，而不加区分地合并未来动作可能违反中间依赖关系。为解决这一局限性，我们提出了OPTD，即带有一致性引导自适应压缩的在线策略过渡蒸馏。它从少步学生自身的轨迹中采样部分状态，使用冻结的、仅基于问题的教师来识别与结果对齐的未来候选，并按当前状态置信度对其进行排序。随后，该方法选择保持教师展开结果的最长联合承诺前缀。集合瓶颈目标促使每个已验证的未来候选达到解码器的释放阈值，而冻结教师KL锚点则对所有其他活动位置进行正则化。目标构建和训练均不使用金标准响应。在四个数学推理和代码生成基准上，OPTD持续改善了质量-效率权衡，并在所评估的少步基线中获得了最强的整体质量约束AUP。

## Abstract
Diffusion language models (dLLMs) can predict many tokens in parallel, but accurate generation still requires many iterative denoising steps. Few-step distillation accelerates decoding by compressing multiple teacher steps into a single student transition. However, existing methods construct supervision on off-policy trajectories. At inference, the student's early parallel commitments alter the context of later predictions, so the states it actually visits drift away from the supervised ones--precisely when step compression is most aggressive. On-policy distillation is a natural remedy for this mismatch, but it leaves open how far each transition should advance: matching only the teacher's next action limits compression, while indiscriminately merging future actions can violate intermediate dependencies. To address this limitation, we propose OPTD, On-Policy Transition Distillation with consistency-guided adaptive compression. It samples partial states from the few-step student's own trajectories, uses a frozen, question-only teacher to identify outcome-aligned future candidates, and orders them by current-state confidence. The method then selects the longest prefix whose joint commitment preserves the teacher's rollout outcome. A set-bottleneck objective promotes every verified future candidate to the decoder's release threshold, while a frozen-teacher KL anchor regularizes all other active positions. Neither target construction nor training uses a gold response. Across four mathematical reasoning and code-generation benchmarks, OPTD consistently improves the quality--efficiency trade-off and attains the strongest overall quality-constrained AUP among the evaluated few-step baselines.

## 1. 核心问题与整体含义（研究动机与背景）

扩散语言模型（dLLMs）通过迭代替换掩码位置的方式生成文本，其去噪器可对每个掩码位置预测分布，从而支持多个高置信度 token 的并行提交。然而，准确生成仍需大量迭代去噪步骤（多次 NFE），因为后续预测常依赖前面去噪步骤揭示出的新上下文。

少步蒸馏（Few-step Distillation）通过把教师的多步转换压缩到学生的单步转换来加速解码。现有方法的主要问题在于：

- **离线策略监督失配**：现有蒸馏方法在固定的教师轨迹或预定义损坏调度上构建监督目标，属于 off-policy；而推理时学生通过自己的解码策略访问状态，其并行提交会改变后续所有掩码的上下文，导致学生实际访问的状态与监督状态显著漂移。
- **压缩程度问题**：即使改用 on-policy 蒸馏，仍需回答"每个转换应推进多远"——只匹配教师的下一步动作不带来额外压缩，而固定长度的合并可能违反中间依赖。
- **逐 token 验证不足**：单独看每个未来 token 都与教师结果一致，但联合提交时可能仍然失效。

论文的审计数据表明：学生访问的状态仅有 33.7% 出现在教师轨迹上，覆盖率从解码前 8 步的 55.0% 降至 40 步后的 6.5%；并且按进度匹配的教师状态上验证通过的合并动作，迁移到学生状态后仅有 50.3% 仍然有效。这些证据表明 on-policy 状态采集与联合一致性验证是必要的。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 核心思想

OPTD 通过 **on-policy 状态采集** 与 **一致性引导的自适应压缩** 相结合，在少步蒸馏中实现"每步尽可能多地、且不破坏结果一致性"的并行提交。

### 2.2 方法流程（文字说明）

1. **On-policy 状态采集**：给定训练问题 q，用当前学生的推理解码器从完全掩码起始运行到随机采样深度，得到学生实际访问的"根状态" x；保留该状态及其暴露的 block group。
2. **冻结教师延展**：用冻结教师策略 pᴛ 从根状态继续生成保守延续，得到一系列释放波次 A₁ → A₂ → … → A_J，终点为教师展开结果 xᵀ。
3. **候选筛选（token 级）**：在暴露 block group 中，剔除已在第一波 A₁ 中的位置，保留"当前状态教师预测等于教师结果中的值"的候选位置集合 C(x)，即满足 identity filter。按当前置信度降序排列候选（位置编号作为确定性 tie-breaker）。
4. **联合一致性验证（集合级）**：对候选前缀依次做 counterfactual 验证——将 A₁ 与候选前缀联合提交到冻结教师，检查展开结果是否与 xᵀ 逐 token 一致。选择满足一致性成立的**最长前缀** Cₘ⋆，得到验证集 V(x) = Cₘ⋆，最终压缩动作 S(x) = A₁ ∪ V(x)。
5. **训练损失**：
   - **集合瓶颈目标（Set-bottleneck certainty loss）**：L_set = max over i∈V(x) [log τ − log pθ(ŷᵢ | q, x, i)]₊，促使验证集中最不自信的 token 也达到解码器释放阈值 τ。
   - **冻结教师 KL 锚点**：对验证集之外的其他活动位置（含第一波），用 KL 散度将学生分布锚定到冻结教师的当前状态分布，防止递归置信漂移。
   - 总损失：L_OPTD = L_set + λ_anchor · L_anchor。

### 2.3 关键公式与理论性质

- 解码器释放集定义：A^τ_θ(q, x) = {i ∈ M_G(x) : c_θ(i|q, x) ≥ τ}
- 一致性引导的最长前缀选择：m⋆ = max{ m ∈ {0,…,|C(x)|} : Φ_T(x; A₁ ∪ Cₘ) = xᵀ }
- Lemma 1 保证：因 C₀ = ∅ 天然一致，m⋆ 定义良好，返回的动作在冻结教师下结果保持；降序穷举扫描最多需要 n 次对比验证，或 ⌈n/b⌉ 个并行批次。
- 该保证**仅覆盖训练目标的构建**，不构成对推理时学生行为的保证。

## 6. 主要结论与发现

1. **在线状态是关键**：随训练推进，on-policy 蒸馏相对 off-policy 的准确率优势从 −0.20 扩大至 +1.88 个百分点（1,024 次更新），而 TPF 几乎一致，表明准确率提升来自状态匹配而非效率妥协。
2. **联合一致性验证优于逐 token 验证**：独立验证虽多放行 token（2.875 vs 1.327/状态），但 416 个联合测试中有 10 个逐 token 验证通过却被联合提交破坏结果的案例。
3. **自适应压缩提供额外效率**：在匹配设定下，自适应选择在 H=2 时 TPF 提升 7.2% 而准确率基本持平；较大 H 下换取 20.7%–29.2% 的 TPF 增长。
4. **结构验证而非推理保证**：Lemma 1 的保证只在冻结教师验证下成立，不延伸至推理时学生的实际行为；推理质量仍依赖所学策略的置信度校准。
5. **初始化器贡献显著**：从基础 LLaDA 起步的迁移实验仅获得 138.77 AUP 和 3.78 TPF，远低于 TAD-S 初始化的 313.18 AUP 和 7.87 TPF，说明现有蒸馏检查点提供了大部分可压缩的并行结构。
6. **压缩空间是自适应的**：请求 8× 跨度在很多状态下并不可用（仅 10.1% 状态完全满足），实际实现的自适应上限约为 3.16×；这印证了固定深度合并的不合理性。
