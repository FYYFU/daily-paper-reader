## 摘要
特权在策略蒸馏通过允许同步教师利用仅训练可得的参考（如成功轨迹）在每一轮重新评分学生的响应，为多轮智能体提供密集监督。然而，在交互式环境中，学生先前的动作会持续改变执行状态。当学生采取不同动作或以不同顺序完成子目标时，其轨迹可能到达参考未覆盖的状态，从而使参考对于实际到达状态的引导变得不可靠。因此，不加区分地应用特权蒸馏会造成状态-参考失配。这一失配引出了一个核心目标：提供与学生当前执行状态兼容的特权参考引导。我们提出了状态匹配路由与情境化自蒸馏（SMRC-SD），它明确决定特权轨迹应在何时以及如何引导在策略学生。在每一轮，SMRC-SD 验证学生当前执行状态是否与参考轨迹上的某个受支持状态匹配。仅在匹配状态下应用蒸馏，过滤掉参考缺乏局部兼容引导的轮次。对于每个匹配状态，SMRC-SD 还从成功轨迹构建状态条件化的教师上下文，将监督锚定在实际到达的状态上。在 ALFWorld 和 WebShop 上，SMRC-SD 一致地优于无条件的成功全路径蒸馏。使用 Qwen3-1.7B 时，它将 ALFWorld 的任务成功率从 0.746 提升到 0.865，将 WebShop 的任务成功率从 0.574 提升到 0.693。受控路由与上下文消融实验支持以下结论：选择局部受支持的轮次以及构建状态兼容的教师上下文都是这些增益的贡献因素。代码可在 https://github.com/liujunzhuo/SMRC-SD 获取。

## Abstract
Privileged on-policy distillation provides dense supervision for multi-turn agents by allowing a synchronized teacher to re-score the student's response at every turn with access to training-only references, such as successful trajectories. In interactive environments, however, the student's preceding actions continually change the execution state. As the student takes different actions or completes subgoals in a different order, its rollout may reach states not covered by the reference, making the reference an unreliable source of guidance for the state actually reached. Applying privileged distillation indiscriminately therefore creates state--reference mismatch. This mismatch motivates a central objective: providing privileged reference guidance that remains compatible with the student's current execution state. We introduce State-Matched Routing and Contextualized Self-Distillation (SMRC-SD), which explicitly determines when and how a privileged trajectory should guide an on-policy student. At each turn, SMRC-SD verifies whether the student's current execution state matches a supported state along the reference trajectory. Distillation is applied only at matched states, filtering out turns for which the reference lacks locally compatible guidance. For each matched state, SMRC-SD further constructs state-conditioned teacher context from the successful trajectory, grounding supervision in the state actually reached. Across ALFWorld and WebShop, SMRC-SD consistently outperforms unconditional successful full-path distillation. With Qwen3-1.7B, it improves task success from $0.746$ to $0.865$ on ALFWorld and from $0.574$ to $0.693$ on WebShop. Controlled routing and context ablations support both selecting locally supported turns and constructing state-compatible teacher context as contributors to these gains. Code is available at https://github.com/liujunzhuo/SMRC-SD.

## 1. 核心问题与整体含义

- 论文聚焦于多轮交互智能体的**特权在策略蒸馏（Privileged On-Policy Distillation, OPD）**可靠性问题。OPD 允许一个同步教师利用训练时独有的参考信息（如成功轨迹）对学生每个回合的响应进行重新评分，从而提供比稀疏结果奖励更密集的中间监督。
- 然而，在交互式环境中，学生先前的动作会持续改变执行状态（位置、库存、物体属性、当前页面、已完成子目标等）。学生一旦偏离参考轨迹的动作顺序或采取替代动作，就可能到达参考轨迹未覆盖的状态。
- 此时，参考轨迹虽然在任务层面仍然“正确”（是同一任务的可行解），但其**局部延续**可能并不适用于学生实际到达的状态。论文将这一现象命名为**状态–参考失配（State–Reference Mismatch）**。
- 不加区分地将完整成功轨迹作为教师上下文（即 FullPath-SD 基线）进行蒸馏，可能对学生本已合理的恢复性动作给出不利的评分信号，从而误导策略。其核心问题在于：**可执行的参考轨迹应当被视为“状态条件的条件化计划”，只有在其局部有效性先得到验证之后，才能用于监督多轮策略。**

## 2. 方法论：SMRC-SD

### 2.1 核心思想

- SMRC-SD 将成功轨迹视为一个**按状态索引的训练资源**，通过“状态匹配”显式决定：
  - **何时（when）**使用参考轨迹进行蒸馏——仅在学生当前状态与参考轨迹中某个受支持状态匹配时；
  - **如何（how）**使用——基于匹配位置构建状态条件化的教师上下文。

### 2.2 关键技术细节

**（1）状态签名重建**
- 环境适配器从普通交互数据与参考动作前缀中重建紧凑的签名：
  - 参考签名：`σ̄_{g,k} = φ_ref(g, ā_{g,<k})`，表示参考动作 `ā_{g,k}` 执行前的条件；
  - 学生签名：`σ_t = φ_stu(g, h_t, o_t, A_t)`，表示当前已到达的执行进度。
- 签名为手工设计、环境特定，但遵循统一接口：确定性重建、方向性字段检查、动作可执行性检查。

**（2）结构化状态匹配与路由**
- 通过方向性支持关系“`σ_t |=_g σ̄_{g,k}`”判断当前状态是否满足参考位置 `k` 的任务相关要求；同时将参考动作 `ā_{g,k}` 通过函数 `Γ_g` 映射到当前可行动作集合 `A_t` 上，以验证候选动作的**可执行性**。
- 匹配判定：`C_t(k) = I[σ_t |=_g σ̄_{g,k}] · I[ã_{t,k} ≠ ∅]`。
- 选择**最新匹配位置** `k_t = max{k : C_t(k) = 1}`，避免重复完成已完成的子目标。
- 路由权重：`w_t = I[max_k C_t(k) = 1]`，即仅当存在匹配时施加蒸馏损失；未匹配回合仍由 GRPO 目标覆盖。

**（3）状态条件化教师上下文构建**
- 对匹配回合，上下文体为三部分：完整成功路径 `p_g`、当前状态摘要 `Summary(σ_t)`、可落地的候选动作 `ã_{t,k_t}`。
- 这样既保留了全局任务结构，又通过状态摘要与局部候选动作将监督锚定在实际到达状态上，而非要求教师从无差别的完整路径中自行推断对齐关系。

**（4）训练目标**
- 总损失：`L = L_GRPO + λ_SDL · L_SDL`，其中蒸馏损失仅在 `w_t = 1` 的匹配回合生效。
- 采用 Chosen-Token K3 估计器，分母包含所有原始响应 token，因此路由掉更多回合会减少整体 SDL 权重，而非重新归一化。
- 推理时不使用参考、签名、匹配结果、候选动作等任何特权组件，部署策略只依赖普通提示。

## 6. 主要结论与发现

- **状态–参考失配是真实的、可测量的可靠性问题**：固定状态干预显示，同样的 FullPath-SD 上下文在匹配回合平均提升已一致动作的分数（+0.017），在未匹配回合降低有效动作的分数（−0.052），A–C 对比为 +0.070（95% CI [+0.012, +0.153]）。
- **匹配路由是主要增益来源**：在教师上下文固定为完整路径时，仅将 SDL 限制在匹配回合就将 ALFWorld Average@4 从 0.746 提升到 0.836；同数量随机选择仅有 0.723，未匹配回合路由也只有 0.750，从而排除了“稀疏性”假说。
- **上下文构建提供额外增益**：在匹配路由下，从完整路径切换到 SMRC 完整上下文（路径+状态摘要+候选）将 Average@4 从 0.836 进一步提升至 0.865。
- **结构化状态匹配优于历史匹配**：结构化状态将候选覆盖率从 15.4% 提升到 20.2%，保留了 98.8% 的历史匹配，同时拒绝 63 个因库存不匹配而无法执行的“历史相似”回合；在线端到端将 Average@4 从 0.756 提升到 0.865。
- **候选可执行性得到回放验证**：结构化状态匹配的 781/781 个候选+规范后缀样本全部成功回放完成，历史匹配为 792/800，失败案例均为“观测相似但执行进度不同”的别名状态。
- **主结果**：在 Qwen3-1.7B 上，ALFWorld Average@4 从 FullPath-SD 的 0.746 提升到 0.865，Pass@4 从 0.836 到 0.914；WebShop Score 从 0.694 到 0.825，Acc 从 0.574 到 0.693。Qwen2.5-3B 上增益同样存在。
- **附带收益**：SMRC-SD 的响应长度（78.8 tokens）接近 GRPO（79.5），远低于 FullPath-SD（142.6）和 Skill-SD（255.6），重复 4-gram 率仅 8.8%，显著低于 FullPath-SD 的 20.7% 与 Skill-SD 的 38.6%。

## 7. 优点

- **问题识别准确且具有普遍性**：状态–参考失配是特权 OPD 中一个容易被忽视的上游问题，论文用具体示例（Figure 1）与固定干预实验清晰地展示了该问题的存在与后果。
- **方法论干净、可解释**：SMRC-SD 不依赖学习的语义匹配或隐藏模拟器状态，而是用确定性、可审计的状态签名完成匹配与路由；每个设计选择（何时路由、如何构建上下文）都有对应的独立实验证据。
- **实验逻辑严谨、层层递进**：从固定状态干预建立因果证据 → 端到端主结果验证有效性 → 消融分离路由与上下文贡献 → 匹配器对比与回放审计排除替代解释。这种“先干预后训练，先消融后审计”的验证链条值得借鉴。
- **计算开销低、部署友好**：匹配与上下文构建仅在训练时 CPU 端运行（每匹配回合约 0.83 ms），推理无任何额外成本；教师上下文相比 FullPath-SD 仅增加约 21 个 token。
- **良好的泛化证据**：在具身（ALFWorld）与网页交互（WebShop）两个异质环境、两个不同模型家族上均取得一致改进，说明方法不依赖特定环境的过拟合。

## 8. 不足与局限

- **状态签名仍为手工设计**：论文承认签名与匹配规则是环境特定的手写规则，虽然接口统一，但迁移到新环境需要人工适配。尚未验证其在更复杂或开放领域的通用性。
- **参考轨迹的依赖**：方法假设每个训练任务都能获取一个成功参考路径。在真实世界中，成功轨迹的获取成本可能较高；论文未讨论参考缺失或参考质量较差时的降级策略。
- **覆盖率有限**：结构化状态匹配在 ALFWorld 归档回合中的匹配覆盖率约为 20.2%（WebShop 约 53.9%），这意味着大部分回合实际上未接受蒸馏，仅依赖 GRPO——匹配器的召回率上限未明确分析。
- **实验统计强度有限**：主要端到端结果均为单次运行（单种子），未报告多次重复的均值与方差；固定检查点（而非验证集选择）虽然避免了选择偏差，但也可能低估或高估最终性能。
- **未充分消融超参数**：λ_SDL、匹配的严格程度（字段检查的松紧）、最新位置选择策略等关键超参数的敏感性未做系统分析。
- **潜在偏差风险**：
  - 固定状态干预中的锚点来自训练 rollout，可能受策略分布漂移影响；
  - “匹配/未匹配”是操作性的 matcher 标签而非动作正确性标签，未匹配回合中也可能包含部分有害子集（论文承认未匹配并非全部有害）；
  - 教师上下文包含的“完整路径”本身可能引入任务级信息泄露风险，虽然论文证明 SMRC-SD 优于全路径无条件使用，但路径信息的长期影响未被追踪。
- **应用限制**：方法仅在文本环境（TextWorld/WebShop）中验证，未覆盖视觉具身环境或实时交互场景；状态签名依赖环境的确定性字段检查，在部分可观测或噪声观测环境中可能失效。
