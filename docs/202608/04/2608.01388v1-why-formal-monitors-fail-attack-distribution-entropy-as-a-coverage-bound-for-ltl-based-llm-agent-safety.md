## 摘要
基于线性时序逻辑（LTL）和有限自动机（FSA）的运行时安全监视器越来越多地被部署用于拦截LLM智能体中的不安全工具调用序列。然而，同样的监视器在某些模型架构上实现了68-75%的攻击覆盖度，而在其他架构上几乎为零，且无法从能力分数、训练数据或提示设计中得到解释。我们提供了缺失的理论。我们证明了任何固定不变式FSA监视器的召回率受限于攻击分布的集中度：即攻击被最常见的k个触发-完成模式覆盖的比例。当攻击集中时（低香农熵），一个小的固定不变式集合可以实现高召回率；当攻击分散在多个结构不同的模式中时（高熵），无论不变式如何推导，任何可处理大小的固定不变式集合都无法实现高召回率。我们在八个前沿LLM架构上验证了这一熵-覆盖度界。GPT类和后端DeepSeek产生高度集中的攻击（H ~ 0.24比特；一种模式覆盖96%），解释了68-75%的召回率；Gemini变体产生高熵分布（H ~ 2.81比特；7个簇各<=7%），解释了近零召回率（6-13%），且对架构匹配的重新训练具有不变性。熵解释了覆盖度方差的76%（Pearson r = -0.87，p = 0.005，95% CI [-0.98, -0.78]），在留一法下保持（r在[-0.91, -0.82]之间）。我们引入了一种部署前熵测试，可从少量攻击样本预测监视器覆盖度，从而在部署前实现架构感知的监视器选择。该界和测试与架构无关，适用于任何基于FSA的离散动作序列的运行时监视器。

## Abstract
Runtime safety monitors based on Linear Temporal Logic (LTL) and finite automata (FSA) are increasingly deployed to intercept unsafe tool-call sequences in LLM agents. Yet the same monitor achieves 68-75% attack coverage on some model architectures and near-zero on others, with no explanation from capability scores, training data, or prompt design. We provide the missing theory. We prove that the recall of any fixed-invariant FSA monitor is bounded above by the concentration of the attack distribution: the fraction of attacks covered by the k most frequent trigger-completion patterns. When attacks concentrate (low Shannon entropy), a small fixed invariant set achieves high recall; when they disperse across many structurally distinct patterns (high entropy), no fixed invariant set of tractable size can, regardless of how the invariants were derived. We validate this entropy-coverage bound across eight frontier LLM architectures. GPT-class and DeepSeek backends yield highly concentrated attacks (H ~ 0.24 bits; one pattern covers 96%), explaining 68-75% recall; Gemini variants yield high-entropy distributions (H ~ 2.81 bits; 7 clusters each <= 7%), explaining near-zero recall (6-13%), invariant to architecture-matched retraining. Entropy accounts for 76% of variance in coverage (Pearson r = -0.87, p = 0.005, 95% CI [-0.98, -0.78]), holding under leave-one-out (r in [-0.91, -0.82]). We introduce a pre-deployment entropy test that predicts monitor coverage from a small attack sample, enabling architecture-aware monitor selection before deployment. The bound and test are architecture-agnostic and apply to any FSA-based runtime monitor over discrete action sequences.

## 2. 论文提出的方法论

- **监视器形式**：LTL 公式形如 ϕ = G(T_trig → F[1,k](t_comp))，即"当触发集合 T_trig 出现后，在 k 步内不得出现被禁止的完成动作 t_comp"，编译为滑动窗口 FSA；监视器 M = {ϕ₁,…,ϕₙ} 在任一公式被违反时触发报警。
- **攻击分布建模**：将攻击轨迹抽象为"触发-完成模式"π = (T, t_c)，攻击分布 D 定义在这些模式的概率分布上。
- **定理 1（熵-覆盖度界）**：对任意含 n 条不变式的 FSA 监视器 M，其召回率不超过前 n 大概率之和：R(M,D) ≤ Cₙ(D) = Σᵢ₌₁ⁿ p\*ᵢ（p\*ᵢ 为排序后的模式概率）。证明要点：每个公式语义上对应一个触发-完成模式，n 个公式最多覆盖 n 个模式，而最优覆盖就是贪心选择前 n 个最可能模式。
- **推论 1**：最小可实现攻击成功率（ASR）满足 ASR_min(n) ≥ 1 − Cₙ(D)；当 H(D) ≥ log₂(n+1) 时，任何 n 不变式监视器都无法将 ASR 降至零。
- **命题 1**：若 D 近似均匀分布在 m 个模式上（高熵、大 m），则 Cₙ(D) ≈ n/m，即覆盖率随 n/m 线性衰减——这是结构性的容量约束，而非学习失败。
- **定理 2（熵-覆盖度对偶）**：H(D) ≥ H_b(Cₙ(D))（二进制熵函数）。推论：当 H(D) < 1 bit 时，Cₙ(D) > 0.5，即 FSA 监视器必然达到优于随机的覆盖率。
- **定理 3（部署前熵测试的样本复杂度）**：基于 Hoeffding 不等式，给出插值熵估计的误差界与样本量下界：N ≥ log₂²(m̂)·ln(2/δ)/(2ε²)。例如，m̂=3 簇、ε=0.3 bits、δ=0.05 时需 N≥51 条轨迹。
- **部署前熵测试协议**：①收集 ≥50 条攻击轨迹 → ②按 Jaccard 距离层次聚类（阈值 θ=0.4）提取模式 → ③计算经验熵 Ĥ → ④参考阈值：Ĥ<0.5 bits 表明 FSA 监视器适用；Ĥ>2.0 bits 则建议改用概率/神经监视器；0.5–2.0 为灰色区域，需按领域风险评估。

## 6. 论文的主要结论与发现

- **熵-覆盖度负相关**：攻击分布熵每增加 1 bit，FSA 监视器覆盖率显著下降；熵解释了 76% 的覆盖率方差（Pearson r = −0.87, p = 0.005）。
- **能力分数无预测力**：Elo 能力分数与覆盖率无显著相关，说明"更强的模型"不等于"更易被监视"。
- **GPT/DeepSeek 类：低熵可覆盖**：攻击高度集中（H≈0.19–0.31 bits，单一模式覆盖 93–98% 概率质量），固定 8 条不变量即可达到 50–75% 覆盖率。
- **Gemini 类：高熵不可覆盖**：攻击分布在大量结构不同的模式间分散（H≈2.64–2.81 bits，7 个簇各 ≤7%，60% 为孤立单例），理论上限仅 27–31%，实际覆盖率仅 6–13%。
- **重训练无效**：对 Gemini 做架构匹配的重训练后，覆盖率提升为 0.0 个百分点——因为分布本身未变，只是换了个不变量子集。
- **理论界的验证**：所有观测覆盖率均未超过 C₈(D̂) 上界，且通过 FPR 约束和分布不匹配两个因素合理解释了上界与实际之间的差距。
- **实用工具**：50–100 条攻击轨迹上的熵估计即可在部署前判断监视器是否适用，低熵架构（m̂≤3）仅需约 51 条轨迹即可达到 ±0.3 bit 精度。
