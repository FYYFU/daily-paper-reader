## 摘要
AI智能体在持久化环境中运行，早期状态变化可能影响远期的决策。与传统语言模型交互不同，智能体行为通过一个共享状态进行调节，该状态在长周期工作流中被反复修改和复用。当前的安全基准测试往往无法捕捉这些累积风险，因为它们侧重于短期的静态任务。为解决这些局限性，我们引入了OpenART，一个通过环境演化进行可扩展智能体红队测试的开放式竞技场。OpenART提供了跨越50个领域的超过10,000个经过验证的有状态场景，来源于超过500,000个工具和技能的池子。这些任务需要中位数97次工具调用，并支持在75种不同的智能体模型配置上进行统一评估。为系统性地探索这些不断演化的攻击面，我们提出了演化马尔可夫超图攻击（EMHA）。EMHA是一种黑盒策略，通过协调授权的状态转换来执行反馈驱动的环境演化，无需参数更新。在整个评估过程中，任务目标保持不变，仅环境状态发生变化。在所有配置中，EMHA实现了85.0%的汇总攻击成功率（ASR）。其相对于仅指令演化的优势从简单环境中的约2%增加到最复杂环境中的超过17%，表明随着任务复杂度的增长，环境演化日益暴露出安全失败。此外，我们的分析显示，智能体的具体运行时实现在很大程度上解释了超出底层模型能力之外的安全差异。这些结果将OpenART确立为在复杂、演化环境中研究智能体安全的可扩展基础。

## Abstract
AI agents operate in persistent environments where early state changes can influence decisions far into the future. Unlike conventional language-model interactions, agent behavior is mediated through a shared state that is repeatedly modified and reused across long-horizon workflows. Current safety benchmarks often fail to capture these cumulative risks because they focus on short, static tasks. To address these limitations, we introduce OpenART, an open-ended arena for scalable agent red teaming through environment evolution. OpenART provides over 10,000 validated stateful scenarios across 50 domains, drawing from a pool of more than 500,000 tools and skills. These tasks require a median of 97 tool calls and enable unified evaluation across 75 different agent-model configurations. To systematically explore these evolving attack surfaces, we propose the Evolutionary Markov Hypergraph Attack (EMHA). EMHA is a black-box policy that performs feedback-driven environment evolution by coordinating authorized state transitions without requiring parameter updates. Throughout the evaluation, task objectives remain fixed while only the environment state changes. Across all configurations, EMHA achieves a pooled Attack Success Rate (ASR) of 85.0%. Its advantage over instruction-only evolution increases from approximately 2% on simple environments to over 17% on the most complex ones, demonstrating that environment evolution increasingly exposes safety failures as task complexity grows. Furthermore, our analysis shows that the specific runtime implementation of an agent explains a significant portion of safety variation beyond the underlying model's capabilities. These results establish OpenART as a scalable foundation for studying agent safety in complex, evolving environments.

### 2. 方法论

#### 2.1 核心思想

- 将**场景（scenario）**而非单个提示作为评估的语义单元。一个场景封装：良性任务目标 + 可执行环境 + 隐藏安全契约。
- 场景保持目标无关（target-agnostic），在运行时通过**目标特定适配器**投射到不同智能体的原生接口。
- 环境演化过程中，**任务目标和安全契约固定不变**，仅改变目标可见的环境状态。

#### 2.2 场景构建

- 基于 O\*NET 职业分类和现有基准的操作场景建立 50 个领域的分类体系。
- 从 SkillNet 收集 50 万+ Tools、MCPs、Skills 组成能力语料库。
- Planner（LLM）将场景种子扩展为：场景模型 → 工作流 DAG → 初始环境 → 确定性评估器。
- 工作流 DAG 满足拓扑排序约束和复杂度目标；评估器通过真值表测试（安全完成=0，不安全泄漏=1）后方可准入。
- 最终生成 **10K 个经验证的场景**，人工专家审计中 99.3% 的评估器被判定正确。

#### 2.3 跨智能体运行时投射

- 15 个已部署智能体（OpenCode、Aider、Claude Code、Codex 等）× 5 个基础模型（GPT-5.5、Opus-4.8、GLM-5.2、Qwen-3.7-Max、DeepSeek-V4-Pro）= **75 个智能体-模型配置**。
- 适配器遵循公式 Π_r 的授权过滤（攻击向量支持、原生位置映射、运行时验证）。
- 支持 **8 个目标可见攻击向量**：Workspace、Instructions、Skills、Tools、MCPs、Short-Term Memory、Plan State、Long-Term Memory。

#### 2.4 EMHA（演化马尔可夫超图攻击）

- **黑盒参考策略**：不更新任何模型参数（目标模型和攻击者模型均冻结），通过外部攻击者状态实现测试时适应。
- **超图建模**：顶点为攻击子目标，超边连接前提子目标与后继子目标；路径采样满足马尔可夫性质。
- **反馈驱动路径学习**：使用软 Q 值策略平衡探索与利用，通过返回再分配（return redistribution）处理延迟奖励，最大化 K 轮内的最佳评估分数。
- **归档引导的图演化**：基于 MAP-Elites 的质量-多样性搜索，保留每个行为单元中的最优攻击，通过图编辑核生成后代。
- 整个流程中，任务目标 τ 和评估器 E_q 始终保持不变。

- **主要实验**：

### 6. 主要结论与发现

1. **环境演化有效暴露安全缺陷**：EMHA 在所有 75 个配置上的汇总 Strict ASR 达 **85.0%**。
2. **复杂度放大演化优势**：全环境演化相对于仅指令演化的优势从简单场景的 1.8–2.7% 增至最复杂场景的 17.2–17.6%，说明长周期工作流放大了持久状态演化的影响。
3. **运行时实现显著影响安全**：在控制基础模型和良性任务完成能力后，加入目标智能体身份额外解释 7.6% 的 ASR 变异（91.3% → 98.9%）。
4. **单向量 vs. 全演化**：最强单向量（Workspace）达到 92.5%，但全 EMHA 达 94.7%，证明协调多向量的环境演化优于任何单一攻击向量。
5. **长期安全漂移普遍存在**：环境变化的中位传播距离为 37 个动作，目标在 23% 执行进度处首次消费演化状态，而首次不安全输出出现在 64% 处，中位延迟达工作流的 41%。
6. **三类重复出现的漏洞**：
   - 过期假设未被撤销（计划-引用漂移、能力重绑定、检查点过期）；
   - 安全决策被传播而非重新计算（模式完整性被误认为安全性）；
   - 风险在长工作流中组合涌现（多个单独良性的变化组合导致不安全）。

### 7. 优点

- **范式创新**：将安全评估单元从提示/任务提升到可执行且可演化的环境，更贴近真实智能体部署场景。
- **规模与覆盖**：10K 场景、50 领域、500K+ 能力、75 配置，显著超越现有基准（DTap 仅 6,682 任务/14 域/2 智能体/4 向量）。
- **目标无关表示 + 轻量适配器**：在保持任务语义和评估标准一致的前提下实现跨异构运行时可控比较。
- **策略无关框架**：EMHA 仅是参考策略，环境演化接口支持任意黑盒搜索策略，具有良好的扩展性。
- **严格的评估协议**：确定性评估器 + 独立判断器双重确认；场景准入需通过真值表探测和人工审计。
- **分析深度**：不仅报告攻击成功率，还揭示了传播距离、延迟位置分布以及三类机制性漏洞，提供可操作的防御洞见。

### 8. 不足与局限

- **算力披露不足**：未提供 GPU 型号、数量或总计算成本，影响可重复性和资源评估。
