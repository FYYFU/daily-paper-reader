## 摘要
在线策略自蒸馏（OPSD）通过使用以参考解决方案为条件的模型特权视图来监督仅观察问题的学生视图，从而提升推理能力。然而，教师提供的标记级目标可能依赖于推理时不可用的参考特定信息。我们提出了问题空间引导的OPSD（PS-OPSD），用基于轨迹的引导（描述初始状态、目标条件、约束和选定的状态转换路径）取代完整解决方案。学生展开和OPSD目标保持不变。在三个数学推理基准和1.7B到8B的模型规模中，PS-OPSD在所比较的方法中取得了最高的聚合问题准确率。受控实验进一步表明，引导相关性和路径一致性对这些增益有所贡献，凸显了特权信息的表示作为OPSD中重要设计选择的作用。

## Abstract
On-policy self-distillation (OPSD) improves reasoning by using a privileged view of a model conditioned on reference solutions to supervise a student view that observes only the question. However, the teacher-provided token-level targets may depend on reference-specific information unavailable at inference time. We propose Problem-Space-Guided OPSD (PS-OPSD), which replaces the complete solution with trajectory-grounded guidance describing the initial state, goal conditions, constraints, and a selected state-transition path. The student rollout and OPSD objective remain unchanged. Across three mathematical reasoning benchmarks and model scales ranging from 1.7B to 8B, PS-OPSD achieves the highest aggregate question-only accuracy among the compared methods. Controlled experiments further indicate that guidance relevance and path coherence contribute to these gains, highlighting the representation of privileged information as an important design choice in OPSD.

## 1. 核心问题与整体含义（研究动机与背景）

**研究背景：**
- **在线策略自蒸馏（On-policy self-distillation, OPSD）** 是一种有效的推理训练范式：学生模型只观察问题生成轨迹，而同一模型的特权视图（teacher）可以读取已验证的参考答案，在学生生成的前缀上提供逐 token 级监督。这种机制避免了固定教师轨迹与推理时状态分布不匹配的问题，也不需要依赖外部更强的教师模型。
- **核心矛盾在于训练与部署的不对称性**：训练时教师能看到完整参考答案，推理时学生只能看到问题。完整解答中包含了大量**参考特定信息**——如特定的推导顺序、措辞、实例化计算、最终答案等——这些信息在推理时无法恢复，导致教师提供的 token 级目标可能"不可迁移"。
- **已有证据的支持**：近期研究表明，OPSD 训练出的模型在推理时可能显式引用不可见的参考答案、答案提示等，说明存在"特权信息依赖/泄漏"问题。

**核心研究问题：**
> 教师在训练时应该观察什么样的特权信息？——即**特权信息的表示方式**本身是决定蒸馏效果的关键设计变量，而不仅仅是蒸馏损失函数的设计。

**整体含义：** 该论文挑战了"越多特权信息越好"的直觉，提出以**问题空间结构（problem-solving structure）**而非完整解答轨迹作为特权信息的表示，从而在保持学生端和蒸馏目标不变的前提下，提升问题推断（question-only）时的泛化能力。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 核心思想

论文从经典**问题空间理论**（Newell & Simon 1972; STRIPS, Fikes & Nilsson 1971）出发，将数学问题概念化为一个形式化结构：

\[
P(q) = \langle S, s_0, O, G, C \rangle
\]

其中 \(S\) 是状态空间，\(s_0\) 初始状态，\(O\) 可用算子，\(G\) 目标条件，\(C\) 约束条件。**但**论文并不试图重建完整的问题空间（这需要枚举所有可达状态和算子），而是从**单条已验证参考轨迹**中提取其实例化的问题空间片段。

### 2.2 问题空间引导（Problem-Space Guidance）

离线提取器（使用 Qwen3.6-35B-A3B）将每个"问题+参考解答"对转换为如下四字段结构化表示：

\[
g_{PS}(q,r) = \langle s_0, G, C, \pi \rangle
\]

- **初始状态（Initial State）**：变量、实体、已知条件与关系；
- **目标条件（Goal Conditions）**：目标量及可验证的成功条件；
- **约束（Constraints）**：定义域限制、全域不变量与有效性条件；
- **选定状态转移路径（Selected State-Transition Path）**：有序列表 \(\pi = (\tau_1, ..., \tau_k)\)，每个转移记录为：
  \[
  \tau_i = (o_i, pre_i, transform_i, s_i)
  \]
  即算子名、前置条件、诱导变换、结果状态。

### 2.3 PS-OPSD 训练流程（Algorithm 1）

```
输入：数据集 D = {(q_i, r_i)}；固定教师 p_T；学生 p_θ；温度 T；裁剪阈值 c
1. 离线提取：对每个样本缓存 g_i ← g_PS(q_i, r_i)
2. 循环迭代：
   3. 采样一个小批量 B ⊂ {(q_i, g_i)}
   4. 对每个 (q, g)：
      - 学生从问题仅生成在线策略轨迹：ŷ ~ p_θ(· | q)
      - 对每个 token t：
        教师评估：p^PS_{T,t} = p_T(· | q, g, ŷ_{<t})
        学生评估：p_{θ,t} = p_θ(· | q, ŷ_{<t})
   5. 计算轨迹上的逐坐标裁剪 KL 损失
6. 仅更新学生参数 θ；教师和缓存引导保持固定
输出：训练好的仅问题学生 p_θ(· | q)
```

### 2.4 关键设计要点

- **学生端完全不变**：学生仍从问题生成在线策略轨迹，推理时不使用参考答案、引导信息、教师或提取器；
- **训练目标不变**：逐 token 的按坐标裁剪 KL 散度（clip-KL）蒸馏目标与 OPSD 完全一致——唯一的改动是**教师上下文中把完整解答替换为结构化的问题空间引导**；
- **提取过程离线完成一次**，训练时直接使用缓存引导，提取器不参与优化或推理。

## 3. 实验设计

### 3.1 数据集 / 基准（Benchmarks）

- **训练数据**：OpenThoughts 数学推理子集；
- **评估基准**：三个竞赛级数学推理基准——**AIME24、AIME25、HMMT25**；
- **评估指标**：每个问题存储 K=12 条仅问题生成结果，计算准确率（Accuracy = 100/(KN) × 正确生成数之和）。

### 3.2 模型规模

- **Qwen3-1.7B、Qwen3-4B、Qwen3-8B** 三个规模；
- 教师与学生使用相同模型家族和初始化；教师为初始 checkpoint 且禁用 LoRA、不追踪梯度；仅更新学生的 LoRA 参数。

### 3.3 对比方法

| 方法 | 说明 |
|------|------|
| Base | 未适配的 Qwen3 后训练 checkpoint |
| SFT | 监督微调 |
| GRPO | 序列级可验证奖励强化学习 |
| OPSD | 完整参考答案暴露给特权教师 |
| AVSD | 多视角共识+残差的蒸馏方法（方法级基线） |
| **PS-OPSD** | **本文方法：结构化问题空间引导替代完整解答** |

### 3.4 额外诊断与分析实验

- **表示控制实验（4B 主设置）**：
  - *Flattened PS*：去掉字段名、层级和步骤分隔符，保留内容与顺序；
  - *Mismatched PS*：用另一个问题的引导替换目标引导（按问题家族、难度、长度匹配）；
  - *Path-Corrupted PS*：保留每个转移的局部语义但打乱/不兼容组合转移路径，破坏全局路径连贯性；
- **问题级行为分析**：相对 Base 的 Better/Worse/Tied 计数、困难问题救援（hard-case rescue）、保留率（retention）；
- **显式特权信息调用率**：生成中是否显式引用不可见参考解答/答案/提示，分别统计训练集与留出验证集；
- **正确路径 token 熵分析**：比较沿正确路径的预测分布集中度。

## 6. 主要结论与发现

1. **PS-OPSD 在全部三个模型规模上取得最高的聚合 Avg**：超过最强基线的幅度为 1.54–2.04 个百分点（1.7B: 43.12；4B: 64.32；8B: 65.40）；在 9 个 scale–benchmark 单元中 6 个严格最高。
2. **引导相关性（relevance）至关重要**：Mismatched PS 在所有三个基准上均明显下降（Avg 61.76 vs. 64.32），证明目标相关的引导是核心增益来源。
3. **路径连贯性（coherence）也很重要**：Path-Corrupted PS 在所有三个基准上均低于 PS-OPSD（Avg 62.19），表明全局有序的状态转移路径对可迁移性的贡献。
4. **显式字段结构的作用是增量而非决定性的**：Flattened PS 与 PS-OPSD 差距较小（0.71 点），且在 HMMT25 上反而更高（47.22 vs. 45.83）。
5. **降低了对不可见参考信息的显式依赖**：OPSD 的 PI 调用率（训练集 3.0%、验证集 2.2%）显著高于 PS-OPSD（0.5%、0.4%）。
6. **能力提升不依赖更锐利的 token 分布**：正确路径熵分析表明，PS-OPSD 在 4B/8B 的覆盖增益并不伴随预测分布更集中，说明其增益来自更广泛/更多样的有效推理模式而非简单的"自信化"。
7. **核心结论**：**更多特权信息并不自动意味着更好**——将特权信息表示围绕问题求解结构组织，能为仅问题自蒸馏提供比暴露完整解答更强的接口。

## 7. 优点

- **问题定位精准**：将在策略自蒸馏的研究视角从"蒸馏损失如何设计"转移到"特权信息如何表示"，填补了一个此前未被系统关注的重要设计维度；
- **理论动机扎实**：建立在问题空间理论（Newell & Simon）和结构映射迁移理论（Gentner 的结构映射、Gick 和 Holyoak 的类比迁移）之上，方法有清晰的认知科学和 AI 规划理论基础；
- **方法简洁且侵入性极低**：只修改教师上下文，学生展开、蒸馏目标、推理接口全部保持不变，便于作为插件式改进嫁接到现有 OPSD 框架；
- **实验设计规范**：受控变体（Flattened / Mismatched / Path-Corrupted）设计精细，精准分离了内容相关性、字段结构和路径连贯性三个因素的贡献；
