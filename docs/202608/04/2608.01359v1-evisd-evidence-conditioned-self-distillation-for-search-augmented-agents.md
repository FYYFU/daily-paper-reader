## 摘要
基于结果的强化学习使搜索增强的语言智能体能够从可验证的最终答案中学习，但其轨迹级别的信用无法区分多轮搜索过程中单个动作的贡献。我们提出EviSD，一种证据条件自蒸馏框架，将实例级支持证据作为搜索动作的特权信息，并将黄金答案作为回答动作的补充特权。在训练期间，学生从原始上下文中采样动作，而同一模型作为特权教师在与动作对齐的上下文中重新评分这些动作。EviSD将分离的教师-学生差距转换为对结果派生的GRPO优势的有界修正，并且仅将其应用于生成的动作片段。这种设计局部化了特权引导，同时保留了由结果奖励确定的更新方向，无需辅助蒸馏目标或在推理时进行任何更改。在七个问答基准和跨越模型规模与代际的三个骨干网络上，EviSD在所有评估设置中实现了最高的宏平均精确匹配，比最强对比方法高出1.3-2.3个百分点，同时仅调制了6.7%-15.1%的响应令牌。代码可在https://github.com/JiananXie/EviSD获取。

## Abstract
Outcome-based reinforcement learning enables search-augmented language agents to learn from verifiable final answers, but its trajectory-level credit cannot distinguish the contributions of individual actions in a multi-turn search process. We propose EviSD, an evidence-conditioned self-distillation framework that uses instance-level supporting evidence as privileged information for search actions and golden answers as complementary privilege for answer actions. During training, the student samples actions from the original context, while the same model re-scores them as a privileged teacher under an action-aligned context. EviSD converts the detached teacher--student gap into a bounded correction to the outcome-derived GRPO advantage and applies it only to generated action spans. This design localizes privileged guidance while preserving the update direction determined by the outcome reward, without an auxiliary distillation objective or any change at inference time. Across seven question-answering benchmarks and three backbones spanning model scales and generations, EviSD achieves the highest macro-average Exact Match in all evaluated settings, outperforming the strongest compared methods by 1.3--2.3 points while modulating only 6.7%--15.1% of response tokens. Code is available at https://github.com/JiananXie/EviSD.

## 一、论文的核心问题与整体含义

- **研究背景**：检索增强生成（RAG）将语言模型与外部证据连接起来，而搜索增强推理智能体进一步将检索转化为顺序决策过程——智能体在内部推理与外部检索之间交替，自主决定何时搜索、搜索什么以及何时已收集到足够证据来回答问题。近年来，基于结果的强化学习方法（如GRPO）使得这类智能体能够通过可验证的最终答案奖励进行训练。
- **核心问题**：结果型强化学习仅提供**轨迹级别的信用反馈**，即只告诉模型整个轨迹成功与否，无法区分多轮搜索过程中**单个动作的具体贡献**。具体问题包括：哪次搜索暴露了有用的证据？哪些生成的token对答案有贡献？正确回答是因为有效的搜索策略还是幸运的轨迹？这种信用分配的粗粒度问题在多轮搜索中尤其突出——一个早期的精准查询可能为后续所有推理提供关键段落，而模糊或冗余的查询则会留下信息不足的轨迹。
- **论文意义**：EviSD通过引入**实例级支持证据作为特权信息**，实现了对动作级别信用的细粒度调制，在保留结果型RL的更新方向的同时，使搜索和回答动作获得更精准的信用校正。该方法在多个基准和模型规模上均取得最优或接近最优的性能，且不增加任何推理时开销。

## 二、论文提出的方法论

### 核心思想

EviSD的核心思想是让**同一个模型同时扮演学生和特权教师**，利用训练数据中标注的支持证据（supporting evidence）和黄金答案（golden answers）作为特权信息，对基于结果的GRPO优势进行**有界的、动作局部化的信用调制**，从而在不改变更新方向的前提下细化动作级别的信用分配。

### 关键技术细节

论文围绕两个核心设计决策展开：

**① 什么信息作为特权（What）：实例级证据作为搜索动作的特权信息**

- 对于搜索动作，教师上下文使用当前QA实例的**标注支持证据**（按源文档分组，最多保留2个文档、每文档2个句子）。
- 对于回答动作，教师上下文使用**黄金答案**（含别名）。
- 对于无效或不支持的动作，教师上下文与学生上下文相同，差距为零。
- 教师特权上下文通过将动作特定的提示前缀前置到原始上下文中构造，不改变交互历史。

**② 如何将特权引导转化为信用（How）：动作局部化 + 结果锚定的调制**

- **教师-学生对比**：学生从原始上下文采样动作，教师在同一响应下使用特权上下文重新评分，计算分离梯度的token级对数似然比：
  - δ = sg[log πθ(yt|privileged context) − log πθ(yt|original context)]
  - 正值表示token与特权上下文更兼容，负值表示不一致。
- **动作跨度局部化**：通过二元动作掩码（action mask），只有生成的搜索和回答动作的内容token接受特权信用调制；推理token、分隔符、检索到的段落等均保持原始GRPO信用。
- **有界调制函数**：将蒸馏信号通过 bounded 函数映射：
  - gτ(δ) = tanh(τδ)，τ控制敏感性
  - ΔA = λ|A|·gτ(δ)·m_act
  - Â = A + ΔA
  - 由于ΔA ≤ λ|A|且λ<1，调制**不能反转原始优势的符号**——GRPO结果决定更新方向，特权信号仅调制每个动作token的信用强度。

### 训练目标

EviSD将调制后的信用Â代入标准GRPO裁剪目标：

J = E[min(ρ·Â, clip(ρ, 1−η, 1+η)·Â)] − β·KL(πθ∥π_ref)

1. **性能领先**：EviSD在所有评估设置中获得最高宏平均EM，比最强对比方法高1.3–2.3个百分点，且跨模型规模（3B/7B/1.7B）和代际（Qwen2.5/Qwen3）一致。

## 七、优点

- **方法设计简洁优雅**：同一模型既当学生又当教师，无需额外教师模型；不需要辅助蒸馏目标。
