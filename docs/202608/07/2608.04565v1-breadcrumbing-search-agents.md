## 摘要
基于LLM的搜索代理广泛用于信息检索任务，但它们对外部工具返回的依赖引入了严重的安全风险：执行过程中检索到的网络内容不可信，使代理面临提示注入和目标劫持。以往关于搜索代理安全性的工作主要集中于静态网络内容注入，但现代代理会发出后续查询并交叉核对相互竞争的信息源，因此单个被注入的页面往往会被稀释或拒绝。我们表明，传递搜索和页面观察结果的通道是一个脆弱的安全边界：除了让代理暴露于单个被投毒的页面之外，中介化的搜索接口还可以反复引导代理如何收集证据并形成最终答案。在受限的工具中介威胁模型下，当证据在代理的轨迹上被协调时，每次查询仅附加一个受控结果便可显著提高攻击成功率。我们通过一个策略驱动的长时域攻击系统研究这一设置，并引入了Authority-Chain Hijack (ACH)，这是一种专家精炼的策略，将孤立的搜索结果和页面内容操纵转化为在看似相互佐证的来源之间的一致证据链。ACH在所有基线中取得了最高的总体ASR，在完整SafeSearch测试分割上达到55.9% / 83.3%的ASR / MaxN ASR。我们进一步引入了Trace-Guided Strategy Evolution (TGSE)，它根据执行轨迹自动改进攻击者策略，用轨迹驱动的精炼替代手动重新设计；其最强单一设置在保留评估中达到71.4% / 95.0%。

## Abstract
LLM-based search agents are widely used for information-seeking tasks, but their reliance on external tool returns introduces a critical security risk: web content retrieved during execution is untrusted, exposing agents to prompt injection and goal hijacking. Prior work on search-agent safety primarily focuses on static web-content injection, but modern agents issue follow-up queries and cross-check competing sources, so a single injected page is often diluted or rejected. We show that the channel delivering search and page observations is a fragile security boundary: beyond exposing the agent to a single poisoned page, a mediated search interface can repeatedly steer how the agent gathers evidence and forms its final answer. Under a constrained tool-intermediary threat model, appending only one controlled result per query can substantially increase attack success when the evidence is coordinated across the agent's trajectory. We study this setting with a strategy-driven long-horizon attack system and introduce Authority-Chain Hijack (ACH), an expert-refined strategy that turns isolated search-result and page-content manipulations into a coherent evidence chain across seemingly corroborating sources. ACH achieves the highest Overall ASR among all baselines, reaching 55.9% / 83.3% ASR / MaxN ASR on the full SafeSearch test split. We further introduce Trace-Guided Strategy Evolution (TGSE), which automatically improves attacker strategies from execution traces, replacing manual redesign with trace-driven refinement; its strongest single setting reaches 71.4% / 95.0% in held-out evaluation.

# 《Breadcrumbing Search Agents》论文总结

## 1. 核心问题与研究动机

- **背景**：基于 LLM 的搜索代理（如 Tongyi DeepResearch）依赖外部搜索和网页浏览工具，在运行时自主决定查询内容与访问页面，最终答案基于完整的观察链（observation chain）而非仅仅依赖模型本身。
- **核心安全风险**：搜索代理在运行时检索到的网络内容不可信，容易遭受**提示注入（prompt injection）**和**目标劫持（goal hijacking）**攻击。
- **现有研究的不足**：
  - 此前工作（如 SafeSearch、WARP、FORGE）主要关注**静态网页内容注入**——恶意内容在攻击前就被固定下来。
  - 但现代搜索代理会发出后续查询、交叉核对竞争性来源，单个被注入的页面往往会被稀释或拒绝。
  - 因此，针对静态注入的攻击评估**高估了搜索代理的实际安全性**。
- **本文提出的新威胁**：搜索代理无法直接观察网络，而是通过外部搜索和浏览服务提供的中介接口（mediated interface）获取信息。这一观察通道是**脆弱的安全边界**。在受限的**工具中介攻击（tool-intermediary attack）**威胁模型下，攻击者可在每次查询中附加一个受控的搜索结果，并动态维护其落地页内容，从而在代理的整个搜索轨迹中反复引导其如何收集证据和形成最终答案。

## 2. 方法论

### 2.1 威胁模型与问题设定

- 每个基准案例表示为 `c = (x, e, g, K)`：`x` 为良性查询，`e` 为安全预期响应，`g` 为攻击者目标，`K` 为最终答案需满足的检查清单（checklist）。
- 受害代理在事件 `t` 时选择动作 `a_t ∈ {SEARCH(q), VISIT(u), ANSWER(y)}`。
- **攻击者权限约束**：
  - 每次搜索最多追加**一个**攻击者控制的搜索结果（追加到约 10 个自然搜索结果之后）
  - 攻击者可为**自己引入的 URL** 提供动态生成的页面内容
  - 自然搜索结果和自然页面内容**不可被篡改**
  - 成功标准遵循 SafeSearch：最终答案必须满足检查清单 K，而非仅仅让代理"看到"攻击内容

### 2.2 攻击者运行时（Attacker Runtime）

- **有状态、策略驱动**：攻击者维护轨迹记忆 `M_t`（记录先前的查询、访问、原始返回、生成的负载、反思），并结合活动策略 `s` 和规划器 `P` 生成事件级负载与反思：
  `(p_t, ρ_t) = P(a_t, o_t, M_t, s, c)`
- **三条事件路径**：
  1. 搜索干预：在自然结果列表后追加合成搜索结果
  2. 可攻击访问（访问先前注入的 URL）：返回动态生成的页面内容
  3. 只读访问（访问自然 URL）：不作内容修改，仅记录观察并生成反思

### 2.3 策略表示与 ACH（Authority-Chain Hijack）

- **策略（Strategy）**是攻击者的宏观轨迹级导航策略，指导规划器如何解释受害者当前的信息需求和如何衔接先前已注入的证据。
- **ACH 是专家精炼的策略**，核心思想：
  - 将孤立的搜索结果和页面内容操纵转化为**跨越多个看似相互佐证来源的一致性证据链**
  - 通过"面包屑"方式引导代理依次经过可信来源、验证步骤和最终综合阶段
  - 关键机制：当受害者发现矛盾或警示信息时，后续受控页面将其重新框定为"过时"或"相关性较低"的证据，而非直接反驳
  - ACH 分三个阶段：权威建立（Stage 1）→ 验证捕获（Stage 2）→ 信任巩固与引导整合（Stage 3）

### 2.4 TGSE（Trace-Guided Strategy Evolution）

- **核心观察**：策略质量对攻击成功至关重要，而攻击轨迹包含了成功与失败的信息。
- **算法流程**（DGM 启发的档案搜索）：
  1. 评估初始策略 `s0` 并构建轨迹反馈包 `D(s0)`
  2. 初始化档案库（archive）`A ← {(s0, D(s0))}`
  3. 每一代：从档案中采样父策略 → 生成子策略 `s' = E(s, D(s))` → 在低成本子集上评估 → 通过门槛后进行全面评估 → 成功的子策略加入档案，可成为未来父策略
- **轨迹反馈包**：压缩攻击轨迹 `τ̄`，记录攻击者负载、决策以及代理的搜索/访问/回答行为，基于最终答案的成败标签 `z`
- **低成本门槛（cheap-stage gate）**：设硬性回归条件，拒绝明显变差的子策略，控制评估成本
- **关键设计**：TGSE 演化的对象是攻击**策略本身**，而非单个负载；生成的语言策略在测试时冻结，但生成的搜索/访问负载仍依赖运行时的状态。

## 6. 主要结论与发现

1. **ACH 显著超越所有静态和冻结内存基线**：
   - 在完整测试分割上，Qwen3 受害者下 ACH 达到 55.9% / 83.3% ASR / MaxN ASR

   - 例外：Prompt-Injection 家族中 AgentDojo 片段在某些单元格更优（因为该家族奖励直接标记或格式服从）

2. **ACH 通过打破两个轨迹门控取得成功**：
   - 静态攻击或在注入页未被访问时失败（点击门），或在访问后被稀释（保留门）
   - ACH 同时提高注入访问率和访问后成功率

3. **攻击者与受害者模型均影响攻击效果**：
   - 攻击端：更强的攻击者后端获得更高的平均 ASR（Kimi 最强，Qwen3.5-9B 最弱）
   - 受害者端：不是镜像关系——Qwen3 和 Qwen3.5-9B 虽暴露率相似但访问转化更高、更易受攻击；Kimi-K2.5 更稳健；Gemma4-31B 较少使用 Visit 工具，主要受搜索片段影响

4. **TGSE 提供额外的持有集增益**：
   - Normal TGSE 将总体 ASR / MaxN ASR 从 56.0% / 85.0% 提升至 70.0% / 93.0%
   - Trace-warm TGSE 达到最高单一设置结果：71.4% / 95.0%
   - 每家族最佳观察结果上界为 77.4% / 96.0%，显示家族条件化路由的潜在收益

5. **不同家族受益于不同的 TGSE 先验**：
   - Injec 最受益于 Trace-warm（将标记变为可复制的输出工件）
   - Bias 和 Misinfo 更受益于 Adv-train（保持虚假来源与主张的绑定）
   - Ads 在验证压力下可能受损（变得更比较性而非直接推荐）
   - Harm 即使使用 Adv-warm 也仍然困难（受害者常将最终答案转回安全警告）

6. **策略质量和记忆具有互补作用**：
   - 在固定运行时下，ACH 优于所有策略替换；糟糕的策略比通用 dummy 策略更差
   - 移除反思影响小，移除记忆显著降低 ASR，移除策略输入导致最大降幅

## 7. 方法亮点与贡献

1. **提出新颖且现实的威胁模型**：受限工具中介攻击模型比全局控制搜索接口更贴近实际（以个性化赞助商结果为例），具有较强的现实可落地性
2. **从静态到动态的范式升级**：率先研究适应受害者轨迹的长期攻击，而非固定的单页注入；弥补了现有搜索代理安全性研究中的关键空白
3. **ACH 策略的设计**：将攻击模式提炼为显式的多阶段策略，将验证步骤转化为受控的佐证步骤，形成跨来源一致的证据链
4. **TGSE 创新**：首次将 DGM 风格的多谱系树搜索应用于攻击策略的自动进化；以轨迹反馈驱动策略迭代，取代手动重设计
5. **丰富的诊断体系**：轨迹门控分析（点击门 vs. 保留门）、跨模型矩阵、跨架构转移、跨基准验证等多种视角提供机理层面的深入理解
6. **成本收益分析**：与动态基线比较时 ACH 仅使用第二少的攻击者 token 和调用次数，说明有效性并非简单地由推理预算堆砌所致

## 8. 不足与局限

1. **受控环境而非真实攻击**：
   - 评估基于模拟的中介接口，而非真正部署的落地页和搜索基础设施
   - 实际平台控制可能使反复暴露更困难，ASR 衡量的是基准漏洞而非真实世界攻击成功率

2. **TGSE 的受害者条件化问题**：
   - TGSE 是受害者条件化的策略搜索，从某一受害者轨迹演化出的策略可能过度专化于该受害者的失败模式
   - 跨受害者转移结果混合（Gemma 和 Qwen3.5 改善，MiniMax 中性，DeepSeek 下降），表明不具备模型无关的泛化保证

3. **离线计算成本高**：
   - 评估档案候选需要重复的端到端滚动和评审，单个家族约 1,200 条轨迹，计算开销显著

4. **防御仍是开放问题**：
   - 论文仅讨论提示级和工具级缓解方向，未提供系统的防御评估
   - 提出的"将工具输出视为不可信证据"的缓解措施本身也有可能在过度使用时削弱搜索代理的正常功能

5. **基线可比性**：动态基线属于"adapted"方法，并非原始方法的精确复制；作者明确承认这些不是计算量或状态匹配的因果控制，削弱了与这些方法比较的严格性

6. **数据分割与外部效度**：训练与测试分割较小，OpenWeb 过滤规则由作者自行定义，可能影响结果的可推广性。
