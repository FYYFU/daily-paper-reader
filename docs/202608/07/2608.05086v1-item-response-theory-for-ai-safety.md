## 摘要
语言模型在安全行为方面存在差异，这些差异通过安全基准来衡量。然而，聚合的基准分数难以信任和解释，因为基准之间相互重复、高度相关，而且模型在检测到评估时可能会故意表现不佳（sandbagging）。为解决这些问题，我们借鉴了项目反应理论（IRT），这是一种统计工具包，用于根据具有推断心理测量属性的项目上的表现来测量这些潜在特质。我们将IRT模型拟合到192个语言模型的八个安全基准上，这是迄今为止对LLM安全评估进行的最大规模心理测量分析，并贡献了三个结果。首先，我们发现拒绝严格性、真实性和情境危害这三个可解释因素解释了模型间跨基准的大部分方差。其次，心理测量学选择的项目以比同规模随机子集更低的误差恢复完整的基准分数，且对于几个单独的基准而言，大约十个自适应选择的项目就足够了，将评估成本降低了97-99%。第三，IRT支持对单个模型的审计，表明它可用于检测天真的sandbagging以及API背后模型的变化。总体而言，我们展示了IRT是一个现成的工具包，用于阅读、简化和审计安全基准，我们建议前沿实验室和评估者采用。

## Abstract
Language models differ in how safely they behave and these differences are measured by safety benchmarks. But aggregated benchmark scores are hard to trust and interpret, because benchmarks duplicate one another, correlate heavily, and models may sandbag when they detect evaluation. To address these issues, we draw on Item Response Theory (IRT), a statistical toolkit for measuring these latents from performance on items with inferred psychometric properties. We fit IRT models to eight safety benchmarks across 192 language models, the largest psychometric analysis of LLM safety evaluations to date, and contribute three results. First, we find that three interpretable factors of refusal strictness, truthfulness, and contextual harm explain most of the variance between models across benchmarks. Second, psychometrically selected items recover full benchmark scores with lower error than random subsets of the same size, and roughly ten adaptively chosen items suffice for several individual benchmarks, cutting evaluation cost by 97-99%. Third, IRT supports audits of individual models, showing that it can be used to detect naive sandbagging and changes of model behind APIs. Overall, we show IRT is a ready-made toolkit for reading, reducing, and auditing safety benchmarks, which we recommend frontier labs and evaluators adopt.

## 论文核心问题与整体含义

- **背景与动机**：LLM 存在多样化的安全行为差异，通常用安全基准来量化。然而现有安全基准的聚合分数存在三大问题：
  - 基准之间高度重复、强相关，导致聚合分数过度加权了重复测量的行为；
  - 模型可能“sandbag” —— 在检测到评估时故意改变行为，使分数失真；
  - 聚合分数掩盖了安全行为之间的实质性权衡（如“拒绝有害请求”与“避免过度拒绝”可能相互对立）。
- **整体含义**：论文主张将教育心理学中的项目反应理论（IRT）系统引入 LLM 安全评估，用统一的测量模型来**解读（read）、压缩（reduce）和审计（audit）**安全基准，使安全评测具备可解释性、高效率与可信性。

## 论文提出的方法论

### 核心思想
- 将语言模型视为“被试（test-taker）”，将基准的每个提示视为“项目（item）”，将得到基准奖励的安全回答视为“正确作答”。
- 通过 IRT 模型同时估计**每个模型的潜在安全能力（θ）**、**每个项目的难度（b）**和**区分度（a）**，从而在统一量表上比较模型、选择信息量最大的项目、检测异常作答模式。

### 技术细节
- **2PL 模型**：\( P(x_{mj}=1|\theta_m,a_j,b_j)=\sigma(a_j(\theta_m-b_j)) \)，其中 σ 是逻辑斯蒂函数。1PL 模型被数据拒绝，而 3PL/4PL 未改善拟合，因此选用 2PL。
- **正则化**：为防止在“项目多、模型少”（192 个模型、数千项目）条件下的参数发散，对区分度施加 log-normal 先验、对截距施加 normal 先验。分半验证表明正则化显著提升参数稳定性。
- **潜在能力推断**：对每个基准拟合独立 2PL，得到每个模型的 8 个基准能力，再对能力矩阵进行最小残差因子分析（oblimin 旋转），并用 RMSEA、CFI 和 Horn 平行分析确定因子数量。
- **基准压缩**：
  - **静态测试**：从全量项目中挑选在能力区间上信息量最大的固定项目子集。
  - **计算机化自适应测试（CAT）**：根据当前能力估计，逐题选择 Fisher 信息最大的项目，实时更新能力估计。
- **审计方法**：
  - **人拟合统计量（person-fit，lz）**：检测“容易题答错、难题答对”这种不符合能力模型的反应模式，用于识别选择性 sandbagging。
  - **能力漂移（ability shift）**：将新测试重新估计的 θ 与历史 θ 比较，检测均匀 sandbagging 或模型替换。
  - **行为指纹（response fingerprint）**：用预选项目上的逐题作答与参考模型的作答比对，识别即使能力匹配的模型替换。

## 实验设计

- **数据集 / 基准**：
  - 共 8 个安全基准，5,255 个原始项目，预处理后 5,067 个有方差项目。
  - 覆盖四类行为：有害请求拒绝（AdvBench、HarmBench、SORRY-Bench、Do-Not-Answer、AHB）、过度拒绝（OR-Bench-Hard）、情境危害（Health-ORSC）、真实性（TruthfulQA）。
- **模型**：
  - 共 192 个聊天模型（OpenRouter API 调用，温度 0，最大生成长度 1024 tokens），涵盖开源权重模型（1B～约 1T 参数）与闭源 API 模型（GPT、Claude、Gemini、Grok 等）。
  - 169 个模型用于跨基准分析，134 个模型用于因子分析和 MIRT 拟合。
- **对比方法**：
  - 基准压缩：对比**随机项目子集（100 次随机采样）**、**静态测试**与**CAT**，在固定预算（k 个项目）下评估分数恢复误差（RMSE）与排名恢复（Spearman ρ），并采用 20 次随机分裂（75% 校准、25% 测试）的 held-out 设置。
  - 审计：对 sandbagging，比较**均匀、针对性、触发式**三种作用范围，以及**plain、persona、incentive** 三种提示框架；对 API 审计，比较三种方法（lz、能力漂移、指纹）。
- **评估指标**：分数恢复 RMSE、排名 Spearman 相关、检测率（在 10% 假阳性率下）、模型对区分度等。

## 论文的主要结论与发现

1. **安全基准测的不是单一能力**：八个基准无法被一个“总体安全能力”概括。三个可解释因子——**拒绝严格性（refusal strictness）**、**真实性（truthfulness）**和**情境危害（contextual harm）** 解释了 77% 的能力方差。HarmBench/SORRY-Bench/AHB 与 OR-Bench-Hard 构成一个双极端轴（后者是反向的拒绝严格性）；TruthfulQA 与 Do-Not-Answer 构成真实性因子；AdvBench 与 Health-ORSC 构成情境危害因子。
2. **基准可以被大幅压缩**：
   - 三个固定的 25 项测试（共 75 项，不到全量 2%）可分别估计三个潜在能力，排名恢复 ρ=0.83～0.94。
   - 对若干单项基准，约 10 个自适应项目即可高精度复现满分成绩，评估成本降低 97–99%。
   - 合成总分必须注意方向对齐：例如翻转 OR-Bench-Hard 方向后，25 个自适应项目的排名恢复从 ρ=0.79 提高到 0.96。
3. **IRT 可用于审计**：
   - person-fit 能捕获 80–100% 的针对性/触发式 sandbagging，但对均匀 sandbagging 效果有限（35% 检出）；
   - 结合历史能力估计的能力漂移检测可捕获均匀 sandbagging，组合测试总检出率可达 94–97%；
   - 行为指纹能在“能力匹配”的模型对中，仅凭 500 个项目的逐题应答区分 13/14 个模型身份，并能识别 API 端点背后的行为漂移。

## 优点

## 不足与局限

- **样本规模限制**：纳入因子分析的模型数为 134 个，虽在 LLM 领域较大，但远小于人类心理测量学通常的样本量，可能影响参数稳定性和因子结构判断（论文也承认难以在“2 因子 vs 3 因子”间做最终裁决）。
- **sandbagging 检测局限**：检测对象是基于提示的“模型生物”，而非经过专门训练、能力更强的对抗性模型；真实场景中的隐蔽 sandbagging 可能更难捕捉。person-fit 对均匀 sandbagging 的检测率较低，需要依赖外部历史能力估计。
- **基准代表性有限**：压缩测试的效率不能自动扩展为新场景或未来更强的模型——项目参数会过时，需要重新校准。
- **聚合分数仍需主观权重**：论文指出任何聚合分数都承载权重选择，但未提出解决价值权衡的完整方案，只建议评估者单独报告能力并论证加权方式。
- **API 审计边界**：行为指纹识别的是“行为连续性”而非“权重身份”，且对重复采集的随机波动需要单独校准；无法保证能对抗专门训练出的规避方法。
- **算力与成本细节缺失**：论文未报告具体推理或拟合算力，不利于其他团队据此估算复现成本。
