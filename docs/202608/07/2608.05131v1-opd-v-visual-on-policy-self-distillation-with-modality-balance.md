## 摘要
在策略自蒸馏（OPSD）已成为提升多模态大语言模型（MLLMs）视觉推理能力的标准后训练方法。现有方法从多样化的输入来源中提取特权信息以指导自蒸馏，然而这些设计忽视了模态不平衡——这是MLLM推理中固有的挑战。当文本信息主导生成时，模型无法充分整合其多模态输入，导致精心设计的特权信息未被充分利用，从而限制了OPSD的有效性。为探究这一局限，我们构建了具有缩放图像的正面教师模型和具有掩码图像的负面教师模型，它们表现出不同程度的模态不平衡。其推理正确性与令牌逻辑值的变化表明，模态平衡本身即可作为特权信息。基于这一发现，我们引入了OPD-V，一种通过正面教师模型和负面教师模型实例化此类信息的视觉OPSD范式。正面模态平衡逻辑值间隔定义了模态平衡信任区域，用于选择进行自蒸馏的在策略令牌。在6个基准、4个MLLM主干网络和5种后训练方法上的实验表明，OPD-V在降低训练成本的同时持续提升了推理性能。

## Abstract
On-Policy Self-Distillation (OPSD) has become a standard post-training approach for improving visual reasoning in multimodal large language models (MLLMs). Existing methods draw privileged information from diverse input sources to guide self-distillation. Yet these designs overlook Modality Imbalance, a challenge inherent to MLLM reasoning. When textual information dominates generation, the model cannot fully integrate its multimodal input. Consequently, carefully designed privileged information remains underused, limiting the effectiveness of OPSD. To examine this limitation, we construct a Positive Teacher with the Zoom-In Image and a Negative Teacher with the Mask Image, which exhibit different degrees of Modality Imbalance. Changes in their reasoning correctness and token logits reveal that Modality Balance can itself serve as privileged information. Motivated by this finding, we introduce OPD-V, a visual OPSD paradigm that instantiates such information through the Positive Teacher and Negative Teacher. Positive Modality-Balance Logits Margins define a Modality-Balance Trust Region that selects the on-policy tokens used for self-distillation. Experiments across 6 benchmarks, 4 MLLM backbones, and 5 post-training methods show that OPD-V consistently improves reasoning performance while reducing training cost.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：在策略自蒸馏（On-Policy Self-Distillation, OPSD）已成为多模态大语言模型（MLLMs）后训练阶段提升视觉推理能力的标准方法。OPSD 的核心思路是：学生模型采样自身轨迹，利用同一模型的冻结副本（教师）在学生对策略前缀上提供密集的分布级监督信号。教师模型可获得仅训练时存在的特权信息（如参考答案、证据区域裁剪图等），从而无需外部教师模型。
- **核心问题**：现有视觉 OPSD 方法（如 Vision-OPD、VA-OPD、Visual-OPSD 等）在构造特权信息时，**普遍忽视了模态不平衡（Modality Imbalance）** 这一 MLLM 推理固有的挑战。所谓模态不平衡，是指模型在生成时不成比例地依赖文本上下文（语言先验），而非充分整合视觉与文本两种模态的信息。当文本信息主导生成时，即使教师获得了精心设计的额外视觉特权信息，模型也未能有效利用这些信息，从而限制了 OPSD 的蒸馏效果。
- **核心研究问题**：在模态不平衡条件下，应如何设计特权信息，使其对 MLLM 的 OPSD 依然有效？论文的核心答案是：**将模态平衡本身作为一种特权信息**——即利用模型内部视觉/文本注意力分配状态，构造可用于 token 级蒸馏监督的信号。

## 2. 方法论：OPD-V 框架

### 2.1 核心思想
OPD-V 将 **模态平衡程度** 转化为可计算的、显式的教师输入差异，并据此筛选蒸馏目标。通过设计两个教师视图——**正教师（Positive Teacher）** 和 **负教师（Negative Teacher）**——它们分别接受**缩放图（Zoom-In Image）** 和**掩码图（Mask Image）** 作为视觉输入，二者对同一学生生成 token 的打分差异即可反映模态平衡的方向性信号。

### 2.2 关键技术细节

**（1）双教师构造**
- 学生接收**原始图像（Original Image）**，采样在策略轨迹：$y = (y_1, \dots, y_T) \sim p_\theta(\cdot \mid I, x)$。
- **正教师**接收**缩放图** $I_{zoom}$（证据区域裁剪并放大），提供蒸馏目标分布 $q^{+}_t(\cdot) = p_{\bar\theta}(\cdot \mid I_{zoom}, x, y_{<t})$。
- **负教师**接收**掩码图** $I_{mask} = \text{Mask}(I_{zoom})$（在缩放图上随机遮盖矩形区域），提供对比参照分布 $q^{-}_t(\cdot) = p_{\bar\theta}(\cdot \mid I_{mask}, x, y_{<t})$。
- 两个教师共享相同的文本查询、在策略前缀和 EMA 参数，因此其分布差异纯粹来自图像操作。

**（2）模态平衡信任区域（Modality-Balance Trust Region）**
- 对每个在策略 token $y_t$，计算**模态平衡对数边际（Modality-Balance Logits Margin）**：
$$\delta^{MB}_t = \log q^{+}_t(y_t) - \log q^{-}_t(y_t)$$
- 当 $\delta^{MB}_t > 0$ 时，说明该 token 在视觉证据被放大后获得的支持高于视觉线索被掩码后所获支持，即该 token 的预测更依赖视觉证据，被纳入信任区域：
$$\mathcal{R}_{MB}(y) = \{ t \in \mathcal{T}_y \mid \delta^{MB}_t > 0 \}$$

**（3）OPD-V 蒸馏目标**
- 仅在被选择的信任区域内，从正教师分布向学生分布施加 **Jensen–Shannon 散度** 蒸馏，且边际值 $\delta^{MB}_t$ 作为该 token 蒸馏损失的权重：
$$\mathcal{L}_{OPD\text{-}V}(\theta) = \mathbb{E}\left[ \frac{1}{\sum_{t} r_t} \sum_{t \in \mathcal{R}_{MB}(y)} r_t \, \delta^{MB}_t \, D_{JS}\left( q^{+}_t, \, p_{\theta,t} \right) \right]$$
- 教师参数通过学生权重的指数移动平均（EMA）更新，无需额外模型参数。

**（4）Top-K 蒸馏策略**
- 为避免全词表 logit 蒸馏的高内存开销，仅保留学生分布的前 K=100 个 logits 及其对应的教师概率，并以尾概率桶补充剩余词表质量，近似无损失地降低内存需求。

### 2.3 算法流程（文字描述）
1. 初始化教师参数为学生参数副本。
2. 每个训练步：采样小批量数据；对每个样本，从训练数据中获取缩放图 $I_{zoom}$，并生成掩码图 $I_{mask}$。
3. 对每个提示采样 n=8 条在策略轨迹。
4. 对轨迹中的每个 token：同时计算学生分布、正教师分布、负教师分布。
5. 计算模态平衡对数边际，若为正且属于生成响应 token，则将该位置的 JSD 蒸馏损失按边际加权重计入总损失。
6. 更新学生参数，再以 EMA 方式更新教师参数。

## 6. 主要结论与发现

- **OPD-V 一致提升性能**：在 Qwen3.5-4B 上平均准确率从 64.30% 提升至 80.01%（+15.71 个百分点），超过最强的匹配基线 Vision-OPD（77.10%）达 2.91 个百分点。在 Qwen3-VL-4B/8B 和 Qwen3.5-9B 上同样一致提升。
- **小模型可超越大模型**：仅 4B 参数的 Qwen3.5-4B + OPD-V 达到 80.01% 平均准确率，超越了表中所有闭源模型以及 397B Qwen3.5（77.44%）和 1T Kimi-K2.6（72.81%）。
- **显著降低训练成本**：4B 骨干步耗时从 352s 降至 240s（↓31.8%），9B 从 451s 降至 340s（↓24.7%）。主要原因是 OPD-V 维持了更简洁的响应（最终响应长度比 OPSD 短 74.5%）且特权输入构造更高效。
- **训练动态稳定**：信任区域 token 占比在训练中持续维持在约 50% 附近，策略熵在 warm-up 后保持稳定，说明训练信号持续有效且策略未退化。

## 7. 优点

1. **视角新颖**：首次将“模态平衡”这一内部状态作为特权信息引入 OPSD 框架，而非依赖显式的外部标注或额外视觉输入，视角独特。
2. **方法简洁高效**：仅增加一次负教师前向传播，不引入额外参数，且因响应变短实际训练速度反而提升。
3. **实验设计严谨**：匹配了骨干、数据和训练协议，进行跨架构、跨规模验证；消融实验逐一验证了双教师互补性和图像操作选择的有效性。
4. **结果显著且一致**：在全部 6 个基准和 4 个骨干上均一致提升，未见退化，具有较强泛化可信度。
5. **机制可视化充分**：通过注意力比、对数边际、信任区域占比等指标，提供了模态不平衡存在的直接证据和训练动态的深入分析。

## 8. 不足与局限

1. **训练数据规模有限**：仅使用 6.2K 样本、单 epoch 训练，数据的领域覆盖和规模有限，可能不足以充分体现方法在大规模多样数据上的稳健性。
2. **基准覆盖存在偏向**：所选基准均偏向高分辨率、细粒度视觉证据提取场景，未包含视频、音频等多模态任务，也未覆盖纯文本推理场景以检验是否影响语言能力。
3. **基线的复现公平性存疑**：部分 SOTA 基线数值直接引用自 Vision-OPD 论文，可能因评估协议（如提示词、解码超参数）不同而存在不可控偏差。
4. **缩放图依赖外部数据**：正向教师的缩放图 $I_{zoom}$ 来自训练数据中预标注的证据区域边界框，实际应用中若无此类标注，构造方式可能受限。
5. **可解释性仍有限**：模态平衡注意力比与对数边际之间的因果联系虽然通过实验说明，但仍缺乏更深层的机制分析（如具体哪些注意力头或层贡献了该信号）。
6. **未报告总训练成本**：缺少总 GPU 小时数和端到端训练时间，无法完全评估方法的绝对算力开销。
