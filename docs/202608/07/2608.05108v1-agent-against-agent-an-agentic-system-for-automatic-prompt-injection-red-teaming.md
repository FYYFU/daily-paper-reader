## 摘要

## Abstract
Prompt injection poses significant security risks to LLM agents. Efficient and effective red-teaming is therefore critical, both for evaluating these risks and for collecting training data to improve defenses. Existing state-of-the-art prompt injection red-teaming methods primarily rely on reinforcement learning (RL), producing attacker models that often generalize poorly to new target LLMs. In this work, we develop PIMiner, an agentic system for prompt injection red-teaming. During training, PIMiner is trained on a sequence of (dataset, target model) pairs and builds a strategy library from scratch. At test time, the learned strategy library can be directly transferred to a previously unseen target LLM without additional training. PIMiner requires only a small number of queries to a target agent (e.g., 10) per test sample. Experimental results demonstrate that PIMiner achieves strong performance. On IPIArena, it attains a 76.2% ASR against Gemini-2.5-Pro, 61.9% ASR against GPT-5.1, and 42.9% ASR against Claude-Sonnet-4.5. On AgentDojo, it achieves an 86.7% ASR against Gemini-2.5-Pro, 53.3% ASR against GPT-5.1, and 40.0% ASR against Claude-Sonnet-4.5.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **安全威胁背景**：LLM 智能体在现实应用中广泛部署，可通过外部工具、检索文档、网页等不可信上下文来源获取信息。攻击者可在此类不可信内容中注入恶意指令，操纵智能体行为，即**提示注入攻击（Prompt Injection）**。
- **红队测试的重要性**：系统化红队测试可评估部署前模型鲁棒性；成功攻击样本可构建高质量训练数据，用于微调护栏模型、对齐骨干 LLM、训练更强的攻击者模型。
- **现有方法的不足**：
  - **RL 方法**（如 RL-Hammer、PISmith）虽然攻击成功率高，但训练需要大量与目标模型的交互（数万次查询），且学到的攻击模式对**新目标模型泛化差**，每个目标模型需重新训练或微调，成本高昂。
  - **搜索方法**（如 TAP、PAIR、Strategy-based Search）无需训练，但对每个样本从零开始搜索，**无法积累和复用攻击知识**，攻击效果明显低于 RL 方法。
- **核心问题**：能否构建一种红队智能体，既能像 RL 方法一样积累攻击知识，又像搜索方法一样无需昂贵训练，实现高效、可迁移的提示注入红队测试？

## 2. 论文提出的方法论：核心思想、关键技术细节、算法流程

- **核心思想**：将攻击历史转化为可复用的攻击知识，并组织在**层次化记忆机制**中，使基于搜索的迭代攻击方法能够随经验积累而不断增强。
- **PIMiner 系统组成**（四大组件）：
  1. **策略库（Strategy Library）**：长期跨数据集记忆，从零开始构建，每个策略为 Markdown 文件，记录目标 LLM 适用范围、任务范围、注入模板、代表性示例、失败条件等元数据。
  2. **策略路由器（Strategy Router）**：针对每个样本，从策略库中检索 Top-K 个最相关策略（默认 K=3），加载到攻击者上下文中，避免加载全部策略带来的高推理成本。
  3. **迭代攻击模块（Iterative Attack Module）**：基于三类记忆迭代优化注入提示，最大迭代次数 Nmax=10：
     - **长期记忆**：路由得到的策略文件；
     - **数据集内记忆（Intra-dataset Memory）**：当前数据集-模型对中已处理样本的浓缩经验（如成功注入、失败分析）；
     - **样本内记忆（Intra-sample Memory）**：当前样本的历史攻击尝试、目标轨迹、成败判断与分析。
  4. **经验消化器（Experience Digester）**：在一个数据集-模型对攻击完成后，分析成功/失败轨迹，更新策略库：成功攻击若匹配现有策略则追加示例；若拓宽适用范围则修订范围；若机制新颖则创建新策略文件；失败样本用于修正策略的失败条件与适用边界。
- **训练-测试流程**：
  - **训练阶段**：在序列 `{(D_t, M_t)}`（8 个数据集-模型对）上依次执行“路由→迭代攻击→消化更新”，逐步丰富策略库 St。
  - **测试阶段**：给定未见过的目标模型，冻结策略库直接应用，无需额外训练，每个测试样本仅需约 10 次目标模型查询。
- **实现细节**：使用 Python/Bash 编排，每个 LLM 智能体（路由器、攻击者、消化器）为独立的 Claude Code 会话；测试时可采用不同骨干模型（如训练用 Opus，测试用 Haiku），以降低测成本。
