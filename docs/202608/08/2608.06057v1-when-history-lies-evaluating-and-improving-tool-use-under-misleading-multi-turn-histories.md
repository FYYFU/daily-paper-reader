## 摘要
工具调用智能体从累积的对话和工具痕迹中推断任务状态。然而，在持续性交互中，历史痕迹在不再对当前请求具有权威性之后，仍可能在结构上有效且在语义上合理。我们表明，此类历史可能劫持模型已具备的策略：在Qwen3-1.7B上，污染使得原始轨迹下正确的决策中有32.1%发生翻转，并经常导致重复使用损坏的实体或接口约定。我们引入了基准测试，一个配对基准，包含同步的原始、污染和预言机状态视图，这些视图保留了系统策略、当前工具、最新请求和黄金下一动作。十一种保留黄金的干预措施将故障隔离为决策状态、实体绑定和接口执行，涵盖完整调用和非调用决策。我们进一步提出我们的方法，该方法通过软监督将预言机条件下的教师策略迁移到仅观察污染历史的学生生成前缀上。在Qwen3-1.7B上，我们的方法达到87.0%的平衡工具使用准确率，优于黄金SFT（66.3%）、预言机序列蒸馏（82.3%）和离策略标记蒸馏（85.0%）。该方法可一致扩展：8B教师将相同的紧凑1.7B学生提升至91.9%，而8B学生达到93.0%。所得策略进一步迁移到干净历史、未见函数、独立重新生成的评估上下文、外部工具使用基准以及带噪声的多跳问答中。这些结果确立了历史可靠性作为独立的工具使用瓶颈，并证明可靠状态策略迁移是一种有效且可扩展的解决方案。

## Abstract
Tool-calling agents infer task state from accumulated dialogue and tool traces. In persistent interactions, however, historical traces may remain structurally valid and semantically plausible after they cease to be authoritative for the current request. We show that such history can hijack a policy the model already possesses: on Qwen3-1.7B, pollution flips 32.1% of decisions that are correct under the original trajectory and frequently induces reuse of corrupted entities or interface conventions. We introduce bench, a paired benchmark with synchronized Original, Polluted, and Oracle State views that preserve the system policy, current tools, latest request, and gold next action. Eleven gold-preserving interventions isolate failures in decision state, entity binding, and interface execution across complete calls and non-call decisions. We further propose ours, which transfers an Oracle-conditioned teacher policy to a student observing only polluted history through soft supervision on student-generated prefixes. On Qwen3-1.7B, ours achieves 87.0% Balanced Tool-Use Accuracy, outperforming Gold-SFT (66.3%), Oracle sequence distillation (82.3%), and off-policy token distillation (85.0%). The method scales consistently: an 8B teacher raises the same compact 1.7B student to 91.9%, while an 8B student reaches 93.0%. The resulting policies further transfer to clean histories, unseen functions, independently regenerated evaluation contexts, external tool-use benchmarks, and noisy multi-hop question answering. These results establish history reliability as a distinct tool-use bottleneck and demonstrate reliable-state policy transfer as an effective and scalable solution.

## 1. 论文的核心问题与整体含义

论文聚焦于**多轮工具调用智能体在面临误导性历史记录时的鲁棒性问题**。具体而言，在真实场景中，智能体积累的对话与工具调用痕迹可能结构合法、语义合理，但已不再对当前请求具有权威性（例如早前失败的调用、涉及其他实体的记录、已废弃工具的痕迹等）。这种非权威历史痕迹会**劫持模型已具备的正确策略**——“历史诱导的策略劫持”现象。作者通过受控实验证明，历史记录中看似无害的残留信息，能显著改变模型本可以正确执行的决策，且现有基准无法区分“模型缺乏相应策略”与“模型具备策略但被误导”这两种情况。该研究确立了**历史可靠性**作为工具使用鲁棒性的独立瓶颈。

## 2. 方法论

### 2.1 基准测试（ContextPollute-Bench）
- **核心思想**：为每个决策点构造三个同步视图——**原始（Original）**、**污染（Polluted）** 和 **预言机状态（Oracle State）**。三视图共享完全相同的系统策略、工具集、最新请求和黄金动作，仅历史上下文不同。
- **构造方式**：基于 APIGen-MT 的航空与零售域轨迹，由 DeepSeek-V4-Flash 生成污染痕迹与预言机状态（但不生成黄金调用/回答），配合确定性校验器保证决策不变性与痕迹合法性。
- **十一种干预算子**：涵盖三个干扰层面——决策状态（不支持的完成声明、决策无关读取、已退役工具）、实体绑定（同工具不同目标、交错竞争实体）、接口执行（错误参数名+拒绝、遗留参数+成功、缺失必需参数、多余参数、格式漂移、单位/尺度漂移）。
- **指标**：采用 **BTA（Balance Tool-use Accuracy）** 平衡完整调用召回（TCR）与不调用约束（1–OCR）。

### 2.2 Oracle-OPD（Oracle-Guided On-Policy Distillation）
- **三个核心组件**：
  1. **可靠状态条件化**（Reliable-State Conditioning）：教师仅观察决策相关的预言机状态，而非完整或污染轨迹。
  2. **分布化策略迁移**（Distributional Policy Transfer）：通过 token 级软目标传递教师对回答/调用、工具选择、参数生成的相对偏好，而非单一硬序列。
  3. **学生状态覆盖**（Student-State Coverage）：教师对学生**自行生成前缀**上的分布进行评估，覆盖真实部署状态下学生可能到达的状态。
- **训练目标**：$$\mathcal{L}_{OPD} = \mathbb{E}_{(x_p, x_o), y} \left[ \frac{1}{|y|} \sum_{t=1}^{|y|} D_{KL}(q_t^S \| q_t^T) \right]$$ 其中 $q_t^S = \pi_\theta(\cdot | x_p, y_{<t})$、$q_t^T = \pi_T(\cdot | x_o, y_{<t})$，即学生针对污染输入生成 rollout，教师针对同一前缀的预言机上下文计算 soft target，并取 student 与 teacher 各 top-16 token 支持集的**反向 KL**。不使用额外黄金交叉熵（gold-CE）目标。
- **部署与推理**：仅需训练后的学生模型与普通交互历史，不依赖预言机状态或教师。

## 6. 论文的主要结论与发现

1. **历史污染确实劫持正确策略**：Qwen3-1.7B 上，32.1% 的原始视图正确决策在污染视图下翻转，且直接重复污染痕迹中的实体/参数格式（例如 34.8% 的“同工具不同目标”案例直接采用被污染实体）。
2. **Oracle-OPD 显著超越基线**：在 Qwen3-1.7B 上达到 87.0% BTA，优于 Gold-SFT（66.3%）、Oracle-SeqKD（82.3%）和 Off-policy OD（85.0%）；硬目标训练（SFT/DPO）导致“要么过度调用、要么完全不敢调用”的失衡策略。
3. **规模化有效**：8B 教师可把 1.7B 学生提升到 91.9% BTA；8B 学生配合 Oracle-SFT 教师可达 93.0%。
4. **可靠状态蒸馏具有可迁移性**：学到的策略可迁移到干净历史（1.7B 学生 Original 视图 84.5% BTA）、未见函数（OOD TCR 74.3%）、跨生成器评估（81.4% BTA）、外部基准（When2Call Macro-F1 从 0.2701 提升到 0.3294）以及带噪声的多跳 QA（HotpotQA Noisy F1 提升 2.97 分）。
5. **提示不足以解决问题**：直接告诉模型“忽略失败的历史”仅将 BTA 从 0.472 提升到 0.485，远低于学习式可靠状态蒸馏（0.870），说明模型需学习判断“哪一段历史依然权威”。

## 7. 优点

- **问题定义清晰、现象显著**：通过“配对的”多视图决策结构，精确分离“缺乏能力”与“能力被劫持”，指出既有基准无法识别的问题。
- **方法设计简洁而严谨**：Oracle-OPD 用“可靠状态教师”+“学生真实前缀”+“分布目标”三个组件形成闭环，部署代价极小。
- **系统化消融**：因子消融设计直接验证每个组件价值，例如 Oracle 视图较 Original 视图提升 +11.4 BTA，软目标相对硬序列提升 +2.7 BTA，学生前缀相对教师/黄金前缀提升 +2–2.3 BTA。
- **大规模外部迁移验证**：同时验证 BFCL、When2Call、HotpotQA 多类型基准，说明不是对基准的过拟合。
- **细节透明**：公开全部构造 pipeline、算子模板、审计协议、环境版本、训练超参，可复现性好。

## 8. 不足与局限

- **领域有限**：基准仅覆盖航空和零售两个领域；扩展到更多领域（如代码、医疗、金融等）才能验证普适性。
- **污染生成依赖大模型**：污染痕迹与 Oracle State 均由 DeepSeek-V4-Flash（训练）和 Claude-Opus-4.7（评估）生成，生成模型自身的偏差可能影响基准的代表性；虽然跨生成器验证缓解了部分偏差，但仍是潜在风险。
- **Oracle State 的“特权信息”在训练时可用、部署时不可用**：这符合 learning using privileged information 的范式，但实际部署中如何获得高质量可靠状态摘要仍是一个开放问题。
- **32B 与 DeepSeek-V4-Flash 仅做诊断未做训练**：大规模模型训练/蒸馏是否能保持同样收益未被验证。
- **OOD-600 仅限 call-only 场景**：未验证“未见工具”下 Answer 决策的泛化；且仅测试 6 个未见工具。
- **HotpotQA 的鲁棒性指标仅为同一训练/评估管线的固定检查点**，未做系统性超参数敏感性分析。
- **论文指出审计量约为 1,200 例（200+1,000）**，与总体约 14,000 例相比占比有限，且人类审计本身可能存在标注偏差。
