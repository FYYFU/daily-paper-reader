## 摘要
虽然检索增强生成系统部分解决了大语言模型中的幻觉问题，但也引入了对知识腐败攻击的新漏洞。 adversaries（对抗者）通过毒化RAG系统提供的文档来操纵LLM输出，从而利用这些漏洞。为应对这一威胁，我们提出了SecureCollaRAG，一种利用多源知识验证机制的拜占庭容错协作式RAG框架。我们的方法使智能体系统能够通过基于动态图神经网络的信誉评分来安全验证文档来源，有效防止隐蔽的知识腐败攻击，同时保持必要的领域知识完整性。通过广泛的评估和形式化分析，我们证明了SecureCollaRAG在非独立同分布数据分布下对攻击者保持鲁棒性。

## Abstract
While retrieval-augmented generation systems partially address the hallucination issues in large language models, it also introduces new vulnerabilities to knowledge corruption attacks. Adversaries exploit these vulnerabilities by poisoning documents provided by RAG system to manipulate LLM outputs. To counter this threat, we propose SecureCollaRAG, a Byzantine-tolerant collaborative RAG framework leveraging Multi-source Knowledge Validation Mechanism. Our approach enables agent system to securely verify document provenance through dynamic GNN-based credibility scoring, effectively preventing stealthy knowledge corruption attacks while preserving essential domain knowledge integrity. Through extensive evaluations and formal analysis, we demonstrate that SecureCollaRAG maintains robustness against attackers under non-IID data distributions.

### 2.1 核心思想

SecureCollaRAG（SCR）是一种拜占庭容错的协作式RAG防御框架，核心创新是**多源知识验证机制**：通过跨独立来源的信息共识验证，利用“多数认可的知识具有更高可信度”的原则，从分布式角度识别和过滤恶意内容。

### 2.2 系统架构与工作流程

系统由三部分构成：目标LLM、聚合服务器 **A**、知识源集合 S = Sb ∪ Sm（良性+恶意文档）。

**核心工作流**：
1. **分布式查询分发**：用户指令qt经LLM任务分析器语义分解为q′t，分发至m个知识源并行执行本地检索，每个来源返回Top-k文档，汇总为D(t)。
2. **动态验证图构建**：在聚合服务器上，以文档为节点、以综合相似度为边权重构建验证图G(t)，节点特征包含12个判别性特征（分为内容特征、图结构特征、跨交互特征三类）。
3. **GNN信用评分**：通过动态图神经网络处理验证图，计算每个文档的可信度评分C(d)∈[0,1]。
4. **后审计机制（Post Audit）**：对处于不确定区域[τ_low, τ_high]的文档，通过常识LLM审计（prompt engineering）生成常识差异惩罚分数Pc(d)，整合后通过GNN重新计算可信度。
5. **验证式聚合**：低于阈值θ的文档被丢弃，保留的文档触发来源可靠性更新；高可信度文档（C(d)>τ_conf）最终返回给LLM生成响应。

## 6. 论文的主要结论与发现

1. **SCR框架持续在所有测试配置中实现最低的ASR**：如在MediNote+Deepseek-V3上，SCR对PoisonedRAG的ASR降至5.24%，而MS-RAG为78.80%、RobustRAG为80.12%。
2. **多源架构提供基础但不足的防御**：从SS-RAG的97.00%（PoisonedRAG/MediNote）降至MS-RAG的78.80%，仅靠内容稀释不足以防护。
3. **ATA攻击的隐蔽性验证**：ATA对基线系统不如动态PoisonedRAG有力（如SS-RAG上78.68% vs 97.00%），但在多个场景中对SCR的ASR略高于PoisonedRAG（如MediNote+SCR：5.72% vs 5.24%），证实其产生的可检测异常更少。
4. **常识机制的贡献**：加入常识审计后TPR从88.40%提升至95.00%（SAA攻击场景），TNR从86.50%提升至94.33%，FPR和FNR显著降低。
5. **可靠性评分有效区分恶意/良性来源**：SAA下良性/恶意差异巨大（如MediNote上0.983 vs 0.009）；PoisonedRAG恶意得分较低（0.018）；ATA恶意得分最高（MediNote 0.287），确认其增强的隐蔽性。
6. **正式安全性保证**：定理1证明当恶意来源少于50%时，接受恶意文档的风险以e^(-γ)指数级衰减，为RAG投毒威胁提供了理论防御保证。

- **常识审计的局限性**：常识LLM审计的作用仅限于基础合理性判断，难以应对需要领域专业知识的隐性错误（论文自述），可能漏过专业化攻击。
- **检索器/嵌入依赖**：防御有效性依赖文档嵌入质量与检索结果的相关性，在低质量嵌入场景下GNN图的质量可能下降。
- **训练开销与门槛**：SCR需训练GNN模型（尽管附录说明可使用用户数据训练），引入额外的部署和维护成本。

### 现实应用层面
- 论文基于合成的数据划分构建多来源场景，真实大规模生产环境中的系统异构性、数据隔离策略和隐私合规约束可能更复杂。
- 版权/隐私问题：虽然提到差分隐私作为可集成方案，但未在实验中验证这些隐私保护技术对防御性能的影响。
