## 摘要
机器学习工程（MLE）任务需要在迭代式的解决方案调试与改进中进行长时程决策，且环境交互代价高昂、受反馈驱动。为这类任务开发和训练单一的整体智能体从根本上具有挑战性，因为它必须同时处理极长且嘈杂的上下文、探索庞大的解空间，并在有限的模型容量和计算预算下保持有效性。为应对这些挑战，我们提出了套娃智能体（Matryoshka Agent），一个用于复杂长时程任务的统一分层智能体框架。套娃智能体将智能体问题求解分解为决策与执行的协调层级：高层编排器维护紧凑的长时程探索状态并发出策略指令，而低层子智能体通过标准化的工具接口与环境直接交互来执行具体的解决方案尝试。这种设计将策略探索与高成本执行解耦，显著减轻了长上下文推理的负担，并实现了高效的迭代式改进。我们进一步为套娃智能体开发了一种高效的训练范式。在涵盖多种模型类型和规模的各种MLE任务上的实验结果表明，套娃智能体是长时程MLE任务和复杂智能体问题求解的有效且可扩展的范式。值得注意的是，套娃智能体使Qwen3-4B-Instruct达到与o4-mini相当的编排器性能。将套娃智能体应用于Qwen3-30B-Coder可带来最高36.7%的相对性能提升。

## Abstract
Machine learning engineering (MLE) tasks require long-horizon decision making over iterative solution debugging and refinement, under expensive and feedback-driven environment interactions. Developing and training a monolithic agent for such tasks is fundamentally challenging, as it must simultaneously manage extremely long and noisy contexts, explore vast solution spaces, and remain effective under limited model capacity and computational budgets. To address these challenges, we propose Matryoshka Agent, a unified hierarchical agent framework for complex long-horizon tasks. Matryoshka Agent decomposes agentic problem solving into a coordinated hierarchy of decision making and execution: a high-level Orchestrator maintains compact, long-horizon exploration states and issues strategic instructions, while lower-level Sub-Agents execute concrete solution attempts through direct environment interaction, mediated by standardized Tool interface. This design decouples strategic exploration from costly execution, substantially reducing the burden of long-context reasoning and enabling efficient iterative refinement. We further develop an efficient training paradigm for Matryoshka Agent. Experimental results on a broad range of MLE tasks with diverse model types and scales demonstrate that Matryoshka Agent is an effective and scalable paradigm for long-horizon MLE tasks and complex agentic problem solving. Notably, Matryoshka Agent enables Qwen3-4B-Instruct to reach Orchestrator performance comparable to o4-mini. Applying Matryoshka Agent to Qwen3-30B-Coder results in at most 36.7% relative performance gain.

## 1. 论文核心问题与整体含义（研究动机与背景）

- **问题定位**：机器学习工程（MLE）任务要求智能体在昂贵、反馈驱动的环境下进行长时程（long-horizon）迭代决策——包括代码生成、执行、调试、评估和优化。
- **核心挑战**：
  - **长上下文与噪声**：多轮交互不断累积执行日志、中间输出和调试反馈，上下文极易膨胀且充满冗余信息；
  - **巨大的探索空间**：观测空间和动作空间开放且多样，智能体需在大量方法论选择中系统探索与利用；
  - **高昂交互成本**：环境执行（特别是大规模数据/模型）在时间和算力上极其昂贵，限制推理时探索与训练时数据收集。
- **单体智能体的不足**：单一智能体需同时承担策略决策、代码编写、调试执行等多重任务，在长上下文推理、模型容量有限和计算预算受限的条件下很难同时做好。
- **本文核心思路**：提出 **Matryoshka Agent**——一个分层智能体框架，通过将“高层战略决策”与“低层具体执行”解耦，让不同层级的模块各司其职，从而以更低的上下文负担和更高的计算效率完成长时程 MLE 任务。

## 2. 论文提出的方法论

### 2.1 整体架构（三层结构）

| 层级 | 组件 | 职责 |
|------|------|------|
| 高层 | **Orchestrator（编排器）** | 维护紧凑的跨轮状态（历史指令、摘要、评分），决定下一步探索/精炼哪个方向，发出策略性指令 |
| 中层 | **Tool（工具接口）** | 标准化交互：格式化编排器指令、注入参考尝试、启动子智能体、返回结构化摘要和评分 |
| 低层 | **Sub-Agents（子智能体）** | 以全新上下文实例化，直接与环境交互，执行具体代码编写、运行与调试，产出解决方案尝试 |

### 2.2 推理时工作流程

1. **初始化**：编排器从任务实例构造根状态；
2. **每轮循环**：编排器发出工具调用，包含三要素：
   - 要精炼的前一轮尝试（父节点）；
   - 详细的实现指令；
   - 可选的参考尝试标签；
3. **工具层**：将工具调用转换为全新子智能体上下文（任务说明 + 父尝试 + 指令 + 参考）；
4. **子智能体执行**：在环境内进行有界“执行—调试”循环（上限 10 次调试），产出有效提交或失败诊断；
5. **结果回传**：工具层将子智能体的执行轨迹压缩为结构化摘要 + 评分，返回编排器；
6. **循环直至预算耗尽**：返回历史最佳分数对应的解决方案。

### 2.3 训练范式：迭代在线优化

- **训练时解精炼树（Solution Refinement Tree）**：
  - 每个任务构造一棵树：根节点为任务初始状态，每个非叶节点由当前编排器策略采样两个候选精炼指令，分别执行得到两个子节点；
  - 树的节点为带评分标注的解决方案尝试，边为编排器的精炼决策。
- **偏好构造**：对内部节点 u 的两个子分支 c1、c2，定义**下游回报** R(c) = max over subtree(c) of r(v)，即分支子树内最高评分；下游回报更高的分支作为偏好分支。这样避免了“首次尝试分数低但后续潜力大”的方向被错误惩罚。
- **在线强化学习目标**：
  - 基于能量形式的策略表示：π\*(Δτ|s_u) ∝ π^(m)(Δτ|s_u) · exp(1/β · r(s_u, Δτ))；
  - 参数化轨迹分数为 log-ratio：r_θ(s_u, Δτ) = β log(π_θ(Δτ|s_u) / π^(m)(Δτ|s_u))；
  - 通过**排名式 NCE 目标**优化编排器（公式4），对偏好分支赋予更高概率，并以旧策略 π^(m) 为参考锚定更新；
  - **子智能体自我强化**：从树中最高分路径提取子智能体轨迹，构造指令-响应对进行 SFT，实现子智能体随编排器共同进化。

## 6. 论文主要结论与发现

1. **分层框架带来一致的推理时增益**：同一模型（Qwen3-30B-Coder）从单体 0.3302 提升至分层 0.3652，纯框架增益即达约 10.6%。
2. **训练范式带来显著额外增益**：SFT + RL 后达 0.4515，相对单体基线提升最高 36.7%。
3. **小型模型可成为高效编排器**：Qwen3-4B-RL 作为编排器配 o4-mini 子智能体达到 0.5360，与 o4-mini 自我配对（0.5465）几乎持平，说明“小模型决策 + 大模型执行”的分离架构有效。
4. **子智能体对模型规模敏感**：Qwen3-4B 作为子智能体执行能力弱（即使指令质量提升后仍失败），表明执行层更依赖模型底层能力，而决策层可通过训练补偿。
5. **即插即用能力强**：RL 训练的编排器可与训练时不同的子智能体（GPT-5-nano）配对，仍显著优于单体基线。
6. **消融显示编排器优化为主导**：RL 模型作为编排器的增益（0.4258 vs 0.3302）大于其作为子智能体的增益（0.3826 vs 0.3302）。
7. **上下文增长更平稳**：编排器斜率约 1201.93 tokens/轮，低于 Dojo Agent 的 1870.29 tokens/轮；在 256K 上下文预算下，编排器可支持约 213 轮 vs 单体 137 轮。

## 7. 优点（方法与实验亮点）

- **架构设计精巧**：三层分离（决策—中介—执行）逻辑清晰，工具层作为“信息边界”既保留决策所需信号，又过滤执行层噪声；多个子智能体可并行、上下文彼此隔离。
- **训练范式高效且有理论基础**：
  - 解精炼树共享执行前缀，最大化昂贵环境反馈的复用效率；
  - 分支级下游回报而非即时分数，避免短视策略；
  - 排名式 NCE 目标 + log-ratio 参数化，天然锚定旧策略、控制更新幅度。
- **实验设计较全面**：包含主实验、即插即用、双组件消融、训练流程消融、上下文分析、指令动态分析、失败案例分析，多角度验证方法有效性。
- **结论有价值**：证明“小模型编排 + 大模型执行”的可能性，为资源受限场景提供实用路径。
- **即插即用特性**：编排器与子智能体的解耦使得训练后的编排器可灵活迁移到更强执行模型上，实用性强。
