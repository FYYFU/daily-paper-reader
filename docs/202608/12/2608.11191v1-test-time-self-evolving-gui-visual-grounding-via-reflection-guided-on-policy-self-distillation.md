## 摘要
GUI视觉定位是GUI智能体的基本能力。现有模型通常在部署后冻结参数，限制了它们适应未见界面的能力。尽管近期方法尝试通过测试时强化学习来适应模型，但它们无法对失败的探索进行反思。为了克服这一局限，我们提出了一种测试时自演化框架，使模型在部署后无需人工标注的真实标签即可自我改进。该框架构建了探索、评估、反思与内化的闭环。具体而言，智能体首先通过预测给定指令的定位坐标来探索未见界面。为了评估这些探索，我们引入了一个基于MLLM的反思器，用于评估生成结果并提供相应的推理反思。为了将反思知识内化到模型权重中，我们提出了反思引导的同策略自蒸馏方法，通过条件自教师将高层推理转化为密集的令牌级监督。此外，我们设计了一种对比校准方法，以防止错误的自回归前缀在失败探索期间破坏监督信号。在六个基准上的大量实验证明了我们框架的有效性，相较于基础模型平均准确率提升了7.4%。据我们所知，这是首个成功利用同策略自蒸馏进行GUI视觉定位测试时适应的研究。通过填补部署后适应的空白，我们的框架完善了GUI智能体的自演化能力。代码将公开。

## Abstract
GUI Visual Grounding is a fundamental capability for GUI agents. Existing models typically freeze their parameters after deployment, limiting their ability to adapt to unseen interfaces. Although recent methods attempt to adapt models via test-time reinforcement learning, they cannot reflect upon failed exploration. To overcome this, we propose a Test-Time Self-Evolving framework that enables models to improve after deployment without human-annotated ground truth. It constructs a closed-loop of Exploration, Evaluation, Reflection, and Internalization. Specifically, the agent first explores unseen interfaces by predicting grounding coordinates for given instructions. To evaluate these explorations, we introduce an MLLM-based Reflector to assess the generated results and provide the corresponding reasoning reflections. To internalize reflection knowledge into the model weights, we propose Reflection-Guided On-Policy Self-Distillation, which translates high-level reasoning into dense token-level supervision via a conditioned self-teacher. Furthermore, we design a Contrastive Calibration method to prevent incorrect auto-regressive prefixes from corrupting the supervisory signals during failed explorations. Extensive experiments across six benchmarks demonstrate our framework's effectiveness, achieving an average accuracy improvement of 7.4% over the base model. To the best of our knowledge, this is the first work to successfully exploit on-policy self-distillation for test-time adaptation in GUI visual grounding. By filling the gap in post-deployment adaptation, our framework completes the self-evolving capability of GUI agents. The code will be released.

## 1. 论文的核心问题与整体含义

- **研究背景**：GUI 智能体需要依赖 GUI 视觉定位（GUI Visual Grounding）能力，即根据自然语言指令定位界面中的 UI 元素。近年来，该能力通过大规模监督微调、专用动作头、强化学习等方式获得了显著提升。
- **核心问题**：现有模型部署后参数冻结，遇到未见过的应用或界面布局时无法通过交互经验改进自身性能；近期出现的测试时强化学习方法（如 GUI-RCPO）虽能在线优化，但依赖稀疏标量奖励，缺乏对失败原因的推理和反思能力，难以指导模型纠正错误。
- **整体含义**：论文旨在补上"部署后自适应"这一关键缺口，使 GUI 智能体真正具备"自我演化"能力——在无人工标注的情况下，通过探索、评估、反思、内化四个环节形成闭环，从成功与失败的探索中持续学习。这是首个将同策略自蒸馏（On-Policy Self-Distillation, OPSD）成功应用于 GUI 视觉定位测试时自适应的工作。

## 2. 论文提出的方法论

### 核心思想
构建一个"测试时自演化"闭环：**探索（Exploration）→ 评估（Evaluation）→ 反思（Reflection）→ 内化（Internalization）**。模型在部署后先自行探索界面，再由一个基于 MLLM 的 Reflector 评估结果并生成详细文本推理，最后通过一种新的自蒸馏机制把推理知识写入模型参数。

### 关键技术细节

- **探索**：给定截图 I 和指令 L，定位模型 πG 预测坐标 B。
- **评估与反思（Reflector）**：引入 MLLM 反思器 πR，输入 I、L 和 B，输出二进制评估 S∈{0,1} 及分步推理 R。其推理模板强制模型先进行意图分析、坐标定位、验证、结论四个步骤。Reflector 使用 GRPO 在 GroundCUA 构造的 10K 样本上训练，奖励为格式奖励 + 二元正确性奖励，训练后冻结。
- **内化（R-OPSD）**：核心创新是将自然语言反思转化为逐 token 的稠密监督。做法是把评估结果 S 和反思 R 作为先验信息（privileged information）注入自教师（self-teacher）的提示模板，让条件化教师为模型自身生成的轨迹提供逐 token 优势：
  - \( a_i = \log \frac{\pi_G(B_i | B_{<i}, I, L(S,R))}{\pi_G(B_i | B_{<i}, I, L)} \)
  - 优化目标为最大化逐 token 优势的期望，即 \( \mathcal{L}_{OPD} = -\frac{1}{T}\sum_{i=1}^{T} \mathrm{sg}(a_i)\log\pi_G(B_i|B_{<i}, I, L) \)。
- **对比校准（Contrastive Calibration, CC）**：针对失败探索中自回归前缀错误导致监督信号被污染的问题。对于 S=0 的轨迹，额外构造一个"逆向提示"学生，通过提示词假称该预测是正确，形成对比式优势：
  - \( a_i = \log \frac{\pi_G(B_i | B_{<i}, I, L(S,R))}{\pi_G(B_i | B_{<i}, I, L(\neg S))} \)。
  - 这样在初始错误 token 处，逆向学生会因误导而高概率选中错误 token，教师则概率较低，产生负优势抑制初始错误；随着 tokens 漂移，两者条件前缀趋同，优势衰减至接近零，防止污染反馈被内化。
- **方向性优势剪裁（Direction-based Advantage Clamping）**：使 token 级更新方向与评估结果一致——成功时优势取 max(0, ai)，失败时取 min(0, ai)，防止梯度方向与结果矛盾。
- **与 GRPO 的 query-level 优势集成**：将上述 token 级优势与 GRPO 标准化后的组内相对优势按系数 λ（实验中取 0.2）结合，形成最终优化目标。

## 8. 不足与局限

- **对 Reflector 的依赖**：框架整体效果依赖 Reflector 评估与反思的质量。虽然论文论证了"不需要完美评估"且实验显示其准确率达 89%–91%，但 Reflector 本身是在 GroundCUA 上训练的，面对训练分布之外的界面（如罕见老旧软件或专业软件）其可靠性可能下降，带来偏差风险。
- **适应数据覆盖有限**：测试时内化仅在 SSv2 和 MMG 两个数据集上模拟，未覆盖移动端、桌面端、跨语言界面等更多场景，泛化性验证不够全面。

- 仅用 R-OPSD 核心部分（不含 CC）则仅需约 129 分钟（约为 GRPO 的 0.34 倍），说明主要开销来自 query-level 优势集成与附加反向传播的协同计算。但即使如此，完整版本在真实"部署后"资源受限场景下仍构成一定门槛。

## 9. 对论文的总体评价

本文是 GUI 视觉定位领域"测试时自适应"方向上的一项扎实且有启发性的工作。其核心贡献不在于提出一个全新的定位模型架构，而在于构建了一套**无标注条件下让已部署模型从自身经验中持续改进的完整方法论闭环**。在技术层面，论文最值得称道的是将 MLLM 产生的自然语言反思与策略优化目标之间建立起了可微、可训练的桥梁——基于反思条件化的同策略自蒸馏（R-OPSD），并以对比校准机制优雅地缓解了失败轨迹中自回归前缀对监督信号的污染问题。

从实验角度看，论文的实证工作是充分且坦诚的：不仅报告了性能提升，也公开了计算开销、组件消融、奖励设计对比和失败案例；既证明了方法的有效性，也揭示了其局限性（如完整版训练成本是 GRPO 的 1.73 倍、依赖 Reflector 质量）。这种严谨性使得结论具有较强的可信度。

从学科意义上看，该工作是"GUI 智能体自我演化"方向的一个重要里程碑——它首次展示了：即便没有外部标注、没有完美评估器，模型也可以通过"探索-反思-内化"的闭环在部署环境中实现性能提升。这为后续研究（如多轮演化稳定性、更轻量的反思器设计、跨界面迁移的鲁棒性）打开了明确的问题空间。

总体而言，这是一篇**问题真实、方法新颖、实验扎实、局限清楚**的高质量论文，其核心思想与工程实现具有一定的示范效应和工业部署参考价值。
