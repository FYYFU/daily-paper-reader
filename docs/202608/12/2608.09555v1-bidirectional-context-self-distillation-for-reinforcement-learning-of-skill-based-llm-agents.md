## 摘要
外部自然语言技能为大型语言模型（LLM）智能体提供了可重用且可编辑的指导，以解决复杂任务。然而，其有效性不仅取决于技能质量，还取决于策略能否将所提供的指导转化为适当的行动。然而，专门用于提高这种技能利用能力的方法仍鲜有探索。在实践中，基于技能的智能体通常以任务级奖励为中心的强化学习目标进行训练，这种目标提供的监督有限，难以捕捉策略在使用所提供技能时效果上的细微差异。我们提出了BCSD（双向上下文自蒸馏），一个将自蒸馏与强化学习相结合的训练框架，使LLM智能体能够更有效地使用外部技能。与先前依赖单一特权上下文的自我蒸馏方法不同，BCSD从两个互补的技能上下文视角评估每条轨迹。增强视角引入更高级别的元技能指导，而缩减视角则剪除通用指导以突出任务特定技能。两者的互补性词元级信号被结合以重新调整RL优势。在ALFWorld和WebShop上的实验表明，BCSD在不同模型规模上实现了最强的整体性能，使智能体能够更有效地利用外部技能。消融研究进一步验证了增强和缩减上下文视角的互补贡献。代码将发布以确保完全可复现性。

## Abstract
External natural-language skills provide large language model (LLM) agents with reusable and editable guidance for solving complex tasks. Yet their effectiveness depends not only on skill quality, but also on whether the policy can translate the provided guidance into appropriate actions. However, methods specifically designed to improve this skill-utilization ability remain largely underexplored. In practice, skill-based agents are commonly trained with reinforcement learning objectives centered on task-level rewards, which offer limited supervision and struggle to capture subtle differences in how effectively the policy uses the provided skills. We propose BCSD (Bidirectional Context Self-Distillation), a framework that combines self-distillation with reinforcement learning to train LLM agents to use external skills more effectively. Unlike prior self-distillation methods that rely on a single privileged context, BCSD evaluates each trajectory from two complementary skill-context views. The augmented view introduces higher-level Meta-Skill guidance, while the reduced view prunes general guidance to highlight task-specific skills. Their complementary token-level signals are combined to rescale the RL advantage. Experiments on ALFWorld and WebShop demonstrate that BCSD achieves the strongest overall performance across model scales, enabling agents to utilize external skills more effectively. Ablation studies further verify the complementary contributions of the augmented and reduced context views. Code will be released to ensure full reproducibility.

## 二、论文提出的方法论

### 1. 核心思想
- 提出 **BCSD（Bidirectional Context Self-Distillation，双向上下文自蒸馏）** 框架。
- 核心思路：与以往只从单一特权上下文构造教师不同，BCSD从**两个互补的上下文视角**分别对同一条轨迹进行词元级重新评分，产生两个方向的“上下文概率差”（context gap），再加权融合，用于重新缩放GRPO（Group Relative Policy Optimization）的优势值（advantage），从而为策略提供更细粒度、更可靠的技能利用反馈。
- 关键原则：BCSD只调节优势的**幅度**，不改变由任务奖励决定的优化**方向**，避免自我蒸馏信号干扰强化学习的正确优化目标。

### 2. 关键技术细节

**（1）问题设定与基础上下文**
- 使用SkillRL风格的分层SkillBank：对于每类任务查询`Q`，提供通用技能`G`和检索到的任务特定技能`S_c`。
- 基础上下文：`C0 = (Q, G, S_c)`
- 策略在`C0`下采样一组K条行为轨迹，获得结果奖励，并按标准GRPO计算组内相对优势`A^{GRPO}_i`。

**（2）Meta-Skill（元技能）提取**
- 定义：Meta-Skill是“关于如何使用特定技能”的高级文本指导，反映当前策略在应用技能过程中的成功与失败模式。
- 提取方式：在训练前和训练中定期（每次验证窗口后）使用冻结的外部LLM，对比成功轨迹与失败轨迹的证据集，结合上一轮Meta-Skill，生成或刷新当前任务的Meta-Skill。
- 重要特性：Meta-Skill只作为**教师端的特权上下文**（加入增强视角C1），不参与学生推理或最终评估，从而避免信息泄漏。
- 证据数据全部来源于**在线训练 rollout**，验证集仅用于触发刷新时机，不提供提取数据。

**（3）双向上下文构建**
- **增强视角（Augmented view）**：`C1 = (Q, G, S_c, M_c)`，在基础上下文上加入Meta-Skill，提供“如何更好地使用技能”的高级指导。
- **缩减视角（Pruned view）**：`C2 = (Q, G_p, S_c)`，其中`G_p`是预先用外部LLM对通用技能`G`进行剪枝后的精简版（去除冗余内容、保留核心程序性指导），从而突出任务特定技能`S_c`的重要性，提供一个更聚焦的参考。

**（4）Gap-Weighted Advantage Rescaling（差距加权优势重标定）**
- 对每条在`C0`下采样的轨迹，保持响应序列不变，分别用同一个策略在`C1`和`C2`下重新计算每个词元的log概率，得到两个token级差值：
  - `Δ^{aug}_{i,t} = log πθ(y_{i,t} | C1, y_{i,<t}) − log πθ(y_{i,t} | C0, y_{i,<t})`
  - `Δ^{pru}_{i,t} = log πθ(y_{i,t} | C2, y_{i,<t}) − log πθ(y_{i,t} | C0, y_{i,<t})`
- 加权融合：`Δ_{i,t} = α·Δ^{aug}_{i,t} + (1−α)·Δ^{pru}_{i,t}`
- 优势重标定：
  - `w_{i,t} = clip(exp(sign(A^{GRPO}_i) · Δ_{i,t}), 1−c, 1+c)`
  - `A^{BCSD}_{i,t} = A^{GRPO}_i [(1−λ_n) + λ_n w_{i,t}]`
- 关键设计：`λ_n`从初始值`λ_0`线性衰减到0。早期提供强上下文引导，后期逐步让位于环境奖励，避免策略对特权上下文信号形成过度依赖。

**（5）策略优化目标**
- 采用标准GRPO裁剪目标，将原始轨迹级优势替换为`A^{BCSD}_{i,t}`，并加上KL正则：
  - `L_{BCSD}(θ) = −E_{i,t}[min(ρ_{i,t}(θ)A^{BCSD}_{i,t}, clip(ρ_{i,t}(θ), 1−ε, 1+ε)A^{BCSD}_{i,t})] + βL_{KL}`

**（6）算法流程（Algorithm 1）**
1. 用外部LLM预先构建`G_p`并初始化`M_c^{(0)}`
2. 每步采样批次数据，在`C0`下生成K条轨迹，计算GRPO优势
3. 用同一策略在`C1`和`C2`下重新评分，计算双向gap与重标定优势
4. 更新策略参数；每N步刷新Meta-Skill并重置证据缓冲

## 六、论文的主要结论与发现

1. **BCSD在不同模型规模上均取得最优或接近最优的整体性能**：
   - Qwen2.5-7B：ALFWorld平均成功率83.6（超最佳基线3.1个百分点），WebShop成功率78.1（最高）。
   - Qwen2.5-3B：ALFWorld成功率82.0（超最强基线5.4个百分点），WebShop得分和成功率分别提升4.4和9.4个百分点，收益最显著。
   - Qwen3-1.7B：ALFWorld平均成功率46.9（最高），WebShop得分76.8（最高），成功率50.8（仅比最佳低0.8）。
2. **两个上下文视角互补且必要**：删除任一视角均显著降低性能，其中删除Meta-Skill视角降幅最大；token级信号一致性分析表明两个视角仅约50%方向一致，说明二者提供的信息具有明显差异而非冗余。
3. **λn衰减策略有效**：保持λn恒定会降低最终性能，早强后弱的调度方式能兼顾早期引导与后期奖励优化之间的平衡。
4. **Meta-Skill定期刷新必要性高**：不刷新Meta-Skill在WebShop上性能大幅下降，固定Meta-Skill会随策略演化而过时。
5. **BCSD真正提升了技能利用率而非记忆化任务知识**：去除任务特定技能后，BCSD较Skill_GRPO*的性能下降更大（ALFWorld下降2.3 vs 0.8个百分点，WebShop下降7.8 vs 6.2个百分点），说明BCSD策略的行为更依赖外部任务技能，而非把任务知识固化为模型参数。
