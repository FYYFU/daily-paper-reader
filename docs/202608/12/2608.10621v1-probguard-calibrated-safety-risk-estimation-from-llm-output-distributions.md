## 摘要
近期关于大语言模型安全性的研究广泛采用护栏来识别不安全的LLM输出。现有护栏通常将安全评估视为确定性分类任务，将离散标记序列映射到离散的安全标签。然而，这种范式存在两个局限性：首先，安全评估本质上是一个不确定问题，尤其在早期生成阶段；其次，仅依赖离散标记序列丢弃了LLM输出分布中蕴含的丰富概率信息。为解决这些局限性，我们提出了首个完全概率化的、架构无关的护栏\textsc{ProbGuard}，利用LLM早期输出分布信号来估计和校准安全概率，从而实现对不安全持续输出的提前终止。具体而言，给定LLM生成的前缀分布，我们将安全风险形式化为其持续生成动态的不安全概率，并通过蒙特卡洛采样估计该风险。通过对分布信号和校准安全风险进行训练后，\textsc{ProbGuard}在所有九个模型-数据集组合设置中取得了最佳校准性能，相较于最优基线，平均Brier分数和ECE分别降低了79.6%和71.9%。\textsc{ProbGuard}进一步在仅观察LLM前十个解码步骤的早期输出分布后，将六种代表性越狱攻击的攻击成功率限制在至多1%。

## Abstract
Recent research on Large Language Model (LLM) safety has widely adopted guardrails to identify unsafe LLM outputs. Existing guardrails typically formulate safety assessment as a deterministic classification task, mapping a discrete token sequence to a discrete safety label. However, this paradigm has two limitations: First, safety assessment is inherently an uncertain problem, particularly during the early generation state. Second, relying solely on discrete token sequences discards the rich probabilistic information embedded in the LLM output distribution. To address these limitations, we propose the first completely probabilistic architecture-agnostic guardrail \textsc{ProbGuard} to leverage the LLM early output distributional signals for estimating and calibrating the safety probability, thereby enabling early stopping of unsafe ongoing outputs. Specifically, given an LLM's generated prefix distribution, we formulate the safety risk as the unsafe probability of its continued generation dynamics and estimate this risk by Monte-Carlo sampling. Through post-training on the distributional signals and calibrated safety risk, \textsc{ProbGuard} achieves the best calibration performance across all nine model--dataset combination settings, reducing the average Brier score and ECE by 79.6\% and 71.9\%, respectively, over the best baseline. \textsc{ProbGuard} further limits the attack success rate to at most 1\% across six representative jailbreak attacks after observing the LLM early output distributions from only the first ten decoding steps.

## 2. 提出的方法论：ProbGuard

### 2.1 核心思想

ProbGuard 是**首个完全概率化、架构无关（architecture-agnostic）的护栏**，利用 LLM 早期生成阶段的输出分布信号来估计和校准"持续生成将导致不安全回答"的概率，以实现对潜在不安全输出的提前终止。

### 2.2 安全风险的概率化形式化

在解码步骤 k，设 LLM 为 L，当前生成状态为 S_k，完整回答为 R，二元安全判断器为 J(R)∈{0,1}，则安全风险定义为：

```
C_k = P(J(R)=1 | x, S_k)
```

由于从当前状态继续生成会产生多种可能的完整回答，R 并非唯一确定。条件于输入 x 和 S_k，继续生成动态诱导一个完整回答的概率分布 Ω_k。因 J(·) 是二元的，上述概率可等价地写成期望形式：

```
C_k = E_{R∼Ω_k}[J(R)]
```

### 2.3 校准目标构造（Calibration Target Construction）

- **蒙特卡洛补全采样**：对当前状态 S_k 独立采样 N 个可能的完整回答 R^(n)，再通过平均它们的二元安全判断来近似 C_k：

  ```
  Ĉ_k = (1/N) Σ J(R^(n))
  ```

- **CalibEval 判断器**：为避免使用商业审核 API 带来的高昂成本与延迟，论文训练了一个名为 **CalibEval** 的轻量判断模型来估计 J(·)，用于对采样回答进行安全标注，从而低成本地构造校准目标。

### 2.4 概率加权表示（Probability-Weighted Representation）

由于不同 LLM 的词汇表、分词器各不相同，输出概率向量在维度与语义上不具可比性，不能直接被 ProbGuard 处理。为此，论文设计了**概率加权表示**的编码流程：

1. 对每个解码步骤保留 top-K 候选令牌及其概率，并进行归一化；
2. 将每个候选令牌用源模型的 tokenizer 解码为文本，再用 ProbGuard 的 tokenizer 重新分词（ReToken）；
3. 在 ProbGuard 的嵌入空间中，取重新分词后子令牌嵌入的平均值作为该候选令牌的表示；
4. 按归一化概率加权求和，得到该解码步骤的分布编码向量 z_{m,i}；
5. 前 k 步的编码向量序列构成输入表示 Z_{m,k}。

该方案**无需访问被保护 LLM 的隐藏状态**，从而保证跨架构的可迁移性。

### 2.5 校准对齐训练（Calibration Alignment Training）

ProbGuard 以输入 x 和前缀表示 Z_{m,k} 为输入，预测安全风险 Ĉ_{m,k}（记预测为 bC_{m,k}），训练目标为**负对数似然（NLL）损失**：

```
L_NLL = −[ Ĉ log bC + (1−Ĉ) log(1−bC) ]
```

该损失将预测的风险与蒙特卡洛估计的校准目标对齐，使 ProbGuard 的预测准确反映"从前缀继续生成将产生不安全回答"的概率。

## 3. 实验设计

### 3.1 数据集与场景

- **训练集**：合并 PKU、WildGuard、SEval 三个数据集的提示，去重后保留 3,000 个代表性有害样本。
- **评估集**：从三个源数据集各取 1,000 个代表性提示（与训练数据无重叠），评估校准性能。
- **攻击集**：分别从 AdvBench 和 HarmBench 随机采样各 100 个有害提示，检验早期干预能力。

### 3.2 目标 LLM

覆盖三个不同模型家族：**Llama3-8B-it、Qwen3-8B、Gemma2-9B-it**，用于生成响应前缀及对应的输出分布。

### 3.3 越狱攻击

考虑六种代表性攻击：**GCG、COLD-Attack、AdvPrefix、AdvPrompter、PAIR、ECLIPSE**。

### 3.4 基线方法

共 13 个基线，分为四类：

- **基于置信度的方法**：Verbalized Confidence、P(True)；
- **传统护栏**：Llama-Guard3、ShieldGemma、Qwen3Guard、GPT-Safeguard、XGuard、PolyGuard；
- **流式监控器**：Qwen3Guard-stream、SCM；
- **特征探测方法**：线性探针、ShieldHead、TPCs。

### 3.5 评估指标

- **Brier 分数**：衡量实例级预测风险与校准目标的平方差；
- **期望校准误差（ECE）**：按十个等宽分箱衡量分布级校准偏差；
- **攻击成功率（ASR）**：在早期干预场景下评估防御效果（由 GPT-5 作为安全裁判）。

### 3.6 实施配置

- 训练前缀长度 k∈[5,15]，评估前缀长度 k∈[5,20]；
- 每个前缀采样 N=16 个持续补全（temperature=1.0，最多 512 令牌）；
- 概率加权表示保留 top-K=50 个输出概率；
- ProbGuard 默认骨干为 Qwen3-8B，另实例化 4B 与 0.6B 版本验证规模效应。

## 6. 主要结论与发现

- **校准性能显著领先**：ProbGuard 在全部 9 个模型-数据集组合中取得最佳 Brier 与 ECE，平均较最优基线**降低 Brier 分数 79.6%、ECE 71.9%**。例如在 PKU 数据集上针对 Qwen3-8B，Brier/ECE 达 0.0141/0.0249，而最强基线 Qwen3Guard-stream 仅为 0.1151/0.0979。
- **仅需 10 个解码步即可有效早期干预**：ProbGuard-8B 在 AdvBench 和 HarmBench 上的平均 ASR 分别为 0.83% 和 0.67%（综合 0.75%），最优基线 Llama-Guard3 为 2.42%；即使 4B 规模（1.00%）也超过所有基线，0.6B 规模（2.83%）仍具竞争力。
- **随解码步增加校准持续改善**：从 k=5 到 k=20（含超出训练范围的外推点），三种规模的 ProbGuard 的 Brier 与 ECE 整体均呈下降趋势，说明模型能持续整合累积的分布信号。
- **N=16 是采样预算的最佳平衡点**：达到 3.60% 翻转率和 0.9197 Spearman 相关性，进一步增加采样边际收益递减。
- **输出分布信号作为架构无关表示更优**：跨三种 LLM 家族均能取得稳定校准，优于 token 级表示（在 Llama3 上不稳定）和隐藏状态表示（不可迁移）。
- **CalibEval 高效且准确**：F1 达 0.943、FPR 仅 0.058，显著优于 DeepSeek-R1（0.786/0.490）、GPT-5（0.827/0.414）和 Gemini3-Pro（0.833/0.392），且耗时仅为 4.9 秒（LLM 裁判需数千秒）。

## 7. 优点

- **范式创新**：首次将护栏从确定性分类范式转变为完全概率化的风险估计范式，更贴合安全评估固有的不确定性本质；理论形式化（期望形式的蒙特卡洛估计）清晰严谨。
- **架构无关性**：通过概率加权表示映射到 ProbGuard 自身嵌入空间，无需访问被测 LLM 隐藏状态，具备跨模型家族迁移能力，实用性突出。
- **早期干预能力**：仅利用前 10 个解码步的输出分布即可可靠估计风险，能实现在有害内容完全生成前停止，显著降低危害窗口。
- **高效的校准目标构造**：自训练轻量判断器 CalibEval 替代昂贵的商业审核 API，"扩展蒙特卡洛采样+轻量标注"的方案具有工程可行性。
- **实验扎实全面**：覆盖三种模型家族、三个数据集、六种攻击、13 个基线，并包含多个消融维度（采样预算、输入表示、模型规模、解码步），结论有充分证据支撑。
- **可扩展性好**：小规模模型（0.6B 和 4B）仍展现良好性能，说明该方法在低计算预算场景下也能部署。

## 8. 不足与局限

- **实验覆盖范围有限**：目标 LLM 仅限 7-9B 规模的开源模型，未验证在更大规模（如 70B+）或商业黑盒 API 模型上的有效性；攻击集中于英文场景，多语言安全风险未考察。
- **依赖"继任判断"的间接性**：安全风险估计依赖于蒙特卡洛采样和 CalibEval 判断的准确性，若采样的覆盖不足或判断器存在系统性偏差（如 FPR 虽低但仍有误判），会传导至最终风险估计；论文未深入分析这种双层误差的传播。
- **训练数据代表性偏差**：训练数据仅保留 3,000 个有害样本，且来自三个特定数据集，对分布外（OOD）的提示类型或新型越狱攻击的泛化能力有待进一步验证。
- **阈值设定与部署细节**：在早期防御实验中，各方法的操作阈值通过在 PKU 验证集上最大化 F1 确定，这种阈值选择方式在新场景下是否仍然适用（受分布漂移影响）值得讨论。
- **计算资源透明度不足**：未披露训练阶段的 GPU 数量与时长，限制了可复现性与成本评估；CalibEval 的训练细节也未充分展开。
- **与现有部署的整合问题**：ProbGuard 需要在生成过程中持续读取输出分布并逐前缀评估，这对推理时的流式架构和工程管线提出了新的要求，文中对实际部署的系统性影响分析不足。
