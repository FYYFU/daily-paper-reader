## 摘要
在线自蒸馏（OPSD）通过自蒸馏将特权上下文内化到模型参数中，从而提高大型语言模型的推理能力。最近的两条研究路线分别通过选择学习哪些令牌和控制教师接收多少特权信息来改进原始OPSD。然而，我们表明每条路线在固定另一个变量的同时优化一个变量，这会导致次优解。我们认为这两个变量通过学生的学习能力耦合：特权信息设定了教师规定的每令牌散度，而令牌加权则选择学生必须吸收其中的哪些。我们将这两条工作路线形式化为一个统一的优化框架，该框架在学生对总学习难度可吸收的预算约束下，最大化教师-学生散度的总和。在此建模下，我们提出了统一在线自蒸馏（USD），一种轻量级在线算法来求解拉格朗日问题。USD揭示了一个单一的对偶变量同时控制两个决策：以某个学习难度价格，它同时设定令牌选择阈值和特权信息调整方向，使监督与不断变化的学生能力相匹配。通过大量实验，USD在各种推理基准上、不同模型规模下，始终表现出优于OPSD及令牌侧和PI侧基线方法的性能。代码可在 https://github.com/lauvlalala/USD 获取。

## Abstract
On-policy self-distillation (OPSD) improves the reasoning abilities of LLMs by internalizing privileged context into model parameters through self-distillation.   Two recent research lines promote vanilla OPSD by choosing which tokens to learn from and by controlling how much privileged information the teacher receives, respectively.   However, we show that each line optimizes one variable while holding the other fixed, which leads to a suboptimal solution.   We argue that the two variables are coupled through the student's learning capacity: the privileged information sets the per-token divergence the teacher prescribes, while token weighting selects which of these the student must absorb.   We formalize the two lines of work into a unified optimization framework, which maximizes the aggregate teacher--student divergence, subject to a budget on the aggregate learning difficulty the student can absorb.   Under this modelling, we propose Unified On-Policy Self-Distillation (USD), a lightweight online algorithm to solve the Lagrangian.   USD reveals that a single dual variable governs both decisions: at one price for learning difficulty, it simultaneously sets the token-selection threshold and the direction of privileged-information adjustment, keeping supervision matched to the student's evolving capacity.   Through extensive experiments, USD consistently demonstrates superior performance over OPSD and token- and PI-side baselines across various model scales on various reasoning benchmarks. Code is available at https://github.com/lauvlalala/USD.

## 1. 论文的核心问题与整体含义

**研究动机与背景：**
- 大语言模型的后训练（post-training）是提升推理能力的关键环节。在众多范式中，在线自蒸馏（On-Policy Self-Distillation, OPSD）因不需要外部更强教师、不需要交互环境、也不需要人工构造轨迹而受到关注。
- OPSD 的基本设定是：同一个模型同时充当学生和教师——学生从普通问题提示中生成 rollout；教师则基于额外的特权信息（PI，如参考答案、环境反馈、真值推理链等）对每个 token 进行评分，提供细粒度监督。
- 然而，原始 OPSD 有两个默认设置可能限制性能：
  - **Token 层面**：统一权重导致监督信号集中于少数 token，且高散度 token 中许多是不可学习的“不兼容分歧”。
  - **PI 层面**：完全暴露特权上下文会使教师分布过度偏离学生，单步更新难以弥合，且可能泄露答案。
- 现有两条改进路线分别处理上述问题：**token 选择方法**（重加权或筛选 token）和 **PI 控制方法**（调节给教师暴露多少特权信息）。但论文指出，这两条路线是**割裂的**：前者固定 PI，后者固定 token 权重，各自只达到条件最优而非联合最优。

**核心论点：**
- token 选择与 PI 强度通过**学生的学习能力（learning capacity）**耦合：PI 决定每个 token 上教师规定的散度（潜在学习量），而 token 权重决定学生必须吸收其中哪些。二者共同消耗同一个“学习难度预算”，必须联合优化。

## 2. 论文提出的方法论

**核心思想：**
- 将 OPSD 形式化为一个带约束的联合优化问题：在“学生可吸收的总学习难度”预算下，最大化加权的教师–学生散度总和。
- 该优化问题的最优解由一个**单一对偶变量 λ** 控制——它同时决定 token 选择阈值和 PI 强度调整方向，从而将监督与学生的动态能力匹配。

**关键技术细节：**

1. **定义两个每-token 量**：
   - 散度（divergence）\(g_t(\beta) = D_{KL}(p^β_T \| p_S)_t\)：教师分布与学生的距离，表示该 token 的潜在更新幅度。
   - 学习难度（difficulty）\(d_t(\beta) = [\log \frac{p^β_T(a^*_t)}{p_S(a^*_t)}]_+\)：教师最高预测相对学生当前信念的“惊讶程度”，表示吸收该修正所需努力。

2. **统一优化框架**：
   \[
   \max_{w\in[0,1]^T, \beta\in[0,1]} \frac{1}{N}\sum_t w_t g_t(\beta)
   \quad \text{s.t.} \quad \frac{1}{N}\sum_t w_t d_t(\beta) \le \varepsilon
   \]
   其中 \(\varepsilon\) 是学生的每批容量预算。

3. **拉格朗日求解**：
   - 引入对偶变量 \(\lambda \ge 0\)，得到每个 token 的净价值 \(v_t = g_t - \lambda d_t\)。
   - 最优权重理论上为硬阈值：\(w_t^* = \mathbb{1}[g_t(\beta) > \lambda d_t(\beta)]\)，即当散度超过 λ 定价的难度时选中该 token。
   - PI 强度的最优条件满足边际平衡：增加 β 带来的额外散度与额外难度的比值等于 λ，即 λ 同时充当“散度–难度交换率”。
   - 由于 β 对教师上下文的作用不可微，论文提出**残差更新规则**：\(\beta \leftarrow \beta + \eta_\beta(\varepsilon - \text{load})\)，其中 load 为当前平均加权难度。在单调性假设（Assumption 1）下，该规则可以单调收敛到预算约束下的最优 β（Proposition 1），无需计算 β 的梯度。图 4 在真实 Qwen3-1.7B 训练 rollout 上验证了散度和难度随 β 严格单调递增。

4. **USD 在线算法**：
   - 将硬阈值替换为带温度 τ 的 softmax（sigmoid）权重：\(w_t = \sigma((g_t - \lambda d_t)/\tau)\)，保证可微。
   - 通过**对偶上升**更新 λ：\(\lambda \leftarrow \max(0, \lambda + \eta_\lambda(\text{load} - \varepsilon))\)。
   - 通过**残差更新**调整 β：\(\beta \leftarrow \text{clip}(\beta + \eta_\beta(\varepsilon - \text{load}), \beta_{\min}, 1)\)。
   - 训练损失为加权 KL 散度归一化（除以总权重），避免 token 选择影响整体步长。
   - 每批额外开销仅为一次 O(T) 的难度计算和两次标量更新，无需辅助网络或额外前向。

**算法流程（文字说明）：**
- 输入容量预算 ε、温度 τ、步长 ηλ、ηβ；初始化 λ=0、β=β_init。
- 对每个训练 batch：
  1. 学生生成 rollout；
  2. 教师以当前 PI 强度 β 对每个 token 打分；
  3. 计算每 token 的散度 g_t 和难度 d_t；
  4. 计算 soft 权重 w_t；
  5. 以加权 KL 损失更新学生参数；
  6. 计算当前 load；
  7. 对偶上升更新 λ；
  8. 残差更新 β。

## 6. 论文的主要结论与发现

- **单变量优化是次优的**：token 选择和 PI 控制分别只在固定另一个变量时达到条件最优，无法达到联合最优。
- **统一框架有效**：将两者纳入同一容量预算约束后，拉格朗日对偶证明单一变量 λ 同时控制 token 阈值和 PI 强度。
- **USD 一致优于基线**：在 3 个模型规模、3 个基准上，USD 的 9 单元格平均准确率从 vanillas OPSD 的 56.4 提升到 58.7（+2.3 点），每个规模均提升约 2 点；同时优于 TIP、PAINT 和 GRPO。
- **两类机制互补**：消融显示每个轴单独都有收益，但联合优于单独任一，且不同规模下两者相对贡献不同，说明固定的手工混合权重无法匹配合适的联合方案。
- **动态行为符合理论**：训练过程中 load 被控制在 ε 附近，λ 在 load 达到预算前为零、之后激活并收紧 token 选择，β 则相应回落，展示了两者协同平衡。
- **容量预算需适中**：ε=0.3 时最优，过紧导致过滤过度、过松退化为均匀权重。
