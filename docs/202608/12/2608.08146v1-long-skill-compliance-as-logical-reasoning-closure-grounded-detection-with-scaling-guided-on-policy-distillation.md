## 摘要
企业业务场景日益复杂，推动了长SKILL文档在智能体系统中的广泛采用，同时也给合规检测带来了新的挑战：大模型推理成本高昂，而小模型可能难以维持检测准确率。为弥合这一差距，我们提出了SkillCDG，一种基于图的长SKILL合规检测框架。SkillCDG将复杂业务策略表示为两层约束依赖图，其中上层索引SKILL描述以进行场景路由，下层捕获每个SKILL内原子约束之间的依赖关系。推理阶段，两级检索后接闭包计算支持合规判断与来源追溯。我们在三个企业数据集和两个受控公共基准变体上全面评估了该框架。实验结果表明，SkillCDG在检测F1分数上比基线方法最多提升12.8个百分点，同时令牌消耗最多降低64.3%。此外，我们进一步探究了策略图复杂度、模型规模与检测性能之间的内在关系。在单个模型家族的四个检查点上进行的对比实验验证了一种简洁有效的缩放趋势：端到端检测正确性呈现复杂度差异化的缩放模式，且从约束依赖图导出的复杂度指标能有效量化实例难度和模型的性能提升潜力。借助这一具有洞察力的缩放趋势，我们进行自适应训练样本选择，并采用在线策略蒸馏来高效提升小规模模型的合规检测能力。

## Abstract
The increasing complexity of enterprise business scenarios has promoted the widespread adoption of long SKILL documents in agent systems, posing new challenges for compliance detection: large models incur substantial inference costs, while small models may fail to maintain detection accuracy. To address this gap, we propose SkillCDG, a graph-based framework for long SKILL compliance detection. SkillCDG represents complex business policies as a two-layer constraint dependency graph, where the upper layer indexes SKILL descriptions for scenario routing and the lower layer captures dependencies among atomic constraints within each SKILL. During inference, two-level retrieval followed by dependency closure supports compliance judgment and source traceability. We comprehensively evaluate the framework on three enterprise datasets and two controlled public benchmark variants. Experimental results demonstrate that SkillCDG outperforms baseline methods by up to 12.8 percentage points in detection F1 score, while reducing token consumption by a maximum 64.3\%. Moreover, we further investigate the inherent relationships among policy-graph complexity, model scale, and detection performance. Comparative experiments conducted on four checkpoints from a single model family validate a concise and effective scaling trend: end-to-end detection correctness exhibits a complexity-differentiated scaling pattern, and the complexity metric derived from the constraint dependency graph can effectively quantify instance difficulty and the performance improvement potential of models. Leveraging this insightful scaling trend, we conduct adaptive training sample selection and adopt on-policy distillation to efficiently enhance the compliance detection capability of small-scale models.

## 2. 方法论

### 2.1 核心思想

将长 SKILL 策略文档离线转化为**双层约束依赖图（Constraint Dependency Graph, CDG）**：
- **上层**：SKILL 级路由索引，记录 SKILL 名称与描述，用于场景定位；
- **下层**：原子规则图，每个原子约束表示为三元组 `rᵢ = ⟨cᵢ, aᵢ, Sᵢ⟩`（条件、规范动作、源文本片段），规则间以**类型化 require 边**表示强制审计前置依赖。

这种表示的核心特性在于：所有边统一语义（均为 require 前置关系），消除了一般知识图谱的关系异质性；每条规则保留源文本链接，满足审计可追溯性要求。

### 2.2 离线阶段：CDG 构建

- **分块原子约束提取**：按 Markdown 标题边界将文档切分为语义块，逐块用 LLM 提取原子规则及块内 require 依赖，形成局部子图；
- **跨块图融合**：将局部子图增量合并为每个 SKILL 的完整规则图，做语义去重、源跨度合并和跨块依赖补边，修复分块造成的碎片化；
- **双层架构组装**：上层索引 SKILL 元数据，下层包含各 SKILL 的原子规则图。

### 2.3 在线阶段：合规检测流水线

三个顺序步骤：
1. **两级策略检索**：从交互上下文提取审计关键词 → SKILL 级关键词匹配排除无关场景 → 所选 SKILL 内对规则条件、动作和源跨度匹配，定位种子义务规则；
2. **依赖闭包扩展**：从种子规则沿 require 边做传递闭包遍历（含环处理），保留所有可达前置规则，滤除无关规则——这一步修复了单纯检索可能遗漏资格检查、例外等必要前置的问题；
3. **合规判定**：将规则闭包转换为结构化条件–动作文本，连同交互上下文交给 LLM 判断，输出违规二分类标签并保留源文本作为取证证据。

### 2.4 复杂度度量与经验缩放模型

定义了三个可量化指标：
- **规则密度**：`I_d = T(R)/T(D)`，可审计规则令牌占全文令牌的比例；
- **依赖耦合度**：`I_c = |E|/|R|`，前置依赖边数相对规则数的比率；
- **策略图复杂度**：`C = I_d × I_c`，密度与耦合度的乘积。

提出如下的经验缩放模型（Eq.3）：

```
logit P(Z=1) = γ_data(i) − η·e^C̃ + β·(1 − e^(−ρ·Ñ^α))·e^(−λ·C̃)
```

其中 Ñ = N/1B 为归一化参数量，C̃ = C/C₀ 为归一化复杂度，γ_data 为数据集截距。该模型允许正确率随规模饱和，并允许复杂度调节规模带来的增益方向。将其与加性逻辑模型和嵌套饱和模型（λ=0）比较，通过分组交叉验证选出最优形式。

### 2.5 缩放引导的在线策略蒸馏（OPD）

- 用拟合模型估计 9B 教师与 4B 学生之间的**预测增益**：`gᵢ = P̂₉B(Cᵢ,dᵢ) − P̂₄B(Cᵢ,dᵢ)`；
- 在固定训练预算（2000 样本）下，Scaling-guided OPD 按增益降序选取样本，而 Uniform OPD 在同一分层内随机抽样；
- OPD 采用 on-policy 机制：学生从当前策略采样响应，教师以学生生成前缀为条件打分，用 k1 反向 KL 估计器（log πθ − log πT）计算优势信号，以策略梯度更新。

## 6. 主要结论与发现

1. **SkillCDG 显著提升检测效果**：在 Qwen3.5-4B 上 F1 较 RawSkill 提升 12.8/5.9/6.8 个百分点（三个企业数据集），9B 上提升 10.8/9.5/5.1 个百分点；27B 上 ACC 提升 13.2/1.8/9.2 个百分点。结构化的策略访问对小型判别模型收益最大。
2. **推理成本大幅下降**：平均在线 token 消耗在 Fulfillment、AfterSales、MerchantSupport 上分别降低 64.3%、33.9%、39.1%。
3. **公共基准稳定迁移**：在 CompliBench 与 CompliBench-Long 上均改善 ACC/F1，且在长策略变体上的增益反映的是对干扰文本的鲁棒性而非任务语义变化。
4. **规模与复杂度联合预测正确率**：低复杂度样本的检测正确率随规模迅速饱和，高复杂度样本更难判断且从大模型中获益更多；27B 的实测表现与拟合趋势吻合，验证了缩放模型的外推有效性。
5. **依赖闭包是核心、关键词过滤是效率保障**：去掉闭包导致最大 F1 下降 7.5 个百分点，而去掉关键词过滤则上下文膨胀、推理开销上升且精度受损。
6. **缩放引导的 OPD 优于均匀抽样**：在相同 2,000 样本预算下，Scaling-guided OPD 在三个数据集上分别恢复教师–学生 F1 差距的 127.7%、166.7%、39.2%（Uniform 为 85.1%、83.3%、19.6%），前两个数据集上学生 F1 甚至反超教师，说明高增益样本集中于学生尚未掌握的策略推理行为。

## 7. 优点

- **问题建模创新**：将合规审计从端到端黑箱判断解耦为「场景路由 → 依赖补全 → 义务比对」三阶段，每个阶段可独立诊断和优化；
- **图表示设计精巧**：统一 require 边语义使遍历语义明确（传递闭包而非语义关联），双层结构同时解决跨场景隔离与场景内依赖完整性；源跨度保留使每次判定可审计、可追溯。
- **成本与精度兼得**：两阶段过滤压缩上下文，闭包扩展保精，在降低 64.3% 令牌消耗的同时提升检测精度，方向上优于只考虑精度或只考虑成本的做法。
- **缩放分析具有实践价值**：CDG 复杂度度量（密度 × 耦合度）将实例难度从长度中解耦出来，揭示模型规模收益递减的结构性原因；拟合模型可直接用于模型选型和样本优先排序。
- **蒸馏实验设计严谨**：两种 OPD 变体共享相同配额、预算、架构与超参，仅样本选择策略不同，使性能差异可干净归因于选择策略；恢复率指标（Eq. 6）直观可解释。
- **评估范围较完整**：跨模型家族、跨规模、跨数据集类型（企业/公共/受控干扰)），并有消融、人工评估、外推验证等多重证据支撑。

## 8. 不足与局限

- **大规模模型上优势减弱甚至反转**：在 DeepSeek-V4-Pro 和 GPT-5.4 上，部分数据集中 RawSkill 的 ACC/F1 反而优于 SkillCDG，说明强模型的隐含推理能力可部分替代结构化输入，SkillCDG 的价值更偏向紧凑模型和成本敏感场景。
- **无显著性统计**：未报告重复实验的标准差或显著性检验结果，部分性能差异（1–2 个点）可能落在噪声范围内。
- **缩放模型拟合细节有限**：未报告拟合优度指标、复杂度阈值 C₀ 的具体取值、数据级截距的估计值，也未展示 Eq. 3 与其他候选模型的具体比较数值；留一规模外推只验证了 27B 一个点。
- **公共基准覆盖不足**：CompliBench 迁移实验仅测试了 2 个模型，未覆盖完整 Qwen3.5 尺度系列，也缺少与 CompliBench 原始报告中其他方法的比较。
- **OPD 应用范围受限**：蒸馏实验仅在一个模型对（4B 学生、9B 教师）和一个固定预算（2,000 样本）上验证，未测试不同预算规模下高增益样本优先级是否稳定，也未验证该方法在跨模型家族蒸馏中的有效性。
- **依赖标注成本**：图构建依赖 LLM 提取规则与依赖关系，虽有高质量人工评估（规则正确率 ≥98.7%），但提取错误的边界情况可能被误差传导到下游判定；跨域迁移到未见过的 SKILL 格式时，提取质量未经测试。
- **多模态策略未覆盖**：文中将策略限定为文本规则，明确未涉及图片、语音等多模态策略场景，实用性有边界。
