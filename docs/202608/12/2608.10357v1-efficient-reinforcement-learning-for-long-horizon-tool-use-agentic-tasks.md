## 摘要
长时程工具使用智能体必须对用户目标、领域策略、工具调用、模拟器状态以及延迟的可验证奖励进行推理。强化学习（RL）天然适合这一场景，但多轮on-policy展开会形成长上下文，而特定于模型的注意力层可能需要自定义掩码和学习到的汇点归一化。我们提出了SINKFLEX-RL，一个用于双控制工具使用环境中强化学习的模块化训练系统。该系统结合了Gymnasium兼容环境包装器、VERL风格的展开数据流、无需独立价值模型的组相对策略优化，以及一个汇点感知的FlexAttention路径，旨在在因果掩码和滑动窗口掩码下保持特定于模型的汇点缩放。在初步的Tau2Bench零售实验中，验证奖励（mean@1）在训练早期从0.25上升到观察到的训练窗口后期的0.44，同时训练得分和轨迹奖励代理指标也呈上升趋势。在固定配置的内存基准测试中，优化后的注意力路径在4096个token时将峰值VRAM从28.06GB降低到22.52GB，减少了19.7%，并且以25.53GB运行了测量的8192个token配置，而eager基线则内存不足。这些结果说明了整合环境接口、RL数据流和注意力内核设计对于内存可行的长时程智能体训练的价值。

## Abstract
Long-horizon tool-using agents must reason over user goals, domain policies, tool calls, simulator state, and delayed verifiable rewards. Reinforcement learning (RL) is a natural fit for this setting, but multi-turn on-policy rollouts create long contexts, while model-specific attention layers may require custom masks and learned sink normalization. We present SINKFLEX-RL, a modular training system for RL in dual-control tool-use environments. The system combines a Gymnasium-compatible environment wrapper, a VERL-style rollout dataflow, group-relative policy optimization without a separate value model, and a sink-aware FlexAttention path designed to preserve model-specific sink scaling under causal and sliding-window masks. In a preliminary Tau2Bench retail run, validation reward (mean@1) rises from 0.25 early in training to $0.44$ later in the observed training window, while training-score and trajectory-reward proxies also trend upward. In a fixed-configuration memory benchmark, the optimized attention path reduces peak VRAM from 28.06GB to 22.52GB at 4096 tokens, a $19.7\%$ reduction, and runs the measured 8192-token configuration using $25.53$~GB where the eager baseline runs out of memory. These results illustrate the value of integrating environment interfaces, RL dataflow, and attention-kernel design for memory-feasible long-horizon agent training.

## 1. 论文的核心问题与整体含义

**研究动机与背景：**
- 长时程（long-horizon）工具使用型智能体需要在多轮交互中同时推理用户目标、领域策略（SOP）、工具调用、模拟器状态，并从"延迟且可验证"的稀疏奖励（sparse verifiable rewards）中学习。
- 强化学习（RL）天然适合该场景，但存在两个核心瓶颈：
  1. **上下文长度爆炸**：多轮 on-policy rollout 产生极长的序列（可达数万 token），导致密集注意力的内存占用呈二次方增长，在反传前即可耗尽高带宽内存（HBM）。
  2. **模型特定注意力层兼容性**：生产级 MoE 模型可能带有学习到的 attention sink 参数、异构掩码（causal + sliding-window），而现有融合内核（如 FlashAttention）可能不暴露这些可微路径。
- 论文的核心论点：解决上述瓶颈需要**系统级集成**——将环境接口、RL 数据流、注意力内核设计三者统一考虑，而非在某一层单独修补。作者提出 SINKFLEX-RL 系统，证明这种集成能够实现内存可行的长时程智能体训练。

## 2. 方法论

**核心思路：** 模块化整合四个组件——Gymnasium 兼容的环境包装器、VERL 风格的 rollout 数据流、无需独立价值模型的 GRPO 策略更新、以及 sink 感知的 FlexAttention 路径。

**关键技术细节与公式说明：**

**(a) 双控制环境包装器（Dual-Control Environment Wrapper）**
- 将 τ2-Bench 类环境抽象为统一的 `reset/step` 接口，模型输出被路由至三种处理器之一：自然语言回复、工具调用、终止信号。
- 该抽象将用户模拟器、工具后端、奖励检查逻辑与训练器解耦，便于扩展到其他可执行环境。

**(b) GRPO 策略更新（无价值模型）**
- 使用组相对策略优化，每组 G 条轨迹归一化奖励得到优势：
  \[
  \hat{A}_i = \frac{R_i - \mu(R_{1:G})}{\sigma(R_{1:G}) + \epsilon_A}
  \]
- 采用重要性采样比率与裁剪目标（PPO 风格）：
  \[
  \rho_{i,t}(\theta) = \frac{\pi_\theta(y_{i,t} | x, y_{i,<t})}{\pi_{\theta_{old}}(y_{i,t} | x, y_{i,<t})}
  \]
  \[
  L_{GRPO}(\theta) = -\frac{1}{\sum_i T_i} \sum_{i,t} \min\left(\rho_{i,t}\hat{A}_i, \ \text{clip}(\rho_{i,t}, 1-\epsilon_c, 1+\epsilon_c)\hat{A}_i\right) + \beta D_{KL}(\pi_\theta \| \pi_{ref})
  \]
- 核心动机：**省去价值模型**，避免其带来的额外内存与计算开销。

**(c) 零值 Sink 等价（Zero-Value-Sink Equivalence）**
- 为避免在 KV cache 中显式物化额外的 sink token，作者推导出代数等价关系：当 sink 的 value 向量为零时，显式 softmax 拼接等价于对标准注意力输出乘以一个 sigmoid 缩放因子：
  \[
  O_{sink} = \sigma(\ell - s_\eta) \cdot O_{std}, \quad \ell = \log\sum_i \exp(q\cdot k_i)
  \]
- 该构造使得 sink 逻辑可仅通过 log-sum-exp 统计量实现，避免显式物化。

**(d) Sink 感知的 FlexAttention 路径**
- 掩码函数组合因果约束与滑动窗口（prefix 始终可见）：
  \[
  M_{b,h,q,k} = \mathbf{1}[k \le q] \wedge \mathbf{1}[q - k \le w \vee k < p]
  \]
- 通过 `torch.compile` 与 AOTAutograd 生成前向/反向代码，保持对 sink 参数的可微性，无需物化 O(n²) 的 Jacobian。
- 内存优化：消除 sink-rescaling 中的 eager 物化；mask 元数据跨 batch/head 广播，避免重复存储。
