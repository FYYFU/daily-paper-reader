## 摘要
可验证奖励的强化学习（RLVR）将单个响应级奖励广播给每个 token，而在线策略蒸馏（OPD）则针对更强的教师对每个 token 进行评分，以提供密集优势，但其性能上限受限于教师质量，且抑制超出教师的探索。两者的互补性使得 RLVR 与 OPD 的结合颇具前景，但我们发现，以固定系数融合这两种优势会引发熵坍缩，原因在于两种误校准：量级不匹配（token 级 OPD 优势可能飙升至远超有界 RLVR 优势，从而抹去其信号）和时间不匹配（持续满强度的 OPD 不断将学生拉向教师，限制了超越教师所需的探索）。我们提出 SAF，一种稳定优势融合框架，通过仅应用于 OPD 优势的轻量级四阶段流水线解决上述两个问题：先稀疏后压缩机制用于量级控制，配合先预热后退火机制用于时间控制，每个阶段均可独立开关，且额外开销可忽略。使用 GRPO 实例化 RLVR，我们在七个数学推理和代码生成基准上，以 Qwen3-1.7B/4B/8B 对 SAF 进行了评估：SAF 避免了熵坍缩，并持续优于固定系数的 GRPO+OPD 融合，在全部六种模型-领域设置中将聚合得分提高了 0.51-2.70%，同时实现了更稳定的训练。

## Abstract
Reinforcement learning with verifiable rewards (RLVR) broadcasts a single response-level reward to every token, while on-policy distillation (OPD) scores each token against a stronger teacher for a dense advantage but caps performance at teacher quality and discourages exploration beyond it. Their complementarity makes combining RLVR and OPD promising, but we find that fusing the two advantages with a fixed coefficient triggers entropy collapse from two miscalibrations: a magnitude mismatch, where token-level OPD advantages can spike far beyond the bounded RLVR advantage and erase its signal, and a temporal mismatch, where sustained full-strength OPD keeps pulling the student toward the teacher and limits exploration needed to surpass it. We propose SAF, a Stable Advantage Fusion framework that resolves both issues via a lightweight, four-stage pipeline applied only to the OPD advantage: a sparsify-then-compress mechanism for magnitude control paired with a warm-up-then-anneal mechanism for temporal control, with each stage independently switchable and adding negligible overhead. Instantiating RLVR with GRPO, we evaluate SAF across seven mathematical reasoning and code generation benchmarks with Qwen3-1.7B/4B/8B: SAF avoids entropy collapse and consistently outperforms fixed-coefficient GRPO+OPD fusion, improving the aggregate score by 0.51-2.70% across all six model-domain settings while achieving more stable training.

## 1. 论文的核心问题与整体含义

- **研究背景**：可验证奖励强化学习（RLVR）将单个响应级奖励广播给所有 token，简单但粗粒度；在线策略蒸馏（OPD）则利用更强教师模型为每个 token 提供密集优势，但性能受限于教师质量、抑制探索。两者天然互补，因此近年来出现将两者优势直接相加的融合方法。
- **核心问题**：以固定系数融合 RLVR 优势与 OPD 优势会引发**策略熵坍缩**，导致探索停滞、最终性能封顶。论文将根因归结为两类"误校准"：
  - **量级不匹配（Magnitude Mismatch）** ：OPD 的 token 级优势无界且重尾，少数 token 的优势值可超过 GRPO 优势一个数量级以上，数值上主导整个梯度的更新，抹去 RLVR 信号；文中观察到 OPD 极值达 20.36，而同期 GRPO 幅值最大仅 2.47。
  - **时间不匹配（Temporal Mismatch）** ：满强度的 OPD 指导在训练初期会加速熵坍缩，在训练后期（学生已接近教师水平）持续满强度又过度约束策略、抑制超越教师的探索。
- **总体含义**：不能将 RLVR 与 OPD 的融合简化为单一系数调参，必须对 OPD 优势的量级和时间尺度分别进行专门控制。

## 2. 方法论述：SAF 框架

### 2.1 核心思想
SAF 是一个仅作用于 OPD 优势分支的四阶段轻量级流水线，与未修改的 GRPO 优势相加构成最终优势用于策略梯度更新。每个阶段均可独立开关；全部关闭时退化为固定系数融合 `A_GRPO + A_OPD`。

### 2.2 量级控制：先稀疏化后压缩（Sparsify-then-Compress）

- **阶段1：Top-k% 稀疏化**。对每条响应序列，按 |A_OPD| 的 (1−k%) 分位数 τ_k(i) 作为阈值，只保留幅值超过阈值的 token，其余置零。阈值按序列自适应计算，k=100 时等于不过滤（即该阶段严格泛化未过滤信号）。
- **阶段2：有界 tanh 压缩**。将稀疏化后的信号经 `c·tanh(·)` 映射至 (−c, c) 区间，保留小信号之间的相对大小顺序，同时约束极端离群值。论文默认 c=0.1。

### 2.3 时间控制：先预热后退火（Warm-up-then-Anneal）

- **阶段3：KL 触发的预热**。OPD 系数按 `scale(s) = min(s/S_warmup, 1)` 线性上升，且监测学生到教师的采样 token 反向 KL（使用 k3 低方差估计），当相对下降 `(KL₀−KL_s)/KL₀ ≥ δ` 时提前结束预热，冻结当前缩放值。此机制防止过早以满强度注入 OPD 导致的熵坍缩，也防止过度模仿教师缺陷。
- **阶段4：剩余步骤线性退火**。预热结束步 s_w 为起点，在剩余训练预算 R = S − s_w 内，系数从 1 线性降至下界 c_min（默认 0）。KL 触发提前结束会扩大 R 使退火更平缓；禁用预热则从第 0 步开始全程退火。

### 2.4 融合公式

最终优势：
```
A_total_{i,t} = A_GRPO_i + opd_coef(s) · scale(s) · A_OPD^{tanh}_{i,t}
```
该方案不引入额外模型、辅助损失或额外前向传播，各阶段仅需维护每序列分位数、KL₀、s_w 和 t_a 等少量统计量，可直接替换现有 GRPO+OPD 训练循环。

- **不足**：只验证了单一教师（Qwen3-30B-A3B）、单一 RLVR 算法（GRPO）、单一时段（2026 年基准版本）；训练的步骤较短（300/200 步）；无多随机种子报告，未报告方差。

## 6. 主要结论与发现

1. **固定系数融合确实导致熵坍缩**：训练早期熵从约 0.35 快速降至 0.30 并保持低位，KL 降至四种方法中最低，批评得分停滞在约 0.77，准确率最早进入平台期。
2. **SAF 避免熵坍缩并改善性能**：熵保持在 0.35–0.38 的中间水平，KL 稳步下降但不过度贴合教师；批评得分恢复至约 0.84，接近 GRPO 的轨迹。
3. **性能提升一致且显著**：SAF 在全部 6 个模型-领域设置的聚合得分上均超过固定系数融合，提升幅度 0.51–2.70%；平均聚合分 49.46%，分别超过固定融合 1.54%、GRPO-only 2.71%、OPD-only 1.60%。数学领域提升随学生规模缩小单调上升（8B 0.97% → 4B 1.51% → 1.7B 1.85%）。
4. **量级控制与时间控制互补**：仅做量级控制不足以提升最终精度（44.35% vs 固定融合 44.38%）；加入退火后显著提升（45.23%）；完整 SAF 达 45.89%。
5. **更紧的 KL 拟合并不等于更好性能**：固定融合 KL 最低但准确率也最低，印证教师是不完美的代理，过度模仿适得其反。

## 7. 优点

- **问题诊断深入**：将固定融合的失败分解为量级/时间两类正交的误校准，并用分布统计、训练曲线、参数空间证据多维度验证，论证有说服力。
- **方法轻量实用**：四阶段均为 OPD 优势的简单变换，无额外模型/损失/前向传播，各阶段独立可开关，可直接插入现有 GRPO+OPD 循环。
- **设计具备自适应性**：top-k 阈值按序列自适应、预热终点由 KL 相对下降动态触发而非固定步数、退火时长由实际预热终点决定，减少了超参敏感性。
- **实验系统性强**：覆盖 3 种模型规模、2 个领域、7 个基准、4 类基线，辅以消融与多种动力学分析，证据链完整。
- **训练稳定性提升**：除了最终精度，还报告了熵、响应长度、权重漂移等稳定性指标，均显示 SAF 训练过程更稳健。

## 8. 不足与局限

- **通用性验证有限**：仅使用单一教师模型、单一时段的 Qwen3 学生家族、单一 RLVR 实例（GRPO），未测试其他教师/学生组合或其他 RLVR 变体（如 DAPO、Dr.GRPO）。
- **混合系数超参数仍需人工选定**：k、c、δ、S_warmup、c_min 五个超参数虽部分自适应，但主值仍依赖人工选择，且 δ 的敏感性实验仅做了 0.2 与 0.3 两组。
- **训练预算偏短**：数学 300 步、代码 200 步的训练时长对于评判最终收敛性能可能不足，尤其代码任务可能尚未完全收敛。
- **未报告统计不确定性**：未给出多次运行的方差或显著性检验，无法判断部分小差距（如 0.51%）的稳健性。
- **高算力门槛**：实验基于 H200 集群，教师模型为 30B 级，小规模团队复现成本较高。
- **分析深度不均衡**：参数空间分析被作者自述为探索性观察，未与 SAF 设计直接建立因果联系；代码领域的动力学分析也未展开。
- **时间错配的度量仅依赖 KL**：KL 触发机制对 KL 估计质量敏感，且论文未讨论 KL 估计在长序列上的数值稳定性边界。
