## 摘要
策略蒸馏（OPD）在教师提供的密集词级监督下，基于学生自身的轨迹进行训练。诸如ExOPD之类的奖励外推方法通过放大教师参考对数似然比来超越直接模仿，但对每个词符应用单一全局系数λ。这可能导致学生拟合隐式奖励中的极端峰值，从而引发奖励黑客攻击和训练不稳定，且最优λ因领域而异，需要代价高昂的扫描。我们提出REOPD，一种用于OPD的可靠性自适应奖励外推框架。REOPD将词级兼容性权重与批量级自适应预算相结合，生成词级系数λ_{b,t}=1+γ_b q_t，在保持教师对齐的同时，沿可靠的教师参考方向选择性外推。它无需验证器、奖励模型、价值模型或超出标准OPD的额外轨迹。REOPD在单教师数学任务和双教师设置的两种领域上均优于G-OPD，同时在单教师代码任务上与G-OPD持平，展示了跨领域和教师配置的有效细粒度可靠性自适应。

## Abstract
On-policy distillation (OPD) trains a student on its own trajectories under dense token-level supervision from a teacher. Reward-extrapolation methods such as ExOPD amplify the teacher-reference log-likelihood ratio to move beyond direct imitation, but apply a single global coefficient $λ$ to every token. This can drive the student to fit extreme peaks in the implicit reward, causing reward hacking and unstable training, and the optimal $λ$ varies across domains, requiring costly sweeps. We propose REOPD, a reliability-adaptive reward extrapolation framework for OPD. REOPD combines a token-level compatibility weight with a batch-level adaptive budget, yielding a token-wise coefficient $λ_{b,t}=1+γ_b q_t$ that preserves teacher alignment while selectively extrapolating along reliable teacher-reference directions. It requires no verifier, reward model, value model, or extra rollout beyond standard OPD. REOPD outperforms G-OPD on single-teacher mathematics and on both domains in the multi-teacher setting, while matching G-OPD on single-teacher code, demonstrating effective fine-grained reliability adaptation across domains and teacher configurations.

## 1. 论文的核心问题与整体含义

- **研究背景**：在线策略蒸馏（On-policy Distillation, OPD）是一种针对大语言模型（LLM）的后训练范式：学生模型在其自身生成的轨迹上训练，并由教师模型在相同前缀上提供密集的 token 级监督，因而能有效迁移教师模型的推理能力。
- **已有问题**：G-OPD 将 OPD 解释为带 KL 正则的密集强化学习，其中教师与参考策略的对数似然比作为隐式奖励。标准 OPD 对应奖励系数 λ=1，而 ExOPD 通过设置 λ>1 放大“超出教师”的残差，以超越直接模仿。
- **核心缺陷**：ExOPD 对所有 token 使用同一个全局标量 λ，无法区分不同 token 的可靠性与学生-教师兼容性。这会导致：
  - 极端教师-参考对数似然比（奖励峰值）被过度放大，引发奖励黑客（reward hacking）和训练不稳定；
  - 最优 λ 因任务领域而异，需要针对每个设置做昂贵的全局系数扫描（sweep），且可能仍无法找到合适的强度。
- **REOPD 的核心动机**：教师对齐（alignment）与“超越教师的外推”应被分开控制。即使某个 token 有较大的学生-教师差异，其对齐信号可能仍有用，但不应被无差别地放大外推。因此需要一种细粒度、可靠性自适应的外推系数。

## 2. 论文提出的方法论

- **核心思想**：REOPD 将 ExOPD 中固定的全局残差乘子替换为“token 级兼容性权重”与“微批级自适应预算”的乘积，从而构造逐 token 有效外推系数 λ_{b,t}=1+γ_b q_{b,i,t}。这样既保留了标准 OPD 的教师对齐项，又只选择沿可靠的教师-参考方向进行外推。
- **问题建模**：
  - 对齐成本：a_t = log π_θ(y_t|s_t) − log π_T(y_t|s_t)；
  - 教师-参考隐式奖励：r_t = log π_T(y_t|s_t) − log π_ref(y_t|s_t)；
  - ExOPD 原始损失：C_t^{ExOPD} = a_t − (λ−1) r_t；
  - REOPD 损失：C_{b,i,t}^{REOPD} = a_{b,i,t} − γ_b q_{b,i,t} r_{b,i,t}。
- **Token 级兼容性权重 q**：
  - 使用低方差差异代理 δ_b,i,t = exp(x) − x − 1，其中 x = log π_T(y_t|s_t) − log π_θ(y_t|s_t)；
  - 定义 q = exp(−δ/τ)，δ≥0 所以 q ∈ (0,1]：学生-教师差异小则 q≈1，保留大部分外推残差；差异大则 q 变小，抑制不可靠外推。
- **微批级可靠残差统计**：
  - 加权残差比例 ρ_b = (∑ m |r| q) / (∑ m |r| + ε)，衡量经兼容性加权后保留的残差比例；
  - 可靠残差尺度 s_b = √(∑ m (q r)^2 / ∑ m + ε)，衡量保留残差的 RMS 规模；
  - 以上统计量在数据并行各 rank 之间做 all-reduce，并使用 EMA 平滑（β=0.95）。
- **有界微批预算 γ_b**：
  - 目标预算：êγ_b = clip(B0 · ρ̄_b / (s̄_b + ε), 0, γ_max)；
  - 直觉：ρ̄ 大说明残差可靠，可增加外推强度；s̄ 大说明残差幅值大，需减小系数以避免主导更新；
  - γ_b 再经 EMA（β_γ=0.9）平滑，并保持有界；B0 可自动校准（基于对齐项 RMS）或手动设定。
- **最终优化**：PPO 风格的 actor 更新使用优势 A = −C^{REOPD}，其余流程与 OPD 基线一致。所有控制信号（q、统计量、预算）均 stop-gradient，不修改教师对齐项 a_t。
- **额外开销**：不引入验证器、奖励模型、价值模型或额外 rollout，只需复用 G-OPD 中已有的学生、教师、参考策略的对数概率。

## 3. 实验设计

- **对比方法**：

## 6. 论文的主要结论与发现

- **单教师数学**：REOPD 达到 47.66% 平均样本准确率，超过 OPD（46.28%）和 ExOPD λ=1.25（47.47%）。
- **单教师代码**：REOPD 达到 63.45% 加权准确率，与 G-OPD（即最佳固定系数 ExOPD，63.60%）基本持平，优于 OPD（62.55%）和 ExOPD λ=1.25（61.72%）。
- **多教师蒸馏**：数学 47.01%、代码 63.32%，同时超过 OPD（46.43%/61.99%）和 ExOPD λ=1.25（46.98%/62.90%）。
- **固定系数敏感性**：最优 λ 因任务而异——数学最优 λ=1.25，代码最优 λ=1.5，多教师设置各有不同；REOPD 无需任务特定 λ 扫描，性能高于或接近各场景下固定系数最优值（4 个场景中超出 3 个，仅单教师代码低 0.15 个百分点）。
- **消融结果**：
  - 去除 token 兼容性权重（no_q）导致准确率从 47.66% 降至 43.39%（−4.27），证明 token 级兼容性是最核心组件；
  - 去除预算上界（no_bound）降至 47.16%（−0.50），说明显式 γ_max 提供一定保护；
  - 固定基系数 + token 权重（no_batch）在 λ0=1.25 时达到 47.66%，与完整 REOPD 相当，说明自适应微批预算可避免固定系数扫描。
- **控制器动态**：训练早期预算 γ 增长迅速（数学从 0.608 升至约 1.000），后期主要靠 token 权重 q 提供自适应调节；有效系数 λ 随训练从约 1.5 升至 1.85 左右。

## 7. 优点

- **创新性**：将奖励外推从“全局统一缩放”细化为“token 级可靠性门控 + 微批级预算控制”，统一了教师对齐与外推之间的冲突。
- **零额外代价**：全部控制信号均由 OPD 流程中已有的学生、教师、参考对数概率计算，无需验证器、奖励模型、价值模型或额外 rollout，工程可用性强。
- **数学性质清晰**：λ_{b,t}=1+γ_b q_t 明确界于 [1, 1+γ_max]，且兼容权重 q∈(0,1]，避免无界放大；退化分析清楚（γ=0 即 OPD，q=1 且 γ=λ−1 即 ExOPD）。
- **实验设计较全面**：包含单教师/多教师、数学/代码、固定系数扫描、消融、动态轨迹分析，从多个角度验证方法有效性。
- **结论实在**：不夸大性能，明确指出单教师代码上只是持平，并承认方法仍有局限性。

## 8. 不足与局限

- **兼容性代理并非正确性估计**：q 只度量学生-教师抽样概率差异，无法识别“学生与教师一致但两者都错”的 token；因此仍可能沿错误方向外推。
- **超参数仍需调优**：虽然避免了 λ 扫描，但 τ、γ_max、B0 校准系数和 warm-up 仍需人为指定，且论文中数学设置还用了 warm-up，增加了不同设置间的不一致性。
- **统计稳健性不足**：主结果未提供多次运行的方差或置信区间，消融也仅在单 seed（seed 42）上执行，结论的偶然性风险未充分排除。
- **消融覆盖有限**：组件消融只在单教师数学上进行，未验证在代码、多教师场景中的贡献排序；对多教师共享控制器的进一步分析（共享 vs 各教师独立控制器）未进行。
- **训练设置信息缺失**：未披露总训练步数、训练总时长、计算成本，不利于复现评估。
- **方法假设限制**：依赖白盒访问教师对数概率；若教师为黑盒 API，则无法直接应用。
- **后期预算饱和**：实验显示 γ 后期接近上界 γ_max，导致预算的调节能力减弱，最终自适应性主要依赖 token 权重，微批预算的作用随训练减弱。
